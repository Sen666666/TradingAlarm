# B3 独立语义审查：用层级状态表达当前上行证据

2026-10-25。审查者 `/root/b3_semantics`。本记录是设计建议和代码静态审查，不是模型结果。没有运行新的真实模型、合成模型或账户，没有修改 B2、E0/R/R1 或旧证据。输入来自已有协议、结论和源码；B2 真实表现数字只按旧结论引用，未独立重算或重新图检。所有相关历史已见，为开发材料。

## 结论先行

支持一个很小的 B3：**63 观察背景、21 观察局部推进、明确滞回，再由急跌事件优先裁决的五档温度**。温度唯一含义是“当前量价证据对上行趋势的支持程度”，不是对称涨跌速度、上涨概率、交易质量或收益预测。它可直接供独立策略选择阈值；本轮不运行策略，不保证阈值越高收益越高。

不要再对 B2 的 P/R_ret/D 加权。P 是指定窗口的速度，R_ret 是当前腿已发生成果的剩余比例，D 是历史合格位移尚未收复的区域，三者分母、时间范围和含义不同。统一的方法应是明确谁能确认、谁能否决，以及何时不再具有“当前”身份，不能是一个轴替另一个轴平均掉反证。

背景方向不能保护已经确认的局部下降。局部正向也不能立即把下降背景抹掉。正常温度采用下方固定表；冲击发生当天可以直接 hot→freeze。freeze 作为最弱上行支持编码并不表示跌速比 cold 更大，也不预测未来会更差。

## 可操作的语义合同

1. **唯一输出定义。** `temperature∈{-2,-1,0,1,2}` 分别为 freeze/cold/neutral/warm/hot；越大只表示当前上行证据越完整。另给解释字段 `phase`、`reason` 和原始量价证据；它们不能反向改变温度定义。
2. **尺度必须外显。** 当前局部尺度为 21 个有效观察、背景为 63 个有效观察，5 观察只用于诊断。不能声称同时拥有日内灵敏性、季度稳定性和无延迟反转识别。持续四个月盘整最终 warm→neutral 是容许的，稳定不等于永远 hot。
3. **冲击具有优先级。** 足够大的向下实际位移在当日收盘产生 freeze；慢窗口正值不能抵消它。低量巨跌也必须有通道。
4. **恢复是可观察事件。** freeze 的结束须区分价格收复、下降证据接管、退出当前观察范围；后两者不许叫“已修复”。历史事实保留，当前裁决权有定义。
5. **允许跳级。** 不要求 cold 必须先经过 neutral/warm 才能 hot；不能采用仅精确 `1→2` 才触发的策略接口。算法只报状态、事件和变更原因。
6. **长向描述必须承认不对称。** 当前表对背景和局部证据分别单调，但价格反射后不要求温度取相反数：上行背景内的确认下跌会 cold；下降背景内的局部反弹最多 neutral。这是“上行支持”的定义，不是无方向偏好的物理温度。
7. **未知不同于中性。** 数据预热、来源断段、无效量价是未知，不能填 0。状态与账户持仓、买入价格、浮盈、E0 有效性无关。
8. **量实际参与证据建立。** 相同价格路径在相对量变化后，可以提前产生有量资格的 freeze；普通量仍可以通过真实价格收复解除。不能只改颜色或附标签。
9. **无经济单调性承诺。** warm/hot 不是买入许可，freeze/cold 不是卖单。阈值分组的未来收益、尾部机会和风险完全可能不单调，需要另行冻结的策略评价。

## 唯一候选核心机制

这是在未看 B3 输出前讨论确定的一组探索值，不是从黄金日期、最优收益或文献最优值导出的参数。最初审查建议离散量资格门槛；冻结前主 agent 选择下述连续参与缩放门槛，并采纳 mechanism 审查的有限 21 观察逐事件机制，替换早期单锚建议。本记录同步最后定案。没有运行候选后挑参数。若主协议采用别的值，应明确记录设计差异；本审查不运行参数比较。

令 `p_t=log(C_t/C_first)`、`r_t=p_t-p_(t-1)`，沿用 B2 的有效观察及 source segment 合同：

```
sigma_t = max(sqrt(mean(r[t-63:t]^2)), 1e-8)   # 不含今日
a_t     = V_t / median(V[t-21:t])
x_h     = sqrt(h) * beta_h / sigma_t           # h=21,63
beta_h  = OLS(p[t-h:t+1] 对 0..h 的斜率)
L_t     = hysteresis(x_21, L_(t-1))
B_t     = hysteresis(x_63, B_(t-1))
```

精确滞回：`x≥1` 返回 +1；`x≤−1` 返回 −1；否则，旧 +1 且 `x>0.5` 才保留 +1，旧 −1 且 `x<−0.5` 才保留 −1，余者为 0。±1 是进入门槛，±0.5 是退出门槛；不是收益调参。浮点比较容差须与数值精度分开，不得拿容差扩大语义区间。

正常温度由唯一表决定：

| 局部 L \ 背景 B | −1 | 0 | +1 |
|---|---:|---:|---:|
| −1 | cold −1 | cold −1 | cold −1 |
| 0 | cold −1 | neutral 0 | warm +1 |
| +1 | neutral 0 | warm +1 | hot +2 |

各格解释：局部确认下降优先；下降背景内暂停仍 cold；下降背景内反弹为 neutral/rebound；上行背景内局部中性为 warm/consolidation；局部上行但背景未定为 warm/emerging；两个尺度均上行为 hot/aligned。B 正、L 负不是“相互抵消后中性”，否则又会让大背景保护当前阴跌。

`x_h` 的原始速度、`100*h*beta_h`、真实端点涨跌必须一并保存。RMS 含有漂移，不是标准误；恒定微小慢涨也可能有高标准化推进。因此温度不能独自用于跨资产绝对机会排序。

### freeze 的建立和有限当前身份

```
q_t        = r_t / sigma_t
m_t        = clip(a_t, 1, 4)
q_eff_t    = q_t * sqrt(m_t)
shock_down = (q_eff_t <= -2)
```

这是一个量价证据规则：普通或低量需要 −2σ；双倍通常量需要 −sqrt(2)σ；四倍及以上通常量需要 −1σ。低量不减免实际跌幅，放量没有负位移不会触发，正向放量不自动 hot。这里“2 个日 RMS”是过去 63 收益 RMS 的 2 倍，不能误写成 2 日波动窗口。2 沿用已有研究中的探索分辨率；参与缩放和上限 4 是待否证假说，不能称统计显著性、尾部概率或校准风险线。

成交量虽然以乘数进入判据，但它实际改变 freeze 证据的创建与当前状态，不是只改变展示分数。其作用范围仍然有限：正常温度 B/L 和向上确认不受量影响，不能宣称解决了所有推进与恢复中的量价关系。

每个合格冲击独立记录 `birth=τ`、冲击前 `p0=p_(τ-1)`、出生 shock/activity/effective_shock、最低收盘及其路径、解除日期和原因。事件创建身份由当时输入冻结，不后续重算。事件只在当前 21 观察范围内存活；新 shock 不替换旧锚、不改变旧出生日期、不延长旧事件寿命。没有 `superseded_unrecovered` 这一最终出口。

每个有效观察日先逐个处理已经存在的事件，按以下顺序裁决：

1. `p_t≥p0`：该事件价格实际收复，归档 `price_recovered`。
2. `L_t=-1`：由确认的局部下降接管，归档 `downtrend_takeover`，不声称价格修复。
3. `t-τ≥21`：当前 21 跨度窗口已不再包含冲击前收盘，归档 `outside_current_scale`，不声称修复。
4. 否则保留该事件。

最后才检查并创建今天的 shock 事件。**任意事件仍活跃则输出 freeze；全部清空才使用正常温度。** 因而即使今天 L 已下降，今日新冲击仍会显示 freeze，不能被同日下降接管抹除。没有新事件且旧事件全被 L 接管时输出 cold；并非每个事件解除都能单独令总状态离开 freeze。

正常执行后活跃事件年龄在 0—20 有效观察之间，最多 21 条（每天至多一条）。无效行不构成新观察，也不延长或缩短以有效观察计的寿命。报告活跃数、最高待恢复锚、最老年龄及完整独立事件日志，不能只画最新事件后隐藏旧目标。

第 3 条是语义上必要的有限尺度边界，必须在计算前决定是否采纳。它不修改历史账本，而是明确“当前急性冲击”只代表当前 21 观察范围。若不愿采用此边界，就必须接受下面的永久冻结反例，不能在真实结果出来后临时加到某一日期。

### 为何只用“回 p0 或 L=-1”不足

分析反例：之前局部价格水平不变，较早 63 观察中的波动提供非零 sigma；通常量突然下移 2σ 后永久横盘。对 22 个收盘点中的单一阶跃，21 跨度 OLS 最大标准化斜率绝对值为：

```
sqrt(21) * (60.5 / 885.5) * 2 = 约 0.626
```

可以把历史非零波动放在未来 21 观察不会移出 RMS 窗口的位置，冲击只会增大分母，所以 L 不必触达 −1。价格又永远没有回到 p0。于是“只回 p0 或 L=-1”可能无限 freeze，虽然当前窗口已经完全平坦。这是无需运行模型即可成立的构造反例。

使用观察尺度退出时，21 观察后当前 L=0，正常表会按背景给 cold/neutral/warm，绝不会把历史区域写成收复；后续真实新上行有建立 hot 的路径，不再由数年前旧区域永久封锁。

## 必须主动保留的代价与否证条件

- **普通整理仍可能 cold。** 21 窗若确实出现超过门槛的下降，B 正也会 cold。这是解决“旧背景保护持续阴跌”的代价，不能为了黄金 2025 年 5—8 月不降档逐日补过滤器。
- **长期盘整会失去上行背景。** 63 窗旧推进移出以后，warm 可以变 neutral。若需求是无期限保留过去上行身份，应另命名结构属性，不能谎称温度仍表示当前推进。
- **真 V 可能延迟 hot。** L 已转正但 B 尚负时为 neutral；随后 B 中性变 warm、B 正变 hot。相同前缀的熊反弹和真 V 在分叉之前必须同状态。
- **RMS 冲击后会降低敏感度。** 本轮建议沿用 RMS 以保持清晰、少改一项机制；不能据此称稳健。固定反例要有一次巨跌后小幅连续阴跌、一次巨涨后细小反向推进，检查是否长期中性或过早回暖。若失败保留，不自动换 robust 分母救图。
- **高参与普通回撤可能 freeze。** a≥4 时仅 −1σ 即触发，会把部分高参与的一般波动判为急性破坏；是否过度敏感必须在固定反例中保留，不能称作已校准尾部冲击。a 在 1 与 4 的裁剪边界以及 q_eff=-2 的创建边界须明示；不能以绝对成交额替代相对量定义，也不能把低量视作无风险。
- **多事件解除不等于总状态解除。** 先跌 100→90，再跌 90→80，随后回 91，只收复第二笔；第一笔目标仍是 100，若未满足其他出口仍应 freeze。若第一笔已由 L 下行接管或超出范围，则明确记录该原因，不得报告“全部破坏已经修复”。新冲击不能让旧事件年龄归零。
- **不把阈值效用写进定义。** hot 比 warm 的未来收益更低、freeze 后立即反弹，均不自动推翻因果状态描述；反而是超大急跌仍 hot、稳定平坦永久 freeze、同前缀不同标签、没有价格变化却报告已收复，直接违反合同。

## 设计冻结前的有限验收清单

1. 枚举 B/L 九格和精确 ±1/±0.5 边界，验证正常表对 B 与 L 分别单调；不要求价格反射后温度对称。
2. hot 后同日通常量或低量 −2σ、双倍量 −sqrt(2)σ、四倍及更高量 −1σ 必须 freeze；高量正向冲击不能凭单日直接覆盖下降背景为 hot。
3. 同价不同量只改变明示有量资格支路，说明创建、存续和结束分别因何变化；普通量实际收复可解除。
4. 阶跃后横盘、连续阴跌、全额 V 修复、未回旧高但形成新上行、连续两次 shock，分别检查三个归档原因，不混同修复；新锚不能替换旧锚或为其续期，部分事件解除后只要还有其他活跃事件就保持 freeze。
5. 同前缀分叉路径在分叉前完全相同；旧事件及端点不能被未来确认重绘。
6. 相同原始量价做价格/量单位缩放，状态、事件时点保持一致；source segment 重启及缺失给未知。
7. 黄金两窗只是固定诊断例；全部固定正反例一并复查，不以黄金达成指定颜色作为通过，也不报告未经定义的五类准确率。
