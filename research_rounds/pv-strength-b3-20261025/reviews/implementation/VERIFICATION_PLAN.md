## 计算前须确定的合同

1. 所有对外字段的定义、单位、合法区间、未知掩码；warmup 结束的准确有效观察下标；温度状态与内部背景/证据字段的关系。
2. 有效行标记应为布尔且无 NA，避免字符串/整数标记被 `.loc` 当标签或其他真值；日期索引类型、NaT、时区口径及空输入应有明确处理。日期必须唯一递增，segment 不能缺失或跨别段后复现。
3. 成交量的创建、维持、否决或恢复作用，去量对照改变的唯一环节；不存在把量只记为展示标签却认领量价机制的情况。
4. 边界采用严格还是包容比较，机器误差带是否统一；分母下界、完全静止的精确零值语义。单位等价不可依赖偶然的二进制尾差。
5. 更新顺序：当日先消费哪组旧状态、冲击与慢性趋势同日冲突的优先级、恢复后同日能否重新建证据、状态年龄按何种时钟推进。

## 有限技术核验

| 组 | 核验与可核对产物 |
|---|---|
| 输入有效性 | 重复/倒序日期、NaT或非日期索引、缺字段、segment缺失/复现、非布尔/NA valid 标记、有效行 NaN/Inf/零/负价量应按合同明确拒绝。全部无效、空输入、短预热应保留行并给明确未知；不静默填零。 |
| 无效行与分段 | 同一有效子序列插入无效行后有效时点值与事件身份不变；无效行全未知且不产生事件。新segment只读本段，重做预热；旧未决状态归档不记为修复。检查相邻全无效段的处理。 |
| 独立公式 | 参考实现不导入主体计算函数，用独立 `math.fsum`/显式状态字典按协议复算窗口、量基准、状态门槛、冲击与恢复字段；逐列比较数值和NaN掩码，离散状态/事件日期精确比较。不得复制主体循环后称独立复算。 |
| 因果前缀 | 将真实输入物理截成文件、重新读取运行，再与完整输出的同一前缀逐值和逐事件比较。合成分岔共前缀先核对一致；只切完整结果不算前缀测试。末态归档事件仅在源断开当日可见，不能出现在断开前前缀。 |
| 等价单位 | 固定价格乘17、量乘10000；日期、温度、事件及未知掩码精确相同，价格坐标等比缩放，无量纲量在冻结容差内一致。原始幅度和价格单位不能混用。只跑冻结有限变换，不扫缩放系数。 |
| 状态机边界 | 首次预热、严格/包容门槛等号及其相邻机器值、同日冲击/慢性变冷/恢复竞争、状态继承、周期重置、方向反射、事件身份不复活、完全静止与单根冲击后静止，逐项按冻结合同建立预期。 |
| 量反事实 | 同价量单位变化应等价；同价冲击低量/高量仅允许合同指定的证据差分。低量不能掩盖已发生的价格急跌；普通量实际收复不能被高量准入门槛误挡。 |
| 身份保留 | 在新输出前保存本轮协议/代码、冻结输入、旧 B1/B2 与 E0/R/R1登记身份，结束时按sha256核对。原失败、数值修订、语义失败分开记录。 |

## 状态语义的核验接口

接收 adversarial 角色的有限路径清单，复用其路径而不另起搜索。实现核验仅核对这些可审计量：freeze 的当日证据、cold 首次出现与此前可见的累计位移、恢复真正用到的价格/量证据、静止和箱体末段的状态与原因。明确响应上限 L 后，持续阴跌在 L 内未转冷属于语义失败，不能用仍等证据无限延期。急跌后静止若仅因时间或波动分母变大而恢复，须判明是否违背恢复定义。

单位/因果/协议一致性为硬不变量。合成语义及真实历史中的弱点会完整保留；不据输出继续改参数，不用技术通过认领准确率、未来胜率、经济增量或账户准入。
