# B3 有限合成路径验收：建议合同

2026-10-25。仅设计；未生成路径、未运行候选、没有通过数字。使用目的为推翻或限制模型解释，不是发现最优阈值。主协议可在计算前选择是否采用；采用范围与未采用项须明确记录，不能把本建议全体写成已执行。

## 范围与生成

保留 B2 原 17 路径的原输入身份与所有失败。只加以下 7 条确定性路径，共 24 条基础路径。既有路径不得为了更易通过改波幅、周期、量或起点。

新增路径共同基准：对数价格 x，初价 100；共同预热 `W=[+0.002,-0.002]×60`（120 个收益）；`U=[+0.003]×70`。除另述外成交量恒 100。价格 `C_t=100×exp(sum(r_0…r_t))`，有效观察时钟，整段有效，无隐藏暖启动。主体若最少预热超过 120，必须在计算前同步延长 W 并记录，不能结果后补长。

模型如只使用收盘与量，直接保留该输入边界。若使用 OHLC，统一 `O_t=C_(t-1)`，`H_t=max(O_t,C_t)`，`L_t=min(O_t,C_t)`；不添加虚构盘中先后，不按不同场景切换造数方式。首行开盘 100。

| 新路径 | W 后路径 | 主要可证伪要求 |
|---|---|---|
| N01 micro_box | `x增量水平=0.00001×sin(2πj/10), j=1…160`；收益取该水平的一阶差分 | 约 0.002 log 百分点全振幅的来回运动不可仅因 sigma 小就不断宣称最强上下趋势。短速度可变号，原始幅度必须明确；若统一强度没有绝对材料性含义，则记录该限制，不能认领已解决低波幅强弱 |
| N02 micro_rise | 整条 `W+[+0.001]×120` 的所有对数收益乘 0.01 | 当前方向为正，原始总推进 0.12 log 百分点；不能因低幅将真实正方向反写负。与 N03 同形，检验原始幅度与标准化持续性是否混淆 |
| N03 ordinary_rise | `W+[+0.001]×120` | 当前方向为正，新增总推进 12 log 百分点。与 N02 的原始速度/幅度比应为 100；标准化值可同，不可据同分认领相同绝对推进 |
| N04 rise_then_static | `U+[0]×120` | 当前推进在声明响应尺度内趋零，末段状态稳定；上行背景可保留。与旧 `constant` 区分曾有结构和从无结构，不能把静止长期称为仍高速上行 |
| N05 slow_decline | `U+[-0.001]×120` | 旧上涨成果仍有部分保留，但持续阴跌必须在冻结响应上限内进入 cold。负方向不能因小幅、旧热状态或量普通而失真。记录首次 cold 日期和当时累计位移，不以最终收益打分 |
| N06 shock_then_static | `U+[-0.12]+[0]×120`；冲击根量 1，其余 100 | 若冲击前为 hot，冲击当日应为 freeze/明确破坏；低量不能免除损伤。以后没有任何向上修复，不得仅靠时间、sigma 增大或旧漂移继续而重返 hot/宣称修复 |
| N07 shock_then_recovery | `U+[-0.12]+[+0.03]×4+[0]×116`；冲击根量 1，其余 100 | 与 N06 到冲击日全部输出相同；之后普通量实际收复可改变恢复证据。四次收复累计正好弥补 log 跌幅，不能仍宣称价格完全未收复；是否立即 hot 取决于冻结的趋势定义，不强迫恢复即成熟 |

N05 与 N06 的下行总位移相同，时间分布不同。终点位置不应抹平“持续阴跌”和“急性冲击后静止”的区别。N06/N07 的未来分支名字不进入模型，冲击日不能预知恢复。

## 原 17 路径中必须逐项保留的验收

| 旧路径 | 必须回答的问题 |
|---|---|
| `flat_box`、`consolidation` | 普通整理和窄箱体是否稳定；有没有把满保留小腿当最强趋势；不可只报较容易的整理正例 |
| `fast_start`、`slow_rise`、`mirror_fast_start` | 快慢与方向是否可解释；慢涨标准化更高不能被说成原始推进更快 |
| `true_weakening` | 连续下行何时 cold；旧结构保留不能阻止当前状态兑现。必须报告观察延迟及同期原始位移 |
| `lowvol_selloff`、`single_lowvol_shock`、`mirror_lowvol_selloff` | 低量损伤、镜像方向、急性反证是否同日可见；不能只依赖高量记忆 |
| `V_continues`、`rebound_fails`、`bear_rebound` | 同前缀完全一致；分岔后实际新增证据何时使状态分化；真 V 的确认延迟与误判反弹代价并列 |
| `one_pulse` | 首根不能预知全回吐；回吐完成后不能永远高热；历史负区域不能永远冒充当前持续下行 |
| `same_end_recovery`、`same_end_retracement` | 同终点不同顺序的当前冲击方向须显露；不强求每个窗口斜率都按最后一根排序 |
| `debt_partial_revisit` | 实际部分收复、结清片段不复活、后来新事件与旧事件身份分别记录 |
| `constant` | 当前零推进、无冲击、结构未建立/未知；有限分母必须不制造无限强度 |

## 固定技术变换，不扩成搜索

1. 全 24 条各做一次合并单位变换：价格乘 17、量乘 10000。类别、事件日期、未知掩码须完全一致；价格锚点按单位缩放，非价格数值容差预先冻结。
2. 只在 N01、N03、N05、N06 各做一次全对数路径反射 `x'_t=2x_0-x_t`；量不变。原始方向反号，绝对运动相同。温度标签按有向合同映射，不要求 `hot/cold/freeze` 字符串机械相同。
3. 只在 N01 箱体段加两次固定相反微扰 `±10^-7×(-1)^t`，重建 OHLC。检查每次状态变化是否有已声明证据边界；若微扰跨边界，单列“边界敏感”，不得写成无关扰动不变性通过。稳定性不能靠浮点误差恰好少触发取得。
4. 只在 N06 与 N07 各复制一次冲击根量 400（原版量 1）。价格完全相同。方向和急跌发生不可不同；预先指定量参与证据中允许/要求变化的字段。恢复根保持普通量 100。

基础 24 条、上述 32 条变换，合计最多 56 个完整合成输入。前缀重放是因果核验，不算新增场景或候选。无需振幅网格、阈值扫描或随机种子筛选。

## 验收输出与冻结项

主体计算前必须声明：`hot/cold/freeze/中性` 的语义、材料性尺度、当前状态响应上限 L、结构背景与当前状态的冲突处理、冲击恢复条件、量参与字段与预期差分、未知规则、数值容差。若没有 L，不能仅以“还在等证据”无限延期 `slow_decline`；若 L 过长使整个新增 120 观察都无法响应，应判本轮没有回答当前阴跌问题。

每条只报告以下读数，禁止合成单一优劣分：

- 原始方向/位移与幅度、标准化值、状态及原因、结构身份、量证据、未知掩码。
- 冲击首根响应；首次 cold/freeze/恢复的观察延迟和发生前已见位移。
- 箱体/静止最后一个完整声明尺度内的状态种类与变换事件清单；只查证据一致性，不最小化次数。
- N02/N03 的单位分解、N05/N06 的同位移异时序比较、N06/N07 共前缀恒等。
- 旧 V/反弹共同前缀所有状态与记忆恒等；物理截断再读后计算，不能只切完整输出伪装因果检查。
- 全部失败、定义不足与允许取舍，不删除输出、不由后来的走势改当前标签。

硬不变量失败直接阻断相应解释。行为项通过仅限这组确定性反事实，不能变成真实市场误报率、五类准确率、未来胜率或账户准入。语义失败不自动重开公式；保持一个候选及所有旧基线，转入固定七资产原图复查时仍称已见开发历史。
