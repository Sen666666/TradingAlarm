# B3 拟定证据状态机的机制审查

2026-10-25。依据主 agent 发来的计算前方案审查，正式 PROTOCOL 当时尚未落盘。本文件不修改候选、不另冻候选、不计算真实新输出；账户0，旧算法不改。

## 裁决

可作为本轮唯一有限候选进入合成语义检验，不能事前认领“盘整稳定、所有阴跌 cold、急跌后恢复合理”已经解决。其准确名称是上行证据状态机：同一 OLS 推进估计在两个固定尺度上的方向证据，加上有期限的急跌否决证据。它不是单一潜在漂移估计器，也不是已校准概率或假设检验。

已有公式足以解释量如何改变最终判断：同一价格、同一两尺度方向，高量中等下跌可以创建 freeze，而普通量相同下跌不创建；低量大跌仍有否决通道。这满足“量有实际判断作用”的机制最低要求，但尚不证明这一假设正确或有经济增量。量只进入急跌证据，不应宣传为所有日常趋势证据均量价一体。

## 审查对象

拟定背景 B 为63观察 OLS 标准化推进、局部 L 为21观察 OLS 标准化推进，使用 enter |x|>=1、exit <=0.5 的方向滞回。L 下行进入 cold，不受 B 上行保护；L 上行、B 下行为 neutral 反弹；L 中性、B 上行为 warm 整理；两向上为 hot。其他映射以正式协议为准。

即时下跌证据为：

    q_t = r_t / lag63_RMS_t
    m_t = clip(V_t / median(V_prior21), 1, 4)
    q_eff_t = q_t * sqrt(m_t)
    q_eff_t <= -2  ->  创建 freeze

当天 freeze 优先。后续以价格实收事件前收盘、L 下行接管、或21有效观察超出本尺度三种原因归档。

## 成交量假说

这是“参与更高的负向位移较早否决上行证据”的明确假说，而非从公开论文推导的定理。sqrt(m) 不是可直接称为标准误或统计置信度的系数。

纯算术反事实如下，未执行任何候选历史输出：

- q=-1.5、m=1时不创建；相同价格、m=2时 q_eff约-2.12，创建 freeze。量改变证据建立与最终状态。
- q=-3时，不论低量还是普通量均创建，因为 m 下限为1。缩量不能消除已发生的大跌。
- q=-0.8，即使 m=4仍为-1.6，不创建。放量本身不会创造下跌证据。
- m=4时的触发价格门槛是-1个旧 RMS；普通量为-2个。这意味着高量的普通幅度下跌可能被标 freeze，须接受它既可能更及时、也可能更误报。

上限4与下限1有真实语义：量只放大负向证据、最多放大2倍，从不减免。只用于负向时，模型有意围绕上行证据构建，不能宣称价格镜像下温度必严格冷热对称。

AU0 的主连换月、成交量口径变化可能触发 m；原输入已披露换月未知，B3 不能把这一放大自动解释为更广泛市场认可。股票公司行为、基金拆分后的量坐标仍须沿用原已验证输入，不能事后换原始量让案例更好。

## 两尺度与滞回的限制

1. 滞回能防止临界数值小抖动直接反复翻态，不保证箱体始终 neutral。箱体中较长单向腿可以越过±1，随后仍会切换；这正是应保留的失败样本。
2. L 只有达到-1才建立下行。真实持续阴跌但 L 长期在(-1,0)时，可以仍为 neutral；若 B 仍上行，则会输出 warm。尤其急跌提高后续 RMS 后，小幅持续下降更可能被标准化尺度遮蔽。不能预先写“阴跌都会 cold”。
3. “L 下行优先”使局部明确下跌不能被旧背景正向覆盖，是对 B2 慢轴误读的具体改善；代价是上行内足够大的正常回撤也可 cold。cold 是当前证据描述，不是卖出。
4. B 下行、L 上行映射 neutral 能保留反弹语义，但真 V 在 B 转正前也不能 hot。要保留共同前缀一致与确认迟的成本，不能用后来继续涨判定当时模型本应知道是真 V。
5. 标准化推进在极低噪声下可能很大。温度为方向证据组合即可，不应据此把微小绝对涨幅称为大机会；原始斜率、21/63尺度幅度应可查。

## freeze 生命周期需写成精确合同

这三种出口不是同义词：

- 实收：价格确实回到该事件前收盘，只能说明该笔位移收复。
- L 下行接管：急性否决已转成持续下行描述，属于 cold 接替 freeze；不是修复。
- 超出21有效观察：旧事件退出本候选的急性记忆范围；不是价格收复，也不是新上行成立。

因此，后两者不得统一写成 recovered 或“风险解除”。尤其到期时价格仍低于事件前收盘，温度可能依映射回到 warm 或其他态；图上必须同时显示 expiry 原因，否则会把纯到期暖化误认成真实恢复。

不把事件前收盘永远作为所有未来上升的硬门槛，是比 B2 无限历史债务更可解释的尺度选择。21仍只是本轮尺度假设，没有资料证明是最优期限。

多次冲击需要消除歧义。若采用每事件一条记录，每条保存事件日、当时前收盘 target、冻结输入和有效年龄，分别实收或到期，L 下行统一转交，当前只要仍有活动事件就 freeze，即可避免两类隐藏选择：新冲击覆盖旧 target 而悄悄降低恢复价；新冲击重置计龄却保留很旧 target 而把旧事件无限续命。活动记录的尺度最多21个有效观察，无需无限账本。

若正式协议选择单条记录，也可实现，但必须明示 target 与 age 如何更新，不能等看图后决定。当天新事件应始终先展示 freeze；不能因为同日 L 下行或旧事件到期立即抹掉新冲击。下一有效观察再按约定转交/清理。

## 计算前应锁定的技术边界

- enter/exit等号、上行直跳下行的优先次序、从未知开始的条件。
- 21/63究竟为收益跨度还是价格点数；OLS、RMS、量 median 均使用严格规定的有效观察。
- sigma 不含今日；冻住事件创建时 q、m、q_eff 和恢复 target，不能后续重算改变历史资格。
- 预热、无效价量、segment断开时输出与记忆；缺失日不冒充新证据，不按日历自动增加有效年龄。
- 多事件 target、age和归档原因；freeze当日优先、后续L接管的明确日期。
- 量单位整体缩放不改变m与事件，价格单位缩放不改变log收益；物理前缀不得重绘。

## 进入合成后的否证，不作修订借口

保留窄箱体、慢阴跌、长涨后高/普/低量急跌、急跌后横盘未收复、缓跌未收复、普通量V恢复、弱反弹再跌，以及重复急跌跨21观察边界。特别检查“到期未收复且L尚未到-1”的路径是否自动变warm。若出现，应如实结论为尺度/门槛局限，不事后增加例外或下调阈值。

本评审支持候选进入有限技术/图检，不支持已成熟或可替代E0的结论；强度/状态变化仍不自动映射卖出。
