## 可采用的开发历史时钟

以下是本研究明确选择的使用规则，需在随后策略协议中冻结；不是从缺失公告时间“推算”出来的历史事实。

1. **名单字段沿有效日运行。** 逐通道使用已核对官方事件的`effective_date`更新名单；保留来源日期、代码、事件及来源哈希。SSE链仍以268推导基线及源覆盖完整为条件，SZ链保留二手托管初始附件的来源等级。两者可用于历史技术与开发检验，无需再要求为每个事件取得原始公告。
2. **新增资格采用延迟。** 某股票在D日正式调入，D日收盘后才能利用这项新增资格参与筛选；最早在下一真实、允许的南向交易时点成交。即使后来取得D之前的公告，本轮也不提前到公告日或D日开盘优化效果。用`research_usable_after = effective_session_close`等派生政策字段表示，不能覆盖`known_at`。
3. **调出在执行日立即拦截新增买入。** D日已被调出的股票，即使D−1生成待买单，也不得在D日新增买入或加仓。成交前应按实际生效状态复核所用通道；不能把“新增资格延迟一天”机械套到调出而错误延长买入权限。这是执行合法性闸门，不是提前向算法泄露未来事件。D之前不预先关闭资格。
4. **已有持仓仍由冻结策略管理。** 在已证实仍上市且规则允许的范围内，调出后可继续卖出，算法的结构退出照常；不因为调出而加锁盈、缩紧退出或强平。停牌、终止上市、派生证券和特殊限制另由执行资料处理。2024之前的卖出规则若未独立验证，只能标研究执行假设，不能声称本次已逐年认证。
5. **执行时再次确认资格。** 若调入后尚未成交便调出，取消待买；若一个通道调出而另一个通道仍允许，须由逐通道状态和可路由资格决定，不能单看一个通道。两通道代码集合并集不替代身份、类型与交易限制检查。
6. **未来记录不提前使用。** 02555的2026-10-23调出保留；截至10-22状态不受影响。账户截止2026-10-20时，10-21和10-23事件均不得进入此前筛选。规则/事件作为资料可保存，计算按有效日期截断。
7. **股票与ETF分开。** 已确认ETF不进入本轮股票主池。`SECURITY_TYPE='-'`的历史事件仍留在名单链，不能先删掉破坏连续性；具体证券在身份/类别未解决时不新增买入，缺失计入覆盖报告，不能静默当作股票。

以实际公告为例：02245于10-21生效调入，其新增名单资格最早用于10-21收盘的研究信号，并在下一允许交易时点执行；02922于10-21调出，10-21任何待买/加仓须被执行闸门拒绝。02922带“旧股”字样，不据名称直接并入其他代码，需公司行为/身份资料连接。这里没有假定10-22必然可成交。

## 字段准入裁决

| 字段/用途 | 本次裁决 |
|---|---|
| 官方调整代码、方向、生效日期、逐通道条件名单状态 | **可用于开发历史**；保留来源和完整性假设，采取上述保守时钟 |
| 生效日收盘后才使用新增资格 | **可冻结为研究政策**；它是派生使用规则，不是实际历史`known_at` |
| 2026-10-20实际公告日期 | 可保留`announcement_date=2026-10-20`及日精度；不能擅自补小时、分钟、收盘前/后 |
| 精确`announced_at`、`known_at`，所有历史事件可知性已认证 | **不可准入**；保持空值/未知，不再为此逐事件爬取 |
| 数据库`FILE_DATE`、`UPDATE_DATE` | 仅作来源更新日期；不可当事件当时公布时间 |
| `TRADE_FLAG='1'`的可买/可卖映射 | **不可准入**；现有源码没有字段定义，继续保留原值 |
| 2024版具体规则用于2024-06-14之前 | **不可作为已验证事实准入**；历史源有效日期可以使用，但旧时期细则仍分开标记 |
| 当前类型/市值/成员向历史回填 | **不可准入** |
| 上述来源全部通过即等于可执行全池账户 | **不成立**；市值、身份、同源行业和执行资料仍是独立条件 |

新增机器可读裁决见[field-admission.json](field-admission.json)。此前`sse-chain-v1`的`eligible_for_account_input=False`是当时证据阶段的冻结结果，本次不重写旧文件；本报告在字段层面允许开发使用，不把整体账户闸门改成true。

## 关闭本项来源调查

南向来源能力验证已得到足够的官方有效日期证据，应停止扩大调查，进入数据连接与研究实现。具体保留而**不在本批继续追查**的缺口为：SSE早期独立完整名单锚点、SZ初始附件官方原托管认证、逐事件精确公告时间、历史未知品种与临时代码、旧规则的逐版全文、完整逐日特殊买卖限制。前两项作为明确来源等级/完整性假设，不能悄悄转成已认证；未知身份、类型与执行条件在后续连接时逐行暴露，不能靠再爬全部公告掩盖。

历史公司总市值、A/H公司去重、南向交易日历、停牌和公司行为仍需各自现有数据桥接。这些不是理由把南向名单调查重新开成第三批，也不是本报告替它们出具通过证明。
