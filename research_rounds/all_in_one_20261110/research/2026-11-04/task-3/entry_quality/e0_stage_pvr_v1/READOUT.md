## 原源码的极值时钟

正式模型仍是[stock_signal.py](../selection_qualification_closeout_v1/eligibility_source/stock_signal.py)，其中event_frame_numeric以joint=True、event_exit=False调用。原事件核[numeric.py:58](/Users/bytedance/Documents/ChatGPT/money/research_rounds/pv-participation-response-20261020/code/numeric.py:58)按收盘和量的有效观察顺序运行。

设当前方向d∈{−1,+1}，该方向发展极值在观察e，r_t=ln(C_t/C_{t−1})。原确认计算为：

```
sigma_e = max(sqrt(sum(r_i^2, i=e−63..e−1)/63), 1e−8)
Vbase_e = median(V_i, i=e−21..e−1)
A_e,t = clip(sqrt(mean(V_i, i=e+1..t)/Vbase_e), 0.5, 2)
Z_e,t = (−d) * ln(C_t/C_e) * A_e,t / (sqrt(5)*sigma_e)
Z_e,t >= 1  => event_t = −d，确认pivot_price=C_e
```

实际比较和log_ratio沿用原binary64边界规则，不另用金融价格容差。+1事件确认谷，−1确认峰。`confirmed_pivot_date`写的是e发生日；确认日是t所在输出行。原码110–114只在t写确认结果，122把发展极值重置为t；不能从e起回填，也不存在单bar多次反转循环。这里的日期只表示收盘观察完成后可计算，不认证真实发布时间或日内成交。

E0实际政策在[policy.py:99](/Users/bytedance/Documents/ChatGPT/money/research_rounds/pv-strength-b5-20261025/code/policy.py:99)先判断旧floor：active且C_t<=F_old则退出；本行若exited，+1也不重新入场。仍active时+1令F_t=higher(F_old,pivot_low)，否则未同日退出才激活。原numeric内部target不是所有输入下的E0政策替身：缺量但有效价格仍可能触发E0价格保护。新实现单独重放这个轻量E0政策，未借numeric.target代替。

旧19字段仅存单日numeric_event/leg_direction、E0/I投影等，缺峰价、发生日、确认日与age，故必须事件重放。源码取证见[independent_review](independent_review/READOUT.md)。

## 冻结的阶段与排名公式

完整合同在[FREEZE.json](FREEZE.json)，实现为[research.py](research.py)。每只股票从本地可得原起点开始；每个目标日期物理截断输入<=该日。先检查原E0旧floor，再确认峰谷，最后更新研究阶段。原I/i_buy资格和保护线不变。

1. −1事件在本行确认局部峰H并进入RETRACED，撤销此前BREAKOUT标签；这只是确认下行反转后的排名降级，不等于I破位，也不新发卖单。
2. +1事件且E0仍有效，进入START；冻结本行已经知道的最近确认峰H，保存峰发生日与确认日。无历史峰时标START_NO_REFERENCE，仍在START队列，不伪造峰。
3. 这次启动本行或以后收盘严格越过冻结H，进入BREAKOUT。该标签表示“这次启动后曾收复H”，锁存至新的−1或原E0失效；并非保证之后每个收盘仍高于H。本组三日期没有锁存后又跌回H下的BREAKOUT，但逻辑允许此情况。
4. 原floor失效优先，阶段BROKEN/INACTIVE；原i_buy成员若意外出现这些状态会阻断排序、先查接口，而非悄悄过滤。本次所有已知原i_buy均属于上述三种有效阶段。

研究优先级p(BREAKOUT)=0、p(START)=1、p(RETRACED)=2。原PVR分值不变，阶段内仍按原分值降序、sid升序破同分：

```
R_i = 1 + count(j:
    p_j < p_i
    or [p_j == p_i and (PVR_j > PVR_i
        or [PVR_j == PVR_i and sid_j < sid_i])])
```

没有拟合系数、按年份设阈值或反转原PVR。未知PVR仍在完整母体中单列、不造最差排名。所谓“母体全保留”**不能保护START免遭有限名额挤出**：BREAKOUT人数足够时，前20/100会完全没有START。这是本候选的经济代价，不能用“没有硬资格门”掩盖。

相对PVR新增的描述是“确认极值的先后关系与是否曾收复此前峰”，它仍来自相同价格/量，不能预设为独立信息。尤其最近局部峰可能是更大下跌中的较低峰；收复它不保证跨越更大尺度阻力，更不能证明正期望。

## 历史起点、日序缓存与下一步成本边界

本源不是统一2014起点。原母体中可见2014以前价格的数量是2022的92/177、924的1226/2313、2026的277/779；其余本地起点较晚，可能是上市较晚也可能截断，未认证。三组最早可见分别为1996-10-29、1995-04-06、1996-12-18。START无峰参考2/0/0只，不能凭热身够63日就认证此前所有关键峰或完整上市历史。旧峰也可能跨E0 epoch遗留，本候选明确保留其已知身份与age，没有以结果给峰设保质期；三个日期可见参考最大age分别79/110/91有效观察。

已有canonical共15,739,264行，2022以后5,424,843行、1054个源日期，最晚2026-05-15。没有同源6/30或2026全年覆盖。它仍是5517本地观察序列，239退市档案另列，历史ST/停牌/限价/行业/上市身份、公司行为完整性及真实available_at未认证，当前qfq版本非PIT。行情缺行不自动等于停牌，复权源变更可能改变历史状态和边界事件。

可行的最小提速是每只股票只顺序跑一次**原完整可得前缀**，保存所需历史state行和确认事件日期，再按日期截取候选，不按1054天反复从头跑。源码中的rolling均向后，sigma/活动确认在当前行只读已知观察；但首次仍需做完整函数的历史前缀一致性检查，不能把terminal ledger outcome/attrs回填到过去。原全函数已保存成本约1.497–1.541 ms/输入行，按12worker理想外推一次全源约32.7–33.7分钟；含落盘预留35–45分钟仅为估计，未执行。逐日独立全前缀重复约397–598小时，也仅是估计。原PVR已有矢量7日导出35秒的收据，尚不是逐日缓存。

本次事件核55.71秒的实测表明结构注释本身不需要每日期30分钟；它不能替代全日新母体所需原G1/I。真逐日增量还缺B4/G1完整递归状态的持久化与恢复契约，不能仅保最近63日就续跑E0：发展极值、旧floor、epoch、pending及此前确认峰都可能更老。缓存至少绑定symbol、原起点/mask/segment、源码/参数、输入前缀内容hash、公司行为/复权版本与确认时钟；复权修改旧历史时须作废受影响股票缓存，不能盲目append。

本次不启动35–45分钟完整跨日生成。成本证据与未实测项见[performance_review](performance_review/)，实现与排序独审另见[independent_review/implemented_review](independent_review/implemented_review/)。当前候选先按上述反例停止晋升，不根据三个已消费日期调阶段优先级或新增条件硬救。
