# V3的B退化与一个未采用的振幅恢复假说

本线只读V3与做纸面推导。没有替代信号运行、参数扫描、账户、订单或收益。以下振幅式不是对已冻结V3的暗改，也不是已证优于V3的建议。

## 1. B确实包含于A，通常是严格子集

设最近负event在确认收盘D_k发布峰H_k，恢复ref `R=H_k`。下一负event之前，原事件交替；若出现下一正event确认L_(k+1)，其相邻前低为L_k，两低间唯一已确认高只能是H_k。因此：

```text
H12 = H_k = R
A = hold_active ∧ up_after_R ∧ C>R
B = hold_active ∧ up_after_R ∧ (L_(k+1)>L_k) ∧ C>H12
所以 B = A ∧ HL ⇒ A
```

未知也不能被用来造B真而A未知：B真意味着相邻高已知、此前负event已知，因此R已知。若输出出现B真/A不真，应先查事件顺序、跨source或reference实现，不应称新独立路径。

允许深V时可有`L_(k+1)<=L_k`而新up后C>R，A真/B假，所以通常是严格子集。若某个未破支撑的局部子区间所有新低都抬高，B与A在该子区间可能恰好相等；这仍不提供独立恢复作用。若保留旧V2的远端max门而不让R等于每个新down峰，结论可改变，但那已不是当前V3。

B可以保留为HL解释标签和支撑来源说明，不能继续宣称它让V3绕过峰恢复门。

## 2. Sea当前事实不支持直接诊断“正常回调都长期锁死”

已知原事件事实：9/27 down峰6.34，9/30新up C6.67即越；10/10 down峰8.07，10/11新up C8.34即越。它们很快恢复，不能拿来证明长时间压制。

11/4 down峰28.20之后则不同：11/20新up C23.96未收复；11/25又down、ref改为25.00；截至11/27未恢复。这个较长退权必须保留，不能只展示前两次迅速恢复，也不能仅凭日后走势称其为“误降级”。

父线程固定五点原事实还直接反驳单用`D/U`分好坏：盈新1/17 `D/U≈0.079755`，Sea9/27约0.079034，几乎相同；Sea11/4约0.160456反而小于10/10约0.218683，但前者确认收盘已较峰跌约19.0%、后者约6.1%。这里`D=ln(H/C_down)`只是当时已见回撤，不是已经确认的完整下行摆动。

## 3. 一个可计算的替代：保留下行撤权，只给浅且尺度内的已确认回调提前恢复

初始假说：每个down仍先照V3撤成熟新增、保原持有支撑；不在down当日预言回调结束。只在**下一真实up确认低点L_new**时，再判断这个已经完成的回调是否足够浅，可不等旧峰收复。这样不用未来低点回填down日，也不取消用户要求的“先新up”。

在down发布H时，冻结其前一已确认低点L_prev、同source的：

```text
U = ln(H/L_prev)                  # 已确认上一上行摆动，必须U>0
σ_H = 原E0在H发生点前63事件有效收益的RMS，按原源/原clock重建并冻结

等下一up发布L_new后才有：
d* = ln(H/L_new)                  # 已确认整个回调，不用ln(H/C_up)冒充
S = max(2d*/U, d*/(sqrt(5)·σ_H))

AMP_base = L_new>L_prev ∧ S<=1 ∧ 同段完整数据 ∧ 原支撑未破
I_expand_alt = V3_A OR (hold_active ∧ up_after_R ∧ AMP_base)
```

AMP_base只在该up确认CLOSE后可用，记录低点ID、峰ID、σ的观察截止与恢复周期；不是提前在低点发生日授权。恢复后保持到下一down或原支撑破坏，该周期的AMP_base随之清除，不回用旧证书。价格仍按原支撑处理，不新增卖出线、仓位、次数或费用规则。

这是一个**新的振幅恢复通路**，不能仍叫原B或偷偷换H12以掩盖B退化。AMP通路允许C仍低于旧峰，因此A跌回峰下不应连带抹AMP；它有自己的已确认浅回调基础和原支撑／新down失效条件。

先验理由：`d*<=U/2`对应低点仍在H与L_prev的几何中点上方；`d*<=sqrt5·σ_H`对应不超过一个原E0的未量调制价格确认距离。取两者更严者，不把上升振幅大就当任意百分比跌幅都轻。1/2是明确待检几何假说，sqrt5/63来自原事件尺度；**不是统计置信水平、最优参数或经济损失界**。σ是原E0 RMS，绝不能拿CP的MAD、current/next_scale替换；分母缺失／不可比／非正时AMP未知，不补ε。

该式在查看各案σ与后续恢复结果前固定。当前不计算它在样本上的命中，不因为盈新或Sea某点不合意更改系数。

## 4. 必须正反并列的冲突

- **可能帮助的前缀**：趋势中已确认的小幅HL回调，下一up已成立但尚未回到旧峰；AMP可能更早恢复。两次Sea已知短回调本来就快速回峰，并不能提供这种增益证据。
- **仍可能放行盈新**：1/17当前回吐占比与Sea9/27几乎相同；若1/20新up确认的实际L_new也浅、且落在峰前RMS尺度内，AMP会恢复，1/21新增仍可能被允许。该式不使用未来失败标签，不能保证专门拦住盈新。两者在已用特征上相同，任何确定公式都应同判，不能事后换阈值只救其中一个。
- **仍可能放行大百分比回撤**：历史波动本身很高时，一原尺度可以很宽；大上行腿又使d*/U变小。合并尺度比单独D/U多一个约束，但不是19%等绝对跌幅的安全保证。
- **也可能误挡真恢复**：历史极静、U很短或随后波动扩大时，真实正常回调可能超尺度。加量调制也不是免费修复：原高量会让小价格反转更早确认，低量会让较大反转才确认，不能把事件强度直接当趋势质量。
- **不能证明区分未来路径**：同样的H/L_prev/L_new/σ及新up前缀，可以随后真延续，也可以立即失败。AMP最多改变成熟恢复时点，不产生未来赢家识别能力。

因此当前先保主V3与全部真实恢复时长；振幅方案只是一条明确可证伪、尚未采用的纸面替代。不能因两个正常回调讲出“长期冻结”，也不能忽略11/4之后少许可与避免弱恢复之间的真实取舍。
