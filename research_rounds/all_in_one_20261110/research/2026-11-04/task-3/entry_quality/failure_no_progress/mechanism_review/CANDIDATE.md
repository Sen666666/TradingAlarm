# 连续两次未进展失败后，暂减同股新增量：唯一候选

2026-11-04；设计与源码近邻审查。此次不算绩效、不做静态收益、不重算信号、不接账户或产品。旧“首笔统一CORE缩量/入场后等待”版本维持停止，不通过换例外、改锚或调参数挽救。

## 候选主张

仅在**同一股票已连续完成两次没有原结构进展的失败**，且之后尚无新进展时，把该股新mobile的原名义目标与股数cap减半。其他首次新主线、正常首买、已有进展的持续赢家按原规则。行业只保留分析标签，不参与门控；不同股票不能借同行业亏损相互施加限制。

这是一个可被否证的资金策略候选，不是市场趋势强度新定义。半额、两次、下述进展定义均固定，不搜次数/比例/窗口组合。

## 1. 一次可观察失败到底是什么

单位为某股**真实full-stock flat-to-flat campaign**，含core/mobile全部层。第一次实际股数从0变正开始，真实全部股数卖至0、原退出及剩余买单责任确认结束才完成。多层、多个sell.parts、一次退出分几日成交，均只属于同一campaign，最多计一次F。单层CP1退出、请求退出、tiny core仍活或部分卖出，不产生full-stock失败事件。

完成时可知的净交易现金：`K=所有真实卖出净现金−所有真实含买费买款`。包含全部原买卖费且只计一次，不含未来股息AR、期末mark、后来赢家标签。公司行动非交易核销/无法映射现金或单位的campaign标UNKNOWN，不拿残差填成亏损。

F必须同时满足：

- K严格小于0；
- 完成该campaign的实际退出责任为原I结构失效或原CP1保护；同一次清仓的部分成交合并，原因混合/不可唯一归因标UNKNOWN；ACT暂停、筹资/配置换仓不算F；
- 本campaign从开始到完成从未出现下文唯一的 `progress_seen`。

若有进展后最终负现金，记 `GIVEBACK_AFTER_PROGRESS`，不计F；正/零现金为非F。该标签不声称所有此类损失都是合理回吐，只是不准把它们当作“没有新进展的初始失败”触发本候选。非F完成campaign打断连续F。

## 2. 唯一、无新阈值的结构进展定义

冻结首笔真实fill所对应decision-CLOSE的原I floor为F0。价格、I floor全部使用同一因果复权价域；普通送转须映射，源段不可比为UNKNOWN。

在campaign实际持有期间的一个有效decision-CLOSE t：

1. 先按原逻辑检查此前已生效的I/mobile保护和未完退出；若已失效或有退出责任，当天不能产生“新进展”来倒救失败。
2. `Hprev=max(C_s : 首fill日期<=s<t日期，s为已完成有效收盘)`。先比较，后更新当日C；不包括当前收盘本身。
3. Hprev非空，原I仍有效，且同时严格满足 `I_floor(t)>F0` 与 `C_t>Hprev`，则第一次确认结构进展。
4. 将 `progress_seen=True` 作为吸收标志保存到真实full-flat。之后回落、receipt消费、I/attempt换号均不把它改回False。

first-fill当天尚无前一已完成持有期close时，不判progress；空max不能填0。这只是失败分类的观察边界，**不增加任何首次买入等待或普遍首笔缩量**。

若campaign历史中某个应观察决策缺原I floor、有效close、保护责任时钟或可比单位，则不能把“未观察到progress”填成False来认证F；该campaign的无进展认定为UNKNOWN，除非已在更早完备观察确认progress_seen=True（吸收标志不受后来缺失逆转）。

单独I换号、floor有值、fresh CP1、CP1 anchor重置、行业新attempt均不构成进展。I floor提高但股价未突破、只突破但原支持未提高，也不成立。F0不随每日更近的新floor重锚；否则提高基准会把曾有进展洗成未进展。

这一定义识别“原支持抬高且价格再创新高”，没有证明该趋势成熟。一个很小的支持提高与新高也可能触发progress，这是不引入新幅度阈值的保守代价。它很可能排除大量原主要损耗——已有归因中大量失败发生在更高价格/候选之后，覆盖小应当接受，不可据此事后放宽F。

## 3. 连续两次如何累计和解除

每股保存已完成campaign的顺序。完成F则streak加1；完成任何已知非F则清0。UNKNOWN打断“已知连续”资格，不把未知填成F或非F，历史账及未知记录均保留。

只有相邻两次完成campaign都为F、其中间和其后没有确认新结构进展，才激活 `NO_PROGRESS_AFTER_TWO_FAILURES`。streak>=2以后保持一次半额，不继续按每多一次失败反复减半。

激活时保存最近两次F持有期间完成close的同价域最高点Hfail，严格截止各自真实flat OPEN之前。它是当时已知高点，不是未来选出的局部顶。普通receipt、CP1低锚repair、I新episode、行业attempt、订单取消都不清streak或财务损耗。

本候选只有两种解除事件，计算前固定：

- 原I有效、无退出责任时，当前close严格突破Hfail；或
- 当前新campaign在实际持有中首次满足上文同一个progress定义：原I floor高于它首笔授权时冻结F0，且当前close突破该campaign此前持有期高。

第二项不是看见个别赢家后添加的higher-low补救；它是“之后有新价格结构进展，就停止减量”的同一语义。它不要求永远收复老失败峰值，可在较低价位的新结构得到实际确认后解除。它也不依赖新repair解析器。首次得到progress的同一CLOSE可供其后新的原生合法mobile恢复原量，但原退出优先、原fresh CP1/receipt消费与所有资源要求不变。

失败财务历史从不删除，解除只清本候选的门控计数。若当前无持仓而只是I/CP1重启，第二项没有真实campaign锚，不能假装已确认；仍可由第一项解除。新趋势第三次首跳因此可能被减量，这是明确代价。

## 4. 怎样暂减新增量

仅在激活且本次未先解除时，`intent.budget` 与 `intent.cap` 分别取原名义值的一半，cap按原合法数量规则向下取整，后续原OPEN价格、费用、手数、现金/股/行业/账户约束照常。不能用未来实际fill数量反推当时cap，也不补最低一手。

该定义是半额原名义新增量，**不保证含最低费用、跳空后的实际货币风险恰好减半**。原floor、角色、退出、排名不改。原core不缩，新mobile已存在订单的剩余/部分成交不追溯重写。没有新的0.25%CORE首笔限制，也没有“先持有一天才能加仓”。不触发时原目标逐项保持。

## 5. 最强反例与必要边界

| 情景 | 本候选必须怎样处理 | 局限 |
|---|---|---|
| 一次退出卖掉五层，分两日完成 | 一个campaign，只计一次F | 不能把五层当连续五败 |
| 前一赢家曾支持抬高且价格创新高，后跌至负现金 | progress_seen保留，不计F | 未证明这笔回吐本来可接受，但它不属于本命题 |
| F、正/有进展完成周期、F | 不连续，不激活 | 不拿很早以前的失败凑两次 |
| F、F后新receipt/I换号但没有支持抬高与新高 | 激活仍在 | 换身份不是独立新进展 |
| F、F后第三次低位真趋势直接单边跳涨，未破旧高、尚无新持有结构进展 | 第三次首笔可能半额，甚至整手变0 | **最强赢家误伤；不能特许，也不能自动挽救** |
| 减量导致新单0股，此后始终无实际campaign可确认进展 | 第二解除通道无法工作，只剩Hfail突破 | 高价股/STAR可能发生真死锁，必须报告并可直接否证 |
| 新趋势在旧高以下形成更高支持并再创新高 | 持有后按唯一progress解除，不用等旧高 | 首次小仓之前/过程中仍可能少参与 |
| 正常持续赢家早扩从未有两个F | 完全原量 | 不将其与其他股票/行业失败混合 |
| 同一次行业冲击使多股票同时失败 | 仅各自stock记录，不汇总成行业连续失败 | 本轮不声明已研究同行业抑制 |
| tiny core仍活、mobile反复失效 | 不产生full-stock F | 已有同core循环确实存在，但本候选有意不覆盖，不增设第二计数器 |

## 6. 与已有机制和反证的区别

`budget_v3/model.py` 的losses按sector+original episode记录毛负已实现损益与费用，native为record_only。`joint_v3.fill_exit` 逐sell.parts累计负额及费，正赢不抵销；它不是独立试验次数，亦不排除已有进展后的回吐。直接把该losses超零/次数映射为连续失败会重复计同次多层并改变本命题。

此前行业negative-feedback按same行业+same资金attempt、已完成mobile净交易结果<0分组。它有短命输家先结束、赢家仍未实现的存续期选择问题；还可能把另一股票的失败施加给首个新龙头。本候选不使用这一汇总来门控。

旧R16是同股失败后的下一份预算反馈，与本候选近邻而非新发明；此处增加连续两次、明确无原结构进展、完整full-stock单位和新进展解除。此前same-E0重入仅39层、净−7115.84元，提示严格同段主张覆盖可能很小；本候选虽跨I换号保留streak，也不能因为覆盖小就扩成“任一行业亏就全行业减量”。

已停止的首笔统一缩量/入场后严格等待伤害强窗赢家，本候选不复用其首次门。Hfail只在两次已知F之后存在，也不能被宣传为对所有股票的新高证明。

## 7. 下一步最小覆盖与停止边界（此文件不执行）

先只回答：真实完整campaign有几个F/F链；哪些实际mobile在第二F已经完成后发生；多少原有进展周期被排除；原固定tail83/94全部对应/未对应保留；无事件、mixed/unknown、0close/跨source、整手归零、tiny-core未覆盖均单列。不能以终态净额选择F定义或从任何未知补失败。

若主体亏损发生在两败之前，或大多数原亏损campaign已progress_seen，作用域不足就关闭；不把progress改成更慢条件、不换mobile层数计败、不加入同行业补覆盖。若当前股早扩赢家仍大量落入两败激活状态，或STAR零单造成不能确认新进展，应明确否定/证据不足，不靠旧高以下临时fallback救样本。

原CP1无reset时已有价格前沿，因此Hfail突破和fresh CP1可能冗余；作用域小也应如实收口。冻结baseline分类只能说明关联，半额会改变未来campaign/持仓、计数、资金排序和解除日期，静态裁剪不得叫新账户收益。本候选的具体作用尚未计算；本次无任何新绩效结论。
