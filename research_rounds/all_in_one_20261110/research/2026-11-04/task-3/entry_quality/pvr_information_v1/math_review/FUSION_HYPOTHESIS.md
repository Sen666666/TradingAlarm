# 一个供证伪的融合例：正贡献时间分散度

这是一项数学上可区分的新观察，不是晋升建议或账户预注册。当前只有有限合成结果，未证明能覆盖D10的ND新mobile损失。η不重新采用、不换参数；保留原PVR净幅度E，不使用η作主分数/二级排序。

## 唯一公式

保持原e、21有效观察和0.9指数权重。j=0为当前观察，w_j=0.9^j/Σ_{k=0}^{20}0.9^k。

```text
E_t = Σ_j w_j e_(t−j)
a_j = w_j max(e_(t−j), 0)
P_t = Σ_j a_j
Q_t = Σ_j a_j²
L_plus_t = P_t² / Q_t                  when Q_t > 0
L_plus_t = 0                          when Q_t = 0 and every e is known
L_w = 1 / Σ_j w_j² = 15.25216295400495
d_t = min(1, L_plus_t / L_w)
J_t = E_t d_t                         when E_t > 0
J_t = E_t                             when E_t <= 0
S_star_t = 50 + 50 tanh(2 J_t)
```

L+是二阶集中度倒数，即正向加权贡献的有效参与观察数，不是连续持续天数、独立证据数、上涨概率或“方向质量”。其理论范围是1..21（有正贡献时）。平铺相同正e时L+=L_w，d=1；单个正脉冲时L+=1，d约0.06556447。超出L_w的均匀加权分布不额外加分。负E保持原值，避免负分被小系数抬到中性。这些选择没有依据历史结果拟合。

数学区别：同E与同η=1的21观察平铺推进和单脉冲，在L+上分别为15.2522和1，故不是η重包。相同正向总量重新分配到观察上，η保持1，L+会改变；正负幅度抵消也不是L+的分母。它仍与η/原E共享源、时窗与趋势语义，不能称统计独立。

## 最强反例与明确失败条件

1. **快速起涨**：21观察内只有当前e=0.9时，E约0.1011；全部e=0.02的微弱平铺路径E=0.02。原PVR强脉冲优先；J将强脉冲降到约0.00663，反让微涨优先。合成原价额已验证此反向排序。这可以错过真正主线早期，不得用“先等确认”掩饰。
2. **快速V**：前19个e=0，最近−0.85、+0.95，当前价已重返此前20观察高点上方；正贡献仍只有当前一个观察，d约0.06556，恢复被大幅压低。不能事后添加V快速通道救该式。
3. **非连续脉冲**：相隔多日的正贡献可以得到较大L+，不代表持续上行；正脉冲之间的下跌只由原E反映。L+不是另一趋势状态机。
4. **细小噪声**：长期微涨能有较大L+；本式保留E避免η式幅度消失，但仍会相对排挤真实启动。不能因为E仍小就断言误伤可忽略。
5. **波动/突破/行业**：本式没有恢复原始绝对波动、实际突破位置或行业共振。数学“补一个维度”不能宣称补全全部丢失信息。

若真实同日有资金竞争时，主要亏损与尾部赢家在L+上高度重叠，或主要亏损本来来自多观察平铺推进，则该经济假说失败。若主要受影响的是首次赢家而非亏损重复资金，也失败。不能改成10/40观察、不同衰减、开幅度门、加EMA/行业门、混η或设置例外继续挽救同一候选。
