# Stochastic / Williams %R / CCI 与原 E0–I–CP–PVR：单一组件融合审计

## 结论

**本次冻结的区间位置条件权重不晋升。** 它确实是原 PVR 未包含的 H/L 信息，但新增信息不等于改善判断：同日、同行业、相同 K 的机会比较，20 日与 60 日路径均值没有改善，已有大行情捕获也略降。没有为凑指标继续调窗口、调权重、加门槛。

未重跑账户、未改变 E0/I/CP、未生成订单，亦未改变任何持仓退出。本报告不能说明完整费后 0→0 胜率达到或接近 35%。以下“正收益比例”与完整净回合胜率不是同一统计量。

## 1. 标准指标到底测什么

令 HH_n(t)=max(H[t-n+1:t])，LL_n(t)=min(L[t-n+1:t])。

- **原始快速 Stochastic %K14** =100(C_t−LL_14)/(HH_14−LL_14)。当前日也在窗口内。快速 %D=SMA3(%K)。慢速版本把快速 %D 当慢速 K，再做 SMA3 得慢速 D。本审计仅把原始 k=%K/100 接入一个实验，D 不构成第二条规则。
- **Williams %R14** =−100(HH_14−C_t)/(HH_14−LL_14)=%K14−100。相同窗口与时钟下严格仿射等价，增加它没有新的信息。
- **CCI20**：TP=(H+L+C)/3；M=SMA20(TP)；MD=mean20(|TP_j−M_t|)；CCI=(TP_t−M_t)/(0.015 MD)。MD 的中心是当前窗口同一个 M_t，不能错用每根历史自己的滚动均值。它是典型价格相对均值的绝对偏差标准化，**不是 H/L 箱体内位置**；没有固定上下界。
- **预热与除零**：原始 K、R 需14根；快速 D需16根；慢速 D需18根；CCI需20根。HH=LL 或 MD=0 时记 UNKNOWN，不擅自填50/0。收盘数据只有当前收盘后可知，最早下一允许决策窗口使用。

标准公式来源：[TradingView Stochastic](https://www.tradingview.com/support/solutions/43000502332-stochastic-stoch/)、[TradingView Williams %R](https://www.tradingview.com/support/solutions/43000501985-williams-r-r/)、[TradingView CCI](https://www.tradingview.com/support/solutions/43000502001-commodity-channel-index-cci/)。这些来源解释指标定义，不证明本次自拟融合有预测力。趋势中高 K 可以持续，不能把“超买”直接等同拒买或卖出。

## 2. 与原机制及已做研究的实质关系

| 机制 | 实质输入/时钟 | 与区间坐标的关系 |
|---|---|---|
| E0 | 极值日冻结前63收益RMS；反向对数位移×活动因子达到 sqrt5 尺度后才发生转折事件 | 用已经到达的位移确认结构，不等于K高低，不得把确认日回写为极值日的已知事件 |
| I | E0结构有效与G证据组成机会及持有状态 | 资格与持有生命周期，不是振荡值；当日i_buy与持续I有效不同 |
| CP | 只把事件内新frontier位移 delta×金额活动因子累积为credit；fresh和双阈值发证后消费 | 不是每日正负平均；当前K高不产生CP发证，也不复活旧证 |
| PVR | 每日标准化close对数收益、金额响应及21根/.9权重 | 不读H/L；可以在同一close/amount历史上，仅改变历史影线得到不同K，是真正不同输入 |
| H1 | 63日分段收益的 .4/.2/.2/.2 合成及横截面排序 | 不读取H/L；新坐标不是H1重命名 |
| 前高/Donchian | 相对于严格过去最高价的突破事件 | 新K是当前含自身的最高/最低包络位置，突破时常饱和，非同一事件定义 |
| Bollinger %B | 相对于均值±标准差的距离，可能越0/1 | 含整个窗口分布，K只依赖极端H/L和当前C；CCI更接近此类标准化偏离，但均值输入与尺度不同 |
| acceptance_A | 当前t价格与每根历史j的H/L逐笔比较，带年龄、金额及锚点限制 | 同样研究价格接受程度，但不是K：A以当前价格重新评价历史区间；本融合用各日j自己的K固定当日e的权重 |
| range efficiency | 净位移/累计绝对close变动或TR | 衡量路径效率，不等于窗口末位置；横盘高位箱体可有高K而无净推进 |

因此 Stochastic 有可解释的增量维度，但不能同时把 Williams 当独立验证，或把 CCI 混称同一维度。原 acceptance_A、布林/前高研究的反例应保留，而不是换名字再试同一门槛。

## 3. 本次唯一冻结的融合式

原式：r=log(C_t/C_{t−1})；s=max(1e−8,1.4826 median(|r|前63))；u=tanh(r/s)；b=tanh(log(A_t/median(A前21)))；e=u(1+0.5|u|b)。

令 e⁺=max(e,0)，e⁻=max(−e,0)，k=%K14/100：

**eK_t=k_t e⁺_t−(1−k_t)e⁻_t**

EK_t=Σ[j=0..20] w_j eK_(t−j)，w_j=.9^j/Σ .9^j；scoreK=50+50 tanh(2 EK)。

这是本次自行提出的条件权重，**不是标准Stochastic的交易规则，也不是更真实的资金流**。没有80/20硬门，没有必须回踩/必须K交叉，没有改变原买入资格或CP信用。

关键恒等式：**eK=0.5e+(k−0.5)|e|**。高k时负日的负贡献也会变小，低k时正日的正贡献也会变小。它编码的是高箱体位置偏好，而非中性地识别真假动量。对于刚从低位反转的赢家，过去低K的正贡献仍要在21根窗口中逐步退出，可能伤害早期切入。

时钟与边界：复用原 PVR 观察有效掩码、segment 及同源复权价格；原式完整85根预热不变。额外要求H/L/C有限、正值且L≤C≤H；坏HLC或来源kind/segment变更重启区间/融合预热。纯HLC断裂需14+21−1=34根重新得到融合值。没有插值、未把缺失当零，也没有把原始价格与复权H/L混用。观察时钟仍是原原生观察时钟，不假称缺失公共交易日的价格已知。

## 4. 因果背离的边界

本次只输出诊断：选严格过去14根最高close的日期j（平局取最早），如果当前C>C_j而k<k_j则记“记录高点区间位置不确认”；低点反之。j及k_j均已发生，当前t才可发诊断。它**不是事后局部拐点**，不使用t之后右侧高点，不回填到j，不加入排序。

即使完全因果，这也不自动具有看空含义：C从100升至101，窗口低90不变，高从101变110，K从90.91跌至55。只是上影线/窗口包络变化，也可出现所谓背离。平滑线性上涨的CCI20可恒为126.67、K可长期接近100，而价格持续创新高。因此绝不能把“没有再创新指标高点”机械转成退出。

固定诊断中002317在2022-10-14出现此类bear标记，但属于原赢家；金海通2026-01-15也出现，且该日原CP=false。未据此新增门槛或伪造MOBILE资格。
