# 上行起点前3日：行业内部结构与独立试仓

## 结论

本轮没有找到足够的新机制可提出为入口修正。原因不是资料多、UNKNOWN多或抽象的“市场难判断”，而是固定起点的可计算结构出现了具体冲突：

1. 真实4月长反弹起点的行业修复位置更低、前三日推进更不连续、行业CP确认更少，不能要求更成熟、更连续才允许独立小仓。
2. 其成员I比2月多，但主要多在同日新生，前一日已存续I反而更少。当前I、当日普涨、量价共现不能当作三份独立确认。
3. 3月弱起点实际选中的个股当日涨幅、行业内分位和放量已经比4月更强；只加个股强度排名不是主修复。
4. 924的先行股在全市场同步以前已有独立机会。把9/24那种全面同步设为首仓条件，会改变9/12银之杰和9/23海能达的时钟。

这不证明所有量价机制无效，也不证明不存在允许少量错过右尾的改进。仅说明本轮这些组件及其简单单调组合，没有提供值得进入经济验证的新信息。没有以保住每个赢家作为不可能的验收标准，没有换阈值救病例。

## 原生状态与可复算公式

行业原canonical facts没有I/G状态，不虚构“行业I”。使用行业E0、已确认leg方向、CP attempt/stage，另列个股成员I。

在t收盘，只使用截至t已确认事件：
L_s(t) = 最近原event=+1所确认的trough价格；
H_s(t) = 最近原event=−1所确认的peak价格。
二者都在事件确认当天才进入记录，同源segment内向前延续，不把pivot日当确认日。
修复比例 D_s(t) = log(C_s(t)/L_s(t)) / log(H_s(t)/L_s(t))，分母必须正，否则UNKNOWN。
另列log(C/H)、两极点年龄与确认年龄。D>1只是已收复已确认峰，不代表未来好；D<0也保留。

成员：
r_i(t)=log(C_i(t)/C_i(t−1))，要求真实相邻共同日与同源。
V_i(t)=A_i(t)/median(A_i(t−21..t−1))，严格此前21共同日；量价缺失/源切换不压缩时钟。
P_i=1[r_i>0]；J_i=1[r_i>0且V_i>1]，负侧同理。
这是价量同现人数，不是主动买入、净流入或统计独立的联合创新。正贡献HHI只作集中度描述。
M3原样使用canonical RIGHT3/KNOWN3；I原样读stock facts。已知比例与固定1709成员比例上下界分开，不把未知成员填0。

I分解：
I_cont=1[I_t=1且I_t−1=1且源连续]；
I_new=1[I_t=1且I_t−1=0且源连续]；
I_prev_unknown=I_t=1但前状态不可知。
三项逐条精确加总为当前I有效。该分解用于识别重复信息，不是新交易门。

- 3/17：522=374+148+0，I已知1473股。
- 4/29：702=427+275+0，I已知1483股。
- 11/1：922=751+170+1，I已知1531股。
- 9/24/2024：1285=733+552+0，I已知1626股。

4/29当前I更多并不是旧I存续更多，427反而少于2/8的457。当天275个新I明显参与了这次差异。9/24也有552个新I，当日全面普涨、放量、I扩散高度共享同一冲击。
这不是说I无用，而是禁止把同一次冲量在多套指标中的投影，当成额外独立确认。

## 排重与裁决

已经查阅：
- market_participation_flow_audit_v1：B20、进入/退出、端点留存、正收益集中度，未解释PVR跨年翻转。
- breadth_member_quality_v1 / breadth_supervised_rank_v1：新M3/持续M3配对、持续性与PVR等联合特征，无稳定增量。
- fast_q1_signal_mechanism_v1：I根、G、行业attempt、前根floor；各原路Q1皆弱。
- cross_window_entry_mechanism_v1：固定行业出生cohort价格留存，失败反例。
- joint_innovation_fixed_cases_v1：J价量中秩共现与二阶汇总，不能认证早起势。
- entry_current_downside_unsaturation_v1：同日强弱改写PVR，覆盖低且真实漏尾。

本轮提供新的因果起点横向对齐与I身份拆分，但没有新原始信息或可靠的新消费者机制。因此不提出“市场够强才能买”的新入口、不改原独立小仓资格、不叠加I/M3/CP共同总门、不根据2/3/4/11月后验结果拟合阈值。若后续另有机制，须说明它如何识别个股新的持续推进，而不只是重新计算共同上冲或用未来长短命名当前状态。
