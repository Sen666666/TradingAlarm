# 复合权益接口冻结设计 V2
状态：设计冻结，未写实现，未新增经济运行。原年度账及其锁、原设计与补充均保持原字节。税准备金方案未裁定，不假定零税或固定 20%。

## A. 本轮最小可实现范围
只接纳有完整事实和经审税口径的现金加资本公积转增、同一除权日新增股已明确上市可售、逐登记层新增股为整数的事件。股票税事实或研究准备金合同必须先明确。送红股、晚上市及非整数不因比例相同就自动进入此域。
不替换原 Account，不更改 M3、PVR、probe、CP、预算或退出信号。437 原事件逐字不动，新增事件独立版本和许可。

## B. 分离的事实与会计字段
每个 event 固定经济 ID、证据版本和可知上界，分开保存：
- record_close：登记日、owner_round_id、layer_id、core/add、登记股数、原真实 buy_cash / fees、当时剩余层成本。
- ex_open：权益归属/数量变化时点、官方实际现金 d_cash、源坐标 d_source、实际股票比例、源股票比例。
- share_credit 与 saleable_from：账户记入和上市可售的各自证据。不以 ex_date 代替上市，不以原 layer.opened 代替新股取得。
- pay_close：现金应收转入 cash 的日级保守时点；无盘前到账证明时不供同日 OPEN 新买入。
- stock_tax：事实税基/税率/归属/支付时点或明确研究准备金政策。未知金额不能伪装已付现金、零税或已结清。

## C. 登记与除权原子处理
record CLOSE 冻结实际 old_q，逐层保留原轮归属；零持仓没有权益，旧轮现金权利不迁移新轮。
ex OPEN 先校验来源、raw OPEN、完整登记、比例、时钟、整数及因子。全部通过后才原子记现金应收和独立股票权益账；失败无半笔变更。同事件重复执行拒绝。
新股 q_new = old_q × ratio_added。现金应收仅以 old_q × d_cash × 原 NET80 计算，不能以扩股后数量多计。source_cash 和 official_cash 各行其责，不为了 factor 拟合现金。
事件不伪造 buy、fill、手续费或 fresh CP，也不增加成功 ADD 次数、不改历史买入股数、spent、Nd 或佣金。

## D. 成本、CP 与两种可售状态
历史真实买入成本和手续费保持原值。层归属不变，新股继承 owner_round_id / layer_id / core-add / first_fill_id；新增权益来源另记而不是伪造新买入。
报告用剩余成本在 old_q 与 new_q 之间按同股类单位均摊，总额守恒，Decimal 尾差指定最后一份吸收。历史 buy_cash 与剩余成本分别记，不能为了分摊改实际现金或盈利判断的累计现金。
同日已上市：原层 current_qty 增加至 old+new，按原请求数量和日期 QuantityRule 退出；first_fill、CP 消费身份与一次 ADD 权限仍原值。
晚上市：至少须分成 old_saleable_qty 与 issued_locked_qty（后者带 saleable_from），总持股仍包含两者。旧股不得因为新股锁定被伪装不可售，新股也不得借旧 opened 提前卖出。到官方上市 OPEN 才释放锁，不能另造 T+1 。
原 I/CP 线仅按已证 Fold/Fnew 做坐标转换。不会生成新 CP、重新获权或重排选股；原 mark/风控与报告估值的各自用途必须保留。

## E. 晚上市为什么不是加一个日期字段
当前原 source_exit_only / sell_all 全仓卖出即关闭状态，indexed _record_new_actions 要求卖出量等于所选全部层量并清零；它们不支持“同一退出请求先卖可售部分，保留锁股待上市卖出”。
因此有界跨日版本须另审：
1. 原退出意图保持，执行只取已可售股；锁股及原轮仍存在，不提前记完整轮胜负。
2. 残余新股上市后按原未完成退出意图和当日真实 OPEN 条件处理，非回填此前价格。
3. 实际多日订单各自按 dated 最低佣金和整单费用入账，不能沿用一次清仓虚构少付费用。
4. core/add 部分数量、成本分摊、冻结权益、同股不重入、结算关闭与报告全部重放。
这些是执行能力扩展，不是已批准或已实现的策略变动。本轮 A 窄版不实现该跨日路径。

## F. 整数与奇零股
逐层整数为窄版硬边界，不按 floor 分配、不编造补偿、不用公司全体零碎算法猜个人所得。若要支持零碎必须另证实际分配粒度与规则。
每次请求真实订单必须用原 dated QuantityRule 校验。整仓奇零股可售与部分 ADD 奇零股可售不是同一规则。若 sell_floor(requested,total)!=requested，明确 UNKNOWN，不自动凑整或改卖核心股。
例如 000987 的 300 -> 405 只是整新增 105，仍要检查未来卖出请求的奇零股规则，不等于所有未来请求都合法。

## G. 期末与税准备金
NAV 显示实际 cash、已确认 receivable、旧/新增/锁定股各自数量及同股类日线 CLOSE 估值，不减假定卖出费；可售性独列。未上市股的估值成立必须有同权同类权益证据，不把外形相似证券当同一价格。
若另采用保守股票税准备金，需先证可量化税基和界限，明确其是研究负债还是实际已付税，并决定它是否改变可花现金、risk NAV 和盈利门。这些选择会改变后续可用资金/风险，不能只在结果末尾悄加或一边声称保持原策略口径。尚无裁定，当前不选金额、不回灌风险。
年末仍保留开放层和应收/可能负债。年度指标只在完整支持的年末路径可得，不将 6/23 OPEN 停止点当完成 CLOSE。

## H. 工程成本比较（不含外部事实等待）
A 同日上市＋逐层整数窄消费者：约 1–2 小时工程与 QA，独立审查约 20–40 分钟；股票税方案额外适配视裁定而定。新独立单次经济仍预算 900 秒 / 6 GiB。
B 同股类、整数、明确晚上市的有界消费者：约 4–8 小时工程，独立审查约 1–2 小时。差额主要是部分退出与残余持仓状态、跨日实际费用、层成本和关闭语义，不是下载更多公告。
C 全类别通用权益消费者：至少数日工程，含零碎、送股税、合并/配股/选择权、分批限售等独立状态和边界；事实缺口仍无法靠工程消除，不承诺为完成本次年度结果而无限扩大。
所有估计为当前源码约束下的粗估，不是全年成功或时间保证。下一步应先冻结税事实/研究假设，再决定只做 A 还是确有责任需要 B。旧经济不重跑，新实现须合成、已存前缀等价、精确 source freeze、独审放行与独立新锁。
