# 固定14例条件路径独立经济核算口径

本目录仅接收已封存 run/DONE.json 与 OUTPUT_HASHES.json 后的只读核算。不得 import、实例化或执行条件/原生账户引擎，不改合同、参数、案例、任何 run 源文件。输出写新子目录，旧审计结果也不覆盖。

## 单位、覆盖和比较
固定14例、各CP/I两臂，截止2026-05-15。每case为从原NOACT seed收盘NAV独立全现金起步的条件路径，不是原账户复刻。不把跨case净额相加作组合收益。三类分别列 SEED_MOBILE、REENTRY_MOBILE、REENTRY_CORE；seed拒单也保留在14分母内，不归为输/赢。每条完整0→0回合从原始journal独立重建，全部保留，不能只保留最后赢家。两臂回合数量或时间不同，不强行逐笔配对。

## 独立核算
按时间从 journal buy/sell/split 与 audit dividend accrual/payment 重建股数、各层股数、全股票含买费剩余成本K、每回合买入含费支出/卖出净款/股息权益/费用。卖出按总股票持仓比例退K；各层现金与售量按原实卖parts分配；拆股按合计取整并按原层顺序分配余股；权益发生在拆股前、当日交易前。单独复算 dated fee components，识别同订单部分成交的累计最低佣金。

逐共同收盘校验：
- 初始本金 + 累计卖净款 - 累计买含费款 + 累计股息权益 + 独立raw mark*股数 = NAV。
- 初始本金 + 累计交易现金流 + 已付股息 = available + order_reserved + sale_receivable（debit lock/payable相消）。
- 分红应收 = 已获权益 - 已付；售款应收按对应settlement待付；预约现金从reserve-fill-release另算。
- 股数桥、各层股数桥、剩余成本K、累计费用与每日字段一致；每回合/各层净额加总与NAV变动一致。
- 不对缺OPEN填价，不把stale mark当可成交报价；缺当日有效raw价的路径指标标为缺价/UNKNOWN。源码原始raw bars/行动/fee versions哈希复核，截止外数据不参与核算。

## 胜负、尾部与未闭
已闭定义为真实代理库存归零，不以首层退出、I失效或最终净值为已闭。已闭净额=卖出净款+股息权益-所有买入含费支出；另列未支付分红及现金实现净额。大于0为W，小于0为L，等于0单列；W/(W+L)仅为开发样本描述并始终附分母。平均赢亏为同case同臂同类别已闭回合的平均金额及各回合净额/累计买入含费支出，盈亏比=平均赢/绝对平均亏，缺任一侧为NA。累计买入支出回报不是账户收益或时间加权收益。尾部预定义为已闭净额/该单位累计买入含费支出>=30%；未闭即使浮盈>=30%也不进入尾部胜例。为展示分布可列固定案例计数，绝不称随机/OOS推断或35%达标。

未闭同时报告原生收盘mark盈亏和扣估计卖出费/5bp的净清算参考盈亏，仍不认作赢；缺当日有效价时标UNKNOWN，并保留原生stale-mark账面数。末日不强平。

## 首层、含ADD整轮、路径与回本
首层是每个0→正回合第一个原订单的全部部分成交层，独立于后续ADD。首层净额/胜负与含ADD整轮分别列出，不把尺寸缩小当胜率提升。
最大不利路径报告可见持仓收盘及raw low时，累计售净款+股息权益+剩余净清算参考-累计买含费支出的最小金额及相应投入分母比率，并报告可用/缺价日。raw low指标为日内代理下界观察，无法证明真实可成交；开盘卖出后不使用当天后续low。另列seed原口径调整价MAE供对照，不把它与账户最大回撤混同。
占资日为真实收盘Q>0的共同收盘数；成本日为这些日子的K之和（元×共同收盘日）；另列开/平仓历时。
经济回本日期为累计卖净款+股息权益+剩余净清算参考>=累计买含费支出首日；已兑现本金回收日期为已结算卖净款+已付股息>=累计买含费支出首日。股息应收不等于已付现金；后续ADD扩大本金后须另看终局。
退出首触发到首笔/全额代理成交的日历和共同收盘间隔、挂卖占日/末日待卖状态分别列。重入逐笔列新信号日、首填日、role、订单及前次归零日。控制退出后候选仍持有天数需按同seed首层比较，原NOACT退出仅事实参考。
重点审看2024润泽/中国银河和2026江丰等宽I亏损/漏尾反例，不因单条极端盈利称成熟。
