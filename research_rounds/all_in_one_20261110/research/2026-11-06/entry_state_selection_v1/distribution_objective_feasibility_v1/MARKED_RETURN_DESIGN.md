# 完整净回合收益分布：可计算目标与推进边界

状态：设计及标签支持审查完成；未拟合新模型、未运行新经济、未改变入口/排序/仓位/ADD/退出。当前历史已反复研究，后续即使时间向前也不能称未见样本外。

## 1. 先固定真正的经济单位

定义 Y_i = 原完整 PRICE 回合净现金损益_i / B，B=3000元。完整净现金含原初仓、原ADD、日期费用、条件5bp成交及该标签已可核定的权益；不是单腿收益。

3000不是本轮回看加出的参数：
- independent_channel_joint_economic_v1/joint_policy.py:11–15 固定 NAV=1200000、INIT=24000、SLOT=48000、RISK=3000。
- 原PROTOCOL_DRAFT.md:21明确整轮计划风险3000，:108明确跳空损失可以超过3000，:114和:116说明ADD共用剩余风险。
- 本目标仅改计量单位，不更改该预算。乘回3000即原金额。上一轮路径归因的1R使用各轮实际entry_risk，本设计用固定计划预算B=3000；两种桶不能拼接或互称同一个1R。
- 不用实际entry_risk作出生已知分母，它到次开才知道且可能很小；不用未来total_buy_cash作事前预算，它包含以后ADD。
- SLOT=48000是ADD时库存市值槽上限，不是累计买入本金上限，不以它伪造最坏终局损失界。

固定金额标记 K(Y)：
1. Y≤−1：超计划单位的净亏损；
2. −1<Y≤0：小亏及零；
3. 0<Y≤1：小赢；
4. 1<Y≤3：中等赢；
5. Y>3：大赢。
这是候选风险单位分箱，不是新的止损/止盈规则。3R为当前待检验的右尾标记，不取代原净回合/全买入成本≥30%的尾部评价。未按成绩扫描或调整边界。

## 2. 排重后，什么并不新

已核实：
- conditional_distribution_numerical_fix_v2：三状态20日路径+60日收益经验分布，均值/ES10排序，41个月真实拟合；共同6511事件增量近零。不是完整净现金回合。
- breadth_supervised_rank_v1：W/L/U softmax、正负金额Gamma回归，Q=(pW×G−pL×D)/(pW+pL)，全部可行影子同K排序。右尾下降，Q仍是120日内已闭条件净额。
- actual_round_probability_v1/competing_risk_v1：已纳入未闭在险日，预测120日正闭/负闭/存活；36个月拟合。没有金额标记，也没有H时仍持仓的经济价值。
- closed_price_supervised_pilot_support_v1：真正完整PRICE正负标签、PVR/DMI/CMF交互、按exit_day时钟月度训练；2024错失大量尾部。
- local_v2已有保守收益下界/尾损比+正分准入，结果全部年度无正分，不应再把这一形式当新出路。

因此“收益概率×盈亏幅度”“生存分析”本身都不能称新。下面候选的区别只在：原完整净金额标记、退出时间、质量故障三者的联合时点目标。它仍没有新增预测信息，不能假定组合旧部件自然有效。

## 3. 候选A：金额标记的退出风险模型

### 数据时钟

x_i只取原PRICE信号收盘已经可用的PVR、原严格Wilder14方向、原CMF21及原pilot的P×D、P×C交互。标准化只用训练cut以前的输入，缺失不补弱值。先保留原特征定义以区分“目标变化”与“换指标”。

T_i为首仓后到原完整退出的共同交易日年龄。G_i只指原账首次可验证的冻结UNKNOWN质量故障，不包括暂待成熟的退出金额。G不是经济清仓，不释放责任或现金。已退出但权益/财务标签尚未成熟的记录另列EXITED_MARK_PENDING：其经济退出T已经发生，不再累加持仓h_0存活日，也不永久塞入吸收U。待真实source_available_at可核后，只在之后cut暴露历史T/Y；不能回改过去预测。

月首cut前：
- 普通、已闭、标签known_at_proxy<cut，才暴露Y、K和T。
- 尚在正常持有，只贡献截至cut前的存活前缀，不贴正负金额。
- 已发生质量故障，以故障类别单列，不能假设其后的损益为零或将其作为独立随机右删失。
- 未买q0、入场UNKNOWN、待次OPEN分开；没有BUY的记录没有持仓回合T。
- 不用最终common、最终ordinary、未来是否有权益决定出生/在险成员。训练仍仅能覆盖原登记/已买域，不能推断未选候选的完整经济效果。

普通label_known_at_proxy保守取退出日收盘，月首OPEN用exit_day<cut。已卖证券后现金可取日不是普通交易损益成熟的额外滞后。此proxy不是历史行情发布版本或真实成交/税务PIT证据。

### 可实现的似然

对年龄a、仍在可观测风险集的回合：
h_k(a|x) = Pr(年龄a完整退出且K=k | 此前未退出且未发生质量故障,x)
h_U(a|x) = Pr(年龄a首次质量故障 | 此前风险集,x)
h_0(a|x) = 1 − Σ_k h_k(a|x) − h_U(a|x)

用共享的离散时间softmax表示，年龄截距与信号特征项分开。沿原年龄段1–5、6–20、21–60、61–120，并显式保留121–252及更晚的在险域，不在120日给未闭者强造金额标签。稀有右尾不能靠多加参数获得证据；当前只写模型契约，不启动这套参数拟合。

以下先写普通退出日收盘即获金额标签、行政仍持有和真实冻结UNKNOWN三种可识别观察的部分似然。EXITED_MARK_PENDING另登记，不冒充仍持有或永久故障。要把它纳入完整拟合，尚需额外冻结“经济退出后标签揭示”的观察过程；不能无声假定金额缺失随机。

首先，只有退出年龄与金额分箱时，负对数似然逐回合为：
- 普通完整、类别k、退出T：−Σ_(a<T)log h_0(a|x) − log h_k(T|x)；
- 行政cut时正常持有到c：−Σ_(a≤c)log h_0(a|x)；
- 首次质量故障G：−Σ_(a<G)log h_0(a|x) − log h_U(G|x)。

以上只识别“退出年龄×金额分箱”，不是连续净金额Y的完整似然；同属>3R的赢家对该分箱项贡献相同。若要直接拟合连续金额，已闭项还必须加 −log f_k(Y_i|T_i,x_i)，其中f_k在该金额bin内归一化，和hazard使用相同as-of样本、联合权重及标签时钟。完整分布目标为上述时间/分箱项加这一金额密度项。当前尾部不足，f_k的参数族尚未获支持或冻结，不拟合f_k、不声称已有完整连续金额模型。仅保留成熟金额经验分布可作为无特征幅度基线，不能说它学出了个股尾幅差别。

正负金额不作任意类别重采样。若日期/行业等权，权重归属整条回合似然，不把一条长持仓的每个日子当独立股票。正则化和任何支持门必须在拟合前另行冻结，不能看到尾部得失再调整。

生存质量 S(a|x)=Π_(u≤a)h_0(u|x)。
有限H的金额类累计发生率：
F_k(H|x)=Σ_(a≤H)S(a−1|x)h_k(a|x)。
并保持 Σ_k F_k(H|x)+F_U(H|x)+S(H|x)=1。

完整金额可在已成熟标签上保留每个标记内部的原始金额经验分布，不裁剪大赢家。必须与退出年龄联合，不能把所有120日前已闭者的分支均值直接补给慢持仓。但目前大赢只有少量旧年样本，年龄×尾部幅度无法稳健估计。

### 这套式子能识别什么、不能识别什么

能计算有限观察期内“哪种净金额终局何时出现”的子分布，以及仍存活/质量故障质量。
它不能无假设给出所有出生最终无限期净额：
- S(H)的未来金额尚不可知，当前浮盈不是其终局下界。
- F_U(H)不是亏损，更不是0；其后真实责任仍存在。
- 不把上述质量除掉，伪装成全出生期望；也不强设更晚退出概率=1或用历史均值强填。
- 因子/缺价/未审企业行动是信息相关故障，不满足“独立删失”假设。
- 120日、252日只是审计H，不是退出规则，也不能保证未来都闭合。

因此当前模型若输出完整终局期望，必须额外声明且验证尾部外推及质量缺失假设。在未具备这一步前，只能输出子分布/未知质量，不能把它接成一个强制准入分数。

## 4. 亏损、右尾权重与35%目标

在完整金额分布和决策效用中，大赢家必须按实际金额产生经济贡献，不能把每次赢/亏都当等价1票；但前述五分箱NLL本身没有做到同桶内金额加权。只有加入可支持的f_k或明确的幅度基线后，才可讨论金额期望；不能将分箱训练冒称连续收益优化。若分布可以识别，决策层可写：
U_λ(x)=E[Y_+|x]−λE[(−Y)_+|x]。
λ=1对应按原金额的净期望；λ>1表达更重视损失，而不是免费改善回撤。当前没有用户明确新增的损失厌恶数值，不从2024结果倒挑λ。

训练用正确分布似然与校准检查，偏好放在决策层；任意把赢家样本权重放大后，未经还原的输出不再是原概率。右尾概率、右尾贡献金额、漏掉原尾部的数量和金额必须同时报告，不能只追AUC或准确率。

若完整胜率w=35%，另无零收益原子且净额已含交易成本时，平均赢/平均亏必须超过0.65/0.35≈1.857才有正净期望。若有零收益，须单列其概率，使用实际亏损概率/盈利概率而非直接用0.65/0.35。更高胜率不必更赚钱；例如25%胜率配4倍平均赢亏比也可能正期望。把预测p≥35%直接设门会再次错杀低频大赢家，所以35%不能替代经济目标。

单回合ES、P(Y≤−1)和平均亏损不是共享账户最大回撤。回撤还取决于同日/同股相关、持仓重叠、现金、行业风险和排序执行。现有独立股票路径不能给出符合某个账户回撤目标的承诺，必须在后续固定共享资金合同中验证，不能拿ES换名。

## 6. 更适合现有支持的下一步

### 第一步：先做无特征风险集基线，不称新alpha

用当前已建的逐cut前缀，按年龄a统计N(a)、各金额事件dN_k(a)、质量事件dN_U(a)，计算：
ĥ_k(a)=dN_k(a)/N(a)
Ŝ(a)=Π_(u≤a)[1−Σ_k ĥ_k(u)−ĥ_U(u)]
F̂_k(H)=Σ_(a≤H)Ŝ(a−1)ĥ_k(a)。

同时保留质量和生存残余，和“只用已闭样本的经验CDF”并列。基线用途是量化闭合选择与资料故障，不是预测哪个股票会赢。跨出生年代非平稳、日期/股票相关仍需明示；不能把 pooled 风险集比例当2024新股的精确概率。先不给复杂模型机会靠改分母胜过一个不公平的常数对照。

固定基线还包括原全保留PRICE与原PVR排序。任何新评分先与无特征金额风险集基线比较 proper score、左尾金额、右尾保留和覆盖，不能只比较二元p0。

### 第二步：补连续经济标签的可生成性，不再换模型

对2023全年、2024年1–8月，先检查原1709池的逐日源、交易规则、权益注册和责任桥的可复用性；不按未来赢家挑股票。若可生成，再单独冻结同一原PRICE/AB消费者、PVR、额度、ADD、保护、退出和费用，仅增加出生日历覆盖。保留旧2022/2024输出及回归，不把日期参数化当新策略。

现有runner的日期与授权是两窗专用，不能假设加一个--window参数就已有正确标签。本任务没有启动新经济或扩展授权。新同合同标签应按各历史cut真实成熟后入库，不能将补出来的2024未来终局提前用于2024。

若这段权益/时点覆盖仍无法成立，应先报告具体覆盖缺口。不能混入CORE/MOBILE不同合同标签，也不能靠放松普通定义扩样。

### 当前消费者范围

本任务没有冻结新的准入、预算或排序消费者。它不是又一个只在同K竞争队列里换人、却声称修复无竞争亏损的方案；也没有凭收益分布名称取得改变每次试仓的权力。

无竞争PRICE占主要亏损时，单纯同K重排只能影响其竞争子域，不能作为主体改善。若以后要影响无竞争试仓，需要明确新的准入或风险预算动作，并遵守出生小仓、盈利才加及正常重入约束；实际完整回合也会随之变化，不能把原静态子集收益当新策略效果。
