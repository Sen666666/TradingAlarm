# 线性走势余量 / 原生入场风险：一次冻结机会检验

## 结论

**停止此候选，不调窗口、不调分母、不改变方向、不接账户。** 这次把一个完整的新公式和配对规则先封存，再验证；不是只作口头判断。但证据不支持把它作为35%完整0→0净胜率目标的有效增强。

真实预算可互换151对核同既有配对hash。在146对完整20日路径中，新式改选46对，25对更好、21对更差，但日期等权收益反而降低0.257个百分点；60日降低0.846个百分点。收盘MAE有所减轻，MFE与原大行情保留变差。大样本MOBILE同日同行业固定名额检验也未显示可信增益。

最明确的机制反例是中国医药600056：2022-03-03早期大赢家信号Q=-2.98，被挤出；03-30末端失败Q=+13.98，仍保留。线性模型把真正加速初段当作“透支”，当陡峭涨幅进入历史回归后，又把末端看作“已有走势支撑”。新式未解决这一区分。

这不是校准概率、期望收益或真实价格目标。所有已有历史被反复消费，本次程序上的预冻结不使它成为样本外。

## 2. 唯一冻结公式与时钟

信号日为t，使用原native复权坐标。取此前21个共同交易日t−21…t−1，不含信号日：

p_j = log(C_j)，x=0…20。

β = Σ[(x−10)p_j] / 770。

拟合到信号时刻的趋势价：
p̂_t = mean(p_j) + 11β。

当前超出原轨迹的价差：
e_t = log(C_t) − p̂_t。

假设既有斜率还延续20日，扣除已付出的偏离：
U20 = 20β − e_t。

原意图保护距离：
D = log(C_t / F_t)。

最终排序：
Q = U20 / D，降序；同分用原PVR、原rank和sid。

F_t必须是该信号日、该角色的原pending保护线，不使用成交后的floor。在真实预算配对中，双方都用这一对实际获资角色的原保护线，128对CORE、23对MOBILE；不会把MOBILE风险距离冒充CORE。

当前及此前21日价格必须完整正值、source segment一致，且0<F_t<C_t。否则UNKNOWN。无epsilon、无截尾、无正Q准入门、无删单或反向策略。UNKNOWN保留原决定/原槽。

21日估计窗、20日外推期、上述排序均在新特征与标签结果前固定。无训练标签、参数优化或网格。最早评价价格是下一共同交易日开盘，不能倒买信号收盘。后续20/60日价格仅用于评价，不进入配对或排名。

该式表达了清晰的代价：同一既有轨迹与保护线下，买价越高，剩余投射收益越低，保护距离越大；但既有斜率高仍允许很高的历史涨幅。**这只是结构假设，不是市场一定均值回归的事实。**
