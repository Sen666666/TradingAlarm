## 必要的成本口径修正（必须置于任何成长结果之前）

原13个决策点使用U_avg，当前回合均未发生卖出，故C_layer=C_avg。这不允许把该相等关系推广到连续路径。定向卖出后平均成本与实际被卖层成本不同。

原账户既有 U_avg_pre > 0 门保留。成长预算及其盈利条件统一使用逐层真实含买费成本：
- C_layer = sum(仍持每层剩余实际买入现金成本)。
- C_avg = 原RemainingCostBook的全股比例退休成本，不改变、不覆盖。
- Δ = C_layer - C_avg；U_layer = U_avg - Δ（同一合并卖出报价和费用）。
- 必须同时原U_avg_pre>0、U_layer_pre>0、U_layer_post(q)>0。
- H + L + P + D_new(q) <= 0.25 * R0 + U_layer_post(q)。
- q不大于当前实持Q，合法整手向下；无永久R0单次限额，无一手豁免。
- 首探Q=0不经过新成长门，原初仓数量公式与资格规则不变。连续分叉后的NAV、现金和库存可以使实际首探数量、成交或重入不同，必须报告这些内生差异，不承诺所有原试仓都成交。原退出、入选、优先级、池迁移、现金与风险约束不改。
- 0.25只是固定研究假设；不扫描，不为窗口表现调整。

U_layer_post(q) = (Q+q)*known_open*(1-0.0005) - dated_sell_fee(Q+q) - C_layer - q*buy_price - dated_buy_fee(q)。
只使用前收盘决策已知保护、当日已知开盘、实际可用费用版本。分红不冲成本，不纳入U；原财务现金与分红应收照旧。

## 同一成本账与损益恒等式

每笔买入的gross+buyfee完整进入该实际层成本。实际卖出parts由原引擎指定层与股份，净卖出现金为真实订单总gross-sellfee按股数比例分配，不能再扣一遍费用。
卖出某层q_s/Q_l时退休成本K_ret=C_l*q_s/Q_l；realized=part.net_cash-K_ret。剩余C_l-=K_ret。H只累计当前回合真实追加层max(0,-realized)，盈利不冲销H。种子层不记入H，但其损益另列审计。
L只估计仍持追加层的max(0,C_l-protection_net_l)。卖出的数量/成本不再保留在L；未来抬保护只影响剩余L，不回写H。
Δ_after = Δ_before - (K_layer_retired-K_avg_retired)。买入在两账同加实际现金，因此不改变Δ。
每回合实际买入现金 = 已退休逐层成本 + 尚存逐层成本（无拆股零股异常时）。
每回合 realized_total + current_net_liquidation_profit = 累计卖出净现金 + 当前净清算值 - 累计买入现金。
分红另列；该恒等式不是“保护线保证成交”，H+L也不保证跳空损失上限。

## 在途与拆股

P为同股真实追加单尚未成交/撤单未确认部分的保护本金损失估计，基于权威订单的剩余gross和fee预占减剩余保护卖出净值。先reserve，后fill；fill将实际成本转入L，释放对应P，不把同一部分同时保留。cancel_requested不释放P；只有cancel_ack释放。首探在途不算P但原现金储备必须保留。禁止在原回调尚待确认时准入。

拆股遵守原层股数分配：每层floor(q*ratio)，余数按原层顺序逐一分配，使总股数等于原证券账。正剩余层总成本不变，原平均成本总额不变，R0/H不变，adjusted保护不变而raw保护随factor转换。在途货币预占不变，仅股数与每股价格变。
若拆股使一层归零但残留取得成本，当前“只由实际卖出记H”无法唯一归因非现金成本转移：标记UNKNOWN，禁止该回合成长追加，不能默认零损失或自行转给别层。若出现同一seed订单多次成交创建多层，当前第一实际fill的R0合同也标记UNKNOWN，先审计，不能悄悄扩大R0；原首探仍不被新门否决。

## H不是全回合亏损（固定定义，不暗改）

主H只计true_add各实际part负损益，不计种子层亏损；实现盈利也不增加预算信用。并行诊断H_all统计所有层的累计负损益，realized_total报告全部层累计实际净损益，不能把H或U_layer称为全回合净利。
种子100股@20，追加100股@10，市价15，种子卖出亏500后，H仍0、H_all=500、剩余U_layer=500，而全回合净利仍0。原U_avg门可能另行拒绝；即使两门通过也只说明剩余持仓盈利，不说明全回合已经回本。
同一mark下实际卖出part收益r，成交/费用差epsilon：U_layer_after=U_layer_before-r+epsilon。true_add单part的(U_layer-H)变化=-max(r,0)+epsilon。多part须逐项取负损益，亏盈不能先轧差；混入seed则另减seed的r。
全回合逐层累计realized与平均成本realized之差=Δ；两种口径realized+未实现清算收益相等。所有这些恒等式由状态测试验证，实际引擎还需用原parts净现金复核。
