## 门的严格定义与实际作用

对全股票当前剩余持仓数量Q和平均含买费剩余成本K_remaining：
- 买入：K ← K + 实际买入gross + 买费；Q增加。
- 部分卖出q：K ← K×(Q−q)/Q，再减Q；无论卖哪层、属于哪池都同比减成本。卖出盈利不抵剩余成本。
- 送转：按原账户实际舍零数量改变Q，K不变；Q归零则K归零并结束回合。池迁移不改变K。
- 分红不抵K。应收股息不等于实际到账，不用于制造可用现金；沿用原引擎支付日/现金可用性假设，未补造缺失到账日。
- 执行时O为已知raw open，V=Q×O×(1−0.0005)−原dated费率表估计的卖出费用（使用该股票par及卖价O×0.9995）。Q>0且V≤K拒绝买入；必须V>K才过新增门。Q=0仍用原试仓资格，并非自动买入。

全期160303次门判定，738次为负，去重股票日也是738；其中621次原价Q×O−K已亏或持平，117次原价微盈但不足5bp与预计卖费。不能把所有负判定都叫下跌摊平。funding中只有57条结果仅含此门，681条还有原现金/行业等约束：后者只称伴随拒绝，不称独立阻止成交。即使57条是单独门原因，也不把其金额直接称节省现金或可收回收益，后续资金分配会改变。
