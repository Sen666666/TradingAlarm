# 成熟量价指标与原 E0 / G / I / CP / PVR：证据综合备忘

本次整理日期：2026-11-06。用途：本项目后续研究与汇报。仅核对既有源码、报告、封存结果及公开指标定义，没有重跑指标、排名或资金账户，没有订单，没有覆盖原文件。

## 一、现在能成立的判断

1. 原体系不是“缺少趋势指标”：G已有EMA5/21对数收益速度、S21/S63量价事件结构及新证据升温锁；CP已有新价格前沿、冻结尺度、凭证消费及保护候选；PVR已有逐日正负收益和成交额调制。再加MACD、RSI或均线，首先面对重复计量，不是默认多一个独立证人。
2. 真正不同的观察量包括H/L范围及边界迁移、单日收盘位置、原始股数方向、实际成交均价。已有实验说明“输入不同”不等于“更能挑出下一笔赢家”：Stochastic、H/L摩擦、均价双前沿都未支持晋升。
3. 目前没有已核实的新融合达到约35%的费后完整0→0净胜率，同时保住赔率和大行情。未跑新账户的机会收益、AUC、原回合保留子集比例，都不能冒称新胜率。
4. “不亏损才加仓”已经完成完整账户对照，不是待跑方案：胜率25.7045%→25.6333%，金额赔率2.6652→2.7392，最大回撤47.7166%→43.9267%，末值只增加1,824.59元。不能再把它包装成35%选入质量突破。
5. 下一步只保留两条有明确不同输入、尚无等价实测的机制检查：CMF的单日收盘位置与股数联合信息，以及DMI的高低边界有向迁移。它们只是值得优先证伪的候选，尚无正面效果证据；不自动启动账户。

## 二、证据等级、统计分母与时钟

- **未测**：只有定义、数学比较或提案，没有该消费者的历史效果。
- **病例/机制**：少量固定股票及其前缀，或者原实际已填单样本的诊断。全2693次原首仓仍是已获资选择样本，不等于全机会。
- **全机会层**：例如53121条、1631股、796日的原PVR合法空仓MOBILE母体；资格、持仓、pending、ACT等条件沿原账户。它不是新策略重排后自然会出现的母体。
- **账户层**：资金、加层、退出、费用、持仓交互均重放的既有模拟账户；仍非真实成交证明，也非样本外。

本批主研究截至**2026-05-15**，2026不是全年。旧通道/退出研究有其他起止区间，不能拼收益。2022—2026已反复消费，是研发历史，封存先于本次标签读取也不会恢复样本外身份。

所有当日收盘、H/L、amount及完整指标均在收盘后才已知；信号评价从下一共同交易日OPEN开始。不得用下一日H/L/close证明同一OPEN本可准入或成交。当前含自身上轨、前日已知上轨、持续I.target、当天i_buy和fresh CP分开。未知不是零；股数、金额、复权价格不能混坐标。涨跌停、ST、T+1、停复牌、真实盘口与开盘排队限制仍在。

大行情标签也至少有三种分母，不能横比计数：
- Stochastic/RSI等沿固定sid/epoch首次合法MOBILE机会，早捕常用出生日至+5共同日，含首日共最多6日。
- raw-share/dual-frontier用已知原生I根及各自5/20/60捕获窗；dual-root价格标签还从根出生而非新收据日起算。
- no-loss-add账户用冻结原I事件、前6日实际代理日末持仓。715、334、4373、4359等不代表同一个母体。

## 三、原公式的准确职责

记C为同源可比收盘，A为实际人民币成交额，r=ln(C/Cprev)。

**E0事件**：极值日e冻结此前63收益RMS，σe=max(1e−8,sqrt(mean(r²)))。极值后平均活动量相对极值日前21中位量，a=clip(sqrt(mean(V_after_e)/median(V_prior21_at_e)),0.5,2)。相反方向log位移×a达到sqrt(5)σe时才确认转折。极值发生日和确认日不同。E0结构floor及持有状态再消费事件，旧线先检。源码字段V为volume；不能未经适配核对将它统称amount。

**G / I**：μh,t=2/(h+1)r_t+(1−2/(h+1))μh,t−1，h=5,21；z_h=sqrt(h)μh/s。S21/S63是有锚、前沿及量信用的结构，不是过去21/63日收益，也不是价格均线。G由速度正负、结构方向、急性推进/破坏及新证据升温锁组成；它是有序证据编码，不是成功概率。I的机会要求E0 shadow有效、G≥2、且E0新开或fresh_up。I持有延续不等于每天i_buy；I-only持有退出不是一降温就卖。

**CP**：s=max(1e−8,1.4826 median(|r|前63))；z=max(s,ln1.001)。
u=tanh(r/s)，b=tanh(ln(A/median(A前21)))，m=1+0.5|u|b。
p=lnC；仅新frontier增量δ增加信用K←K+δm；位移D=frontier−anchor。fresh且D、K均≥sqrt5×锚日冻结z才发证；candidate=C exp(−sqrt21×冻结z)，然后消费并重锚。普通回撤不直接扣K，但不是每次恢复旧高都重复记新前沿。I失效、native-down、SEEK降锚、source reset与receipt各有明确重置语义。当前适配中e0_valid实际来自I.target。

**PVR**：e=um，E=Σ(k=0..20)w_k e_(t−k)，w_k=.9^k/Σ(j=0..20).9^j；PVR=50+50tanh(2E)。它保留有界相对幅度，不只是上涨天数；m不是真实买卖流。PVR每天正负推进都入账，CP只记录本事件尚未消费的新前沿。s不是中心化MAD，E0的RMS也不是中心化标准差。恒定非零收益时二者仍为正。

## 四、成熟指标地图：数学观察量、重叠、可借鉴与证据

参数是标准示例或原冻结值，非项目最优值。EMA_n用α=2/(n+1)；RMA_n用α=1/n，首n值简单均值初始化；分母零/来源断裂须明示UNKNOWN或原约定，不偷补强弱值。

### A. 方向、速度、加速度

| 指标 | 数学定义与观察量 | 与原体系重叠/差异及当前证据 |
|---|---|---|
| 1. EMA | EMA_n(C)=αC+(1−α)EMA_prev | 价格水平平滑；G平滑的是r，不是价格线交叉。EMA9>21>50且三线上行的旧入口门四I池收益全降；EMA20/60退出已到账户层，无通用晋升。 |
| 2. ROC/动量 | ROC_n=100(C_t/C_(t−n)−1)；log版Σr | 端点位移，强烈重叠G/H1/PVR的历史推进；不含路径、保护距离。这里未另测ROC专属消费者。 |
| 3. MACD | DIF=EMA12(C)−EMA26(C)，DEA=EMA9(DIF)，hist=DIF−DEA | 标准价差单位与log版不同。log版DIF/7=EMA12 EMA26 r；hist/28=EMA9 EMA12 EMA26 Δr。G的(μ5−μ21)/8也是平滑加速度且更快。新负负荷融合在367合法病例前缀机会改变0条，停止。 |
| 4. Wilder RSI | U=RMA14(max(ΔC,0))，D=RMA14(max(−ΔC,0))，RSI=100U/(U+D) | 上/下幅度比例，记忆跨CP锚；与PVR双向贡献重叠，但无其有界相对额调制。RSI式量价Q替换及Q折减正PVR均已全机会失败。标准RSI14只作病例解释，不能把Q结果冒称原版RSI14交易系统测试。 |
| 5. DMI | a=H−Hprev，b=Lprev−L；+DM=a当a>max(b,0)，否则0；−DM=b当b>max(a,0)，否则0；±DI=100 RMA14(±DM)/ATR14 | 比较相邻真实高低边界迁移；原G/CP用close前沿，信息不完全相同。旧10/25仅理论职责对照，本次检索未找到等价全机会消费者；未测。 |
| 6. ADX | DX=100|+DI−−DI|/(+DI+−DI)，ADX=RMA14(DX) | 无方向的迁移一致性。大下跌也可高ADX；不能将ADX>25当上涨许可。进一步平滑滞后会损伤早启动，未测该硬门，也不建议现在测硬门。 |
