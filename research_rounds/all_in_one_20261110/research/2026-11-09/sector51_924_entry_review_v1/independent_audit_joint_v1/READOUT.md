## 资金不等于风险

2% 是单次 ADD 含费买款预算，4% 是整轮资金槽，都不是亏损上限。6 次 ADD 的此前整轮开盘净利，均不足以覆盖按当时已知保护线精确卖出新增层的假设损失。

例：601222.SH 的开盘整轮净利只有 1.84498 元，仍按冻结规则加买 23,580.29208 元；新增层在精确保护价卖出的假设损失约 1,511.17 元。这只是解释资金与风险的差异，不是新增风控门槛，且该假设忽略 T+1 与跳空，不能当成最大损失。

## 小样本公式边界

strength 只要求连续两日半数及三日净扩散为正；sector TRUE 另有 n>=3。完整识别表存在 17 个 strength=TRUE、state=FALSE 的行业日：互联网电商 3、珠宝饰品 2、社会服务 6、综合企业 6。N=1 和 N=2 的行业在冻结 state 规则下永远不能产生 TRUE/A/B。

已有成熟轮在 sector FALSE 时不会仅因此退出，且 ADD 未另加 state TRUE 门槛，因此小 N 行业理论上可能在 FALSE 但半数加强时 ADD。当前已认证前缀的 6 次 ADD 计划收盘状态全部 TRUE，没有实际触发这一边界。没有改规则，不可把 strength 个数写成 sector TRUE 个数。
