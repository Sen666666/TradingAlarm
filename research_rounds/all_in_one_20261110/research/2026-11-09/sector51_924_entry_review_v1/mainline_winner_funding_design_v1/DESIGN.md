## 2. 唯一可反证机制：新 MATURE SEED 不得挤出“删新种子”对照中的既有资金用途

不是“盈利就不卖”，也不是建立共享风险池。对每个决策时点，先按完全相同的账户、原 M7 公式和当时事实，构造一个**只删除新 MATURE SEED 请求**的当日筹资影子。新种子只可使用不会增加健康确认 lot 卖量、也不会降低影子本已能成交的合法 ADD/EVENT 数量的剩余融资空间。RESIDUAL 仍只使用原顺序最后剩余现金，不额外保量。

它改变的是一个边际资金竞争许可，不改 A/B、M、E、W、CP/I、进出场保护、股数经济性、费率和储备比例。两个不等式是同一“加入新种子不得挤出既有用途”规则的供给/需求两端，不是两套股票筛选因子。

### 2.1 角色与健康状态

M5 acquisition role 在实际买入时固定：
- EVENT/RESIDUAL SEED = INITIAL；
- MATURE SEED 和全部 ADD = EXPANSION。
本规则不把 EXPANSION 改 INITIAL，不添 core，不永久冻结行业，原固定/T+1/不可卖数量都不放松。

对原本可融资的 lot l，记 H(l,t)=1 当且仅当：
1. 同一真实 round 有 post-SEED CP receipt，且已完成既有 INFORMATION_CONFIRMED 的下一 OPEN 信息确认，具备同身份 CP 来源；仅 CREATED、入场前 CP、或“后来买过 ADD”单独都不够。SEED 当日 OPEN 之后的 CLOSE receipt 合法。
2. 当时该 round 全部已发生现金流+股息权益+所有存量按当前价模拟清算，按既有费用/滑点计 net>0。0 是现有盈利方向判定，不新增收益率阈值；不要求这些利润覆盖本金或 ADD 风险。
3. lot 当前有效保护线可知，I 仍有效，当前价严格高于该线，没有既有 round/lot 退出锁。SEED 用当前 I；ADD 用当前已抬升的 CP/I 有效线，不回退到买入旧 CP。
4. 报价来源、因子/公司行动桥、I/CP 状态、行业/个股状态等原融资所需字段已知。M3=0 或 M=0 不自动等于结构破坏；常山属于“动量弱但 lot 结构未破”，不是当前强势股。

状态必须分开：
- VERIFIED_HEALTHY_POSITIVE：以上全真，有当日竞争待遇。
- STRUCTURE_FAILED：I 明确失效、OPEN/CLOSE 破有效保护或既有退出锁；原保护退出优先，不进入可选融资保护。
- KNOWN_NOT_QUALIFIED：完整已知但没有真实确认、或清算净利<=0；按原规则供资，历史盈利不保级。
- UNKNOWN：关键数据缺失/无合法类型/来源或桥不可知；不推断 healthy/failed，不新增交易许可，沿原冻结/暂停/原block处理并单独报原因。

未突破保护的盈利仓仍可在影子需要时卖出。净利不正或结构失效后待遇消失；股票完全退出再入场是新 round，不继承证明。它没有“错误仓终身占着钱”的授权，但慢跌至旧保护前仍可能被保留，属于必须验证的风险。

### 2.2 保留原 M7 总资金公式，影子必须真的删除新种子需求

记 R_t 为经原原始资格、dated rules 与非现金约束得出的请求。
N_t={r: kind=SEED 且 allocation_phase=MATURE}。
B_t=R_t\N_t，保留原其他请求及其先后关系。
A_t={r∈B_t: kind=ADD 或 allocation_phase=EVENT}，这是受不挤出数量约束的合法请求；不把入场 CP 等同于成交后的 ADD 验证。
RESIDUAL 仍属于 B_t，但沿原尾部现金顺序，不设 q0 下限，也不因为影子出现剩余现金就取得融资优先权。

影子 P0 = OriginalM7Planner(account_t, B_t)。
不能把含 N_t 的实际 D/X/T 拷贝给影子，否则新种子仍可经 sector target/floor 改变健康 lot 卖量。

影子和每次实际候选都重算**原公式**：
W_s=E_s+max(0,E_s-E_{s,prev})，保留原前值 unknown 规则；
D_s=当前请求集合的原独立合法 MATURE 买款需求；
U_s=K_s+D_s；
X_total=min(max(0,free), sum_{eligible sectors} U_s)；
各行业 X_s 用原 capped_water(W,U,free)，K 不是下限，W 只相对分配；
T_s、envelope、行业 floor、receiver/donor sector 排斥均依原公式重新导出。

E 本来连续逐日算、没有在 M=0 时截断。本提案不以“M 首次打开导致 E 跳变”为动机。既有 cash reserve、event reserve、receivable、冻结仓与 stress 都按同一个相应规划快照重算，不能从旧目标中偷出现金。

### 2.3 可计算不等式与有限执行

P0 必须是一个现金/股数/fee 可行的**当日成交投影**，而非仅“想买”列表。它不实际写订单、不推进 CP/票据/事件状态，不处理未来日。
q0_r = 影子可成交买股数；y0_l = 影子可成交融资卖股数。
实际候选 P 满足：
- 对所有当前 H(l,t)=1 的原 mobile lot：y_l(P) <= y0_l；
- 对所有 A_t 的请求：q_r(P) >= q0_r；
- 所有原 stock/sector/reference/event/容量/dated lot/T+1/保护/cash reserve 约束保持；ADD 可缩量但不能低于当前影子可行量，SEED 保持原经济股数的不可拆规则。
- 本影子之外不保证所有原 full-M7 ADD 数量不变。保证对象仅是相同当日账户“删 N”对照中可融资的量，不是历史基线的全账户数量。

确定性处理：
1. 在完整 R_t 上取得原请求排序，冻结新 MATURE SEED 的退让顺序（原 rank 从末到首，同分用原 sid/身份顺序），不使用事后收益。
2. 用当前仍保留的 N 子集和全部 B，重算原 D/X/T。联合规划买入、必需卖出、费用和储备，给 H donor 加 y0 上限，并保证 qA 下限。其他 donor 顺序/卖出最小股数保持原规则。若原目标本身不能容纳 qA 下限，判本次子集不可行，不能突破 T 硬买。
3. 若本次不可行，移除尚保留的最低原优先级新 MATURE SEED，重算原公式。最多移除 |N| 次；N 为空时与 P0 相同，必然有可行回退。过程中不保存真实订单，不反复消费 EVENT 优先资格/CP receipt。
4. 在首个可行子集内，按原排序选择交易，剩余自由现金不强制填满；不新增入场等待时钟。退让票保留原身份并按原资本等待生命周期处理，明日重新竞争。不存在“最后几笔新SEED必须买”的承诺。
5. 健康 donor 仅可卖到影子量；部分出售按原 sell_quantity、lot规则与费用。未确认/净亏/结构失效仓不因此获得冻结。所有数量同时算，不先卖再猜谁能买。

这比单纯按现金来源“标记 ADD 钱”严格：现金100、ADD100、新SEED100、健康donor100 时，若无N影子无需卖 donor，则 y0=0，新SEED不得借“卖赢家给ADD、原现金给seed”绕过限制。相反现金0、合法ADD100且原影子确需卖健康donor100时，即使有新SEED排队，也不会禁止这笔正常轮换。

该有限退让可能比全局最优组合保守：它不搜索不同 seed 子集的最优收益，不重写股票优先级。可能舍弃可被不同组合容纳的种子或留下闲置预算。该代价需报告，不能偷偷上背包选股/分数优化补救。

## 3. CLOSE→OPEN 合同：必须在卖出前完成可行性

CLOSE：
- 先完成原 I/CP 更新与保护锁、事件状态、票身份；以同一快照构造 full/无N shadow，两者只读副本。
- 原所有资格先算，才得到独立 D；不让被原资格拒绝的需求进入任何影子/目标。
- 按上述有限过程完成联合买卖计划，冻结最终 receiver 股数上限、两套相应参考目标、逐 donor 可卖数量和所属规划快照。为保证无N回退可执行，保留最终计划及无N影子 donor 的并集作条件候选簿，逐lot上限只取其已经在CLOSE合法规划的上限；这不是卖出指令。
- 对健康 lot，实际量始终受影子量上限。并集不允许一个 lot重复供资；不同计划的sector floor不能择低拼贴。执行时必须使用所选完整规划的合法 floor。
- Event reserve 与现有 holdings/保护冻结部分不反复计入；使用整数股数、逐单费用和同一储备，形成一份完整现金账。

OPEN：
1. 先按原顺序处理已知/跳空保护退出、公司行动和T+1；强制退出不被H挡住。
2. 在同一个真实OPEN状态上，先验证所有receiver的CP身份、有效保护、整轮正净利、open价/容量/dated rules等。失败 ADD 不保留需求或shadow下限。
3. 使用各自 CLOSE 冻结参考计划与 OPEN 当时可知价格/实际现金，投影无N影子（只用前晚候选簿，不增开新donor）；得到新的可行 q0_open、y0_open，均受前晚数量上限。不能用当日 CLOSE 的 M/E/F 更新OPEN。
4. 实际候选在前晚保留的新SEED中按同一冻结退让顺序缩减，重新求联合可行解。原W公式和CLOSE证据不变；投影不得扩大任何前晚授权股数。不通过原结构/CP/费用重核的需求必须在donor卖出前移除。
5. 若加入新SEED会增加当前健康lot相对shadow卖量，或挤掉shadow仍可融资的A，则退让新SEED。无N回退通过影子候选簿和影子相应floor完成，不拿实际full参考目标冒充shadow目标。
6. 买卖整本均可行才提交研究账单。不得“卖完赢家再在买入循环末端拒绝新票”；若未知/桥/费率令回退也无法认证，沿原atomic block，不扩大候选池、不偷用现金buffer。
7. 信息确认/CP consumed/事件spent/ticket成交只对最终真实成交更新一次。未成交的影子不是真实历史证明。

OPEN时原H变成不合格不构成临时扩大卖量的授权，仍守前晚上限；新变H的原mobile lot亦重核shadow上限。若这使full计划不可行，先退让N；A的保证是此时同样约束下的可行shadow，不是对跳空/未知的保成交承诺。

## 5. 可失去什么、不能声称什么

- 可能保住常山CP未破层，也可能推迟今世缘等真正新主线MATURE SEED；9/24无融资时不加等待不代表9/25以后无机会成本。
- 光伏短期变弱是真的，留住未破CP的旧盈利层可能回吐。它只比“行业M=0立刻供资”更尊重已验证结构，不预言反弹。
