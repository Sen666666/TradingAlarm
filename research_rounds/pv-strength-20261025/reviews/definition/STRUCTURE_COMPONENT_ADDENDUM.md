# 双边结构三分量提案审查

2026-10-25。在完成独立定义审查后，主研究者提出：沿用冻结E0量价摆动事件，保留最近两次已确认高点/低点，以高点进展、低点进展及最新确认极点到当前价的局部推进，分别波动归一化、连续映射后等权平均。E0状态不改；新输出不生成买卖。

**裁决：可以作为一次有限的“结构进展分量”原型画图；目前不足以宣称完整、跨时期可比的趋势强度。** 去掉旧`swing_frame`的“两边异号即归中性”是明确修改，允许保留冲突，值得检验。下面的问题不能靠名字或均值的平滑外观消除。

## 1. 局部项从旧确认极点量起，未必代表当前动作

例：低点100确认后一路涨到130，随后跌到120，但130这个高点尚未被确认。若局部项为`log(120/100)`，它仍显著为正；当前从130回落的反向压力没有进入局部项。130高点一经确认，局部锚改为130，分子立刻变成`log(120/130)`，符号翻转。

这次确认有因果新信息，允许跳分。但如果相邻两天只小幅变化，分数大跳主要来自换锚，不等于当日市场力量突然反转。同一确认还可能更新高点进展项，构成同一事实对两个分量的同步作用。若再让发展中高点扩展高点进展，当前上涨又会同时进入结构项和局部项。

最低要求：图检和逐日表保存局部锚身份、锚价、发生日、确认日，以及换锚前后同一当前价计算的分量。必须区分“新增价格变化导致的变化”和“新的确认令表示换基准”。不能把这类跳分全部描述为新量价压力。

可修的方向只有两种，需在输出前选定：

- 保留此局部项，准确称为“相对最近确认极点的位移”，不称当前反向压力，并明确旧峰等待是本原型限制；另用已存在的诊断展示回撤，不据此追加策略规则。
- 若目标确实是当前压力，明确计入正在发生但未确认的反向运动，并保留父方向。必须写成独立的因果更新，不可等结果后临时换锚。其信息与旧摆动/已有压力机制是否重复，由相同合成路径核查。

## 2. 饱和三项均值会结构性压制反转

若`S=(f(h)+f(l)+f(c))/3`且每项在`[-1,1]`，当`f(h)>0.5`、`f(l)>0.5`时，无论局部项多负，S都不能变负。双结构项都接近1时，S最低约为`+1/3`。负背景中的快速新启动有对称问题。

这个性质不是实现bug，也不由换一组权重根治。它说明S主要是**有结构记忆的背景投票**，不能同时宣称是随当前推进充分转强转弱的量。若两个结构项尚未更新，局部反转的再大幅度也会因有界映射失去影响。

可接受此取舍，但要在协议里写明：新启动首先体现在局部项，主S可能仍偏旧背景；最终转向依赖新结构确认。严禁在图后为某次大反转加特殊放大权重。若用户要求一条线立即反映当前主导强弱，提案还未满足。

## 3. 不同覆盖度的平均不能自然比较

只出现一个确认低点的单调上涨，可能长期缺两组高点和低点，只有局部项可算。若平均现有项，局部项0.9就显示0.9；后来两结构项首次出现为0.1、0.1，完整均值降到0.367。市场未必新转弱，变化来自覆盖数和权重分配。

把缺项填0也会误称未知为中性。最低处理是：完整三项S只在三项齐备时有效；未齐期间单列局部方向及覆盖度。若为连续图显示`partial_S`，须明确它与完整S不是同一口径，不混作跨资产排名。日期/未齐原因均记录。

这会真实暴露冷启动代价：严格等已确认两组极点，可能长时间无法给单调慢涨或无回踩启动一个完整S。允许未知比虚构更高低点诚实；但不能同时报告“快启动和慢涨问题已经解决”。历史有足够旧枢轴也不等于新上市或合成冷启动同样可用。

## 4. 时长和波动分母决定了测量对象

`delta/(sigma*sqrt(delta_t))`是“相对跨度噪声单位的位移”，不是速度：

- 同样总位移，跨度更长，分数按`1/sqrt(delta_t)`下降。
- 同样每日期望位移，累积更久，分数按`sqrt(delta_t)`上升。
- 新高增加分子，但极点当时波动增加更多，分数也可能下降；这是归一化改变，不应自动解释成市场绝对推进变弱。
- 高点间隔与低点间隔不同，且极点选择和确认时间由同一路径内生决定。三个分量相关，无法按独立证据相加解释为置信度。

每项必须保存原始位移、所用sigma的取值日、发生间隔、确认间隔和确认延迟。明确sigma是后一个极点发生时、确认时，还是其他时点的信息；任何一种都要因果可得。不能在未来确认高点之后修改过去发生日输出。

可称同一工程规则下的描述性尺度，不可据此承诺相同S意味着相同未来概率、损伤风险或经济强度。不同证券/时期的事件频率、确认延迟和背景波动差异仍存在。

## 5. 对提案的最小验收清单

1. [定义合同](REVIEW.md)F01同端点异顺序、F02下跌反弹、F03慢涨、F04单脉冲、F05共同整理前缀和F06旧涨幅仍正的转弱，全部展示三项与S，不能只画均值。
2. 增加“100→130→120，未确认/刚确认高点”的事件邻域；解释局部项和高点项跳变来自何处。确认前已知的130不能在确认日被描述成当日新发生的价格。
3. 同一路径比较只有1项、2项、3项有效的阶段，逐项核查任何分数跃迁是市场证据变化还是覆盖口径变化。
4. 单调涨、短促V反转和漫长窄幅下行不得被自动排除。若完整S缺失或响应迟，保留为明确代价。
5. 全局量单位缩放不改输出；相同价格不同量至少改变一项预定结构证据的确认/冲突。仅继承原事件生成器不能替代这个本轮核查，也不需要证明每次改量必变。
6. 分数变弱、变负或覆盖不足均不产生交易动作。旧E0逐日身份不变。

不建议现在追加新家族、更多滤网或调三项权重。先用这一次原型把取舍显示出来，再作支持/否定/证据不足裁决。若问题只是旧确认事件的描述性投影，可如实结项；不必为获得“成熟强度”名称继续无限修改。
