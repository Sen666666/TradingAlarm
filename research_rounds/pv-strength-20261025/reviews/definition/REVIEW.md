# 趋势强度定义独立审查

2026-10-25。审查对象是新原型的语义和可证伪要求；没有查看、调整主研究者的新候选代码，没有运行账户或交易映射。冻结E0保留。本审查只写本目录，外部资料未使用。

**建议把趋势强度定义为“当前量价路径中，某一方向持续取得新进展、承受反向运动后保持或恢复这种优势的程度”。** 它是对已观察路径的描述，不是上涨概率、未来收益、交易安全度或持仓浮盈。必须同时保留方向背景、当前推进和反向压力的证据；单个显示分数可以存在，但不能让分数承担这三种互相冲突的语义。

强度下降只说明证据转弱，可以发生在仍有效的上行结构中。它不自动触发卖出、减仓、止盈或禁止恢复。开仓和卖出的选择留在后续策略层；本轮不生成这些规则。

## 1. 什么能称为新增信息

以OHLCV为输入，所有输出最终都是它的因果函数；“不是涨幅的改名”不意味着不准使用收益、波动或斜率。区别在于：**新表示能否保留端点涨跌、无序价格分布或持仓账之外的、已明确命名的路径信息，并在反例中按语义响应。** 不要求发明新算法家族。

至少区分以下信息：

| 对象 | 可以表达 | 不应冒充 |
|---|---|---|
| 绝对推进 | 每个观察日的新价格位移、速度、扩张幅度 | 方向稳定程度、未来获利大小 |
| 相对推进 | 推进相对于近期波动/往返路径的份额 | 绝对速度；经济显著性 |
| 方向背景与损伤 | 此前接受的推进是否仍有效、反向运动尚未收复多少 | 当前正在加速；账户止损线 |
| 当前强弱 | 新进展与反向压力的关系及其持续、恢复过程 | 只要高于旧低点就始终强；当日大涨就已完成反转 |
| 量的证据 | 相对参与程度改变某次价量运动的接受、冲突、撤销或恢复 | 已观察到净买入、吸筹、派发、投资者成本 |
| 横向排名 | 同一时点同一参照下的相对位置 | 绝对强度；上涨概率 |

低波动慢涨可以有很高的方向稳定程度，同时绝对推进不快。这两个事实不矛盾。强下跌后的暴涨可以有很强的局部修复，同时旧下行背景尚未解除。若只提供一个分数，这两组含义必然被压缩；必须明确该分数的投影含义，并让诊断表仍能还原各项证据。

不能要求一个因果模型同时做到“快速启动即确认将来是大赢家”和“对完全相同的早期反弹不升强”。二者直到未来分叉前可以有完全相同的OHLCV。可以评价响应速度和后来撤销的证据，不能用未来给共同前缀贴不同标签。

## 3. 必须通过的合成反例

以下是**新候选输出前就应冻结的语义合同**，不是按未来赢家倒推的精确分数标签。数值容差、预热长度、反应时限和成熟度含义由候选协议先写定。不能看结果后为某路径更换尺度或阈值。

统一用对数价格`y`定义路径；`C=exp(y)`，`O=上一收盘`，`H=max(O,C)`，`L=min(O,C)`可构成最小合法OHLC。需要长影线时另加并明确这是新对照。成交量先固定1，所有比较使用相同预热。候选若需要更长预热，只扩展共同前缀，不改变反例后段。

| 合同 | 冻结输入 | 必须能证伪什么 |
|---|---|---|
| F01 同终点不同顺序 | 共同预热后，A收益`[+.04,-.06,+.04]`，B`[+.04,+.04,-.06]`，同量 | 至少推进/反向压力/所处阶段有可解释差别，能辨认A最新收复、B最新回吐。若所有输出仅取决于终点或排序分布即失败。**不要求最终单分数必然一高一低**，但不能完全丢掉区别 |
| F02 下跌中的大反弹 | 前缀一：先从`y=0`跌到`-.40`；前缀二：平稳上行背景；随后各接完全相同的4根收益`[+.02,+.025,+.02,+.015]`。第一条仍远低于旧下降起点和旧失败高点 | 局部修复可强，第一条尚未收复的下行证据不得因新腿起点重置而消失。若两条都自动叫“成熟强上行”、理由只有近4根涨幅，定义不合格。若协议把输出限定为局部动量，须直说它没有解决背景强弱 |
| F03 低波动慢涨 | 80日每天`+.001`；每第15日改为`-.003`，之后继续；量始终1。再与同幅度固定区间往返比较 | 在足够证据形成后应能表达持续的正向优势，不能因没有爆量或缺两组完整大摆动永久中性。它不需要高绝对速度，也不要求分数高于所有快速启动；区间往返不能被解释为同样持续取得新区域 |
| F04 单根脉冲 | 共同微小波动预热，单日`+.15`，后60日完全横盘；另设60日持续小幅推进对照 | 可以快速增强，接受后的结构也可以保留；但必须区分“一次水平重估后停留”和“不断产生新进展”。若分数持续高，须能在证据中看到其来源已陈旧、没有新扩张，不能写成持续加速。不要求横盘后卖出或自动破坏结构 |
| F05 正常整理与共同前缀 | 先有80日缓慢抬升，再20日约`±.015`范围内往返且不破先前有效下沿。把此共同前缀复制两次，一次接继续推进，一次接有效下破 | 共同前缀输出必须完全相同。整理期允许强度下降、反向压力上升，背景可存续；不能因短强度下降自动清空全部市场证据。分叉后的新价格/量价事实才可以改变判断；不能靠未来标签提前“知道正常” |
| F06 真正转弱但旧涨幅仍正 | 先从`0`推到`+.25`，随后以更低反弹高点、更低低点逐段退到`+.12`；保留普通量和低量两版 | 当前反向压力、受损或转弱必须在可见新证据下响应，不能等价格跌回研究起点、净收益转负才表达。低量不能把已经发生的价格损伤抹去；是否彻底翻转由候选的背景定义裁决，不规定卖出日期 |
| F07 区间重复与证据身份 | `0→+.03→0→+.03…`，上穿1/3/6次终点均`+.03`；保存每次接受/撤销/恢复的事件ID | 多次测试可以产生新“测试/恢复”信息，但不能把同一历史上升位移复活为独立新扩张、无限累计。不得要求所有末值强制相等；有区别须能归因到新事件，不能归因到重复占用的旧位移 |
| F08 同价异量机制反事实 | 同一价格路径：突破日量1或3；反向日量0.5或3；其后普通量收复，其他日一致 | 至少一个预定场景中量真实改变证据建立、接受、冲突、撤销或恢复的时点/状态。保存具体变化；不要求每次改量都改状态。放量下跌不能机械变强；普通量收复不能被“必须再次爆量”永久卡住，除非这正是待接受的明确代价 |
| F09 量单位缩放 | 全路径`V×1/10000、V、V×10000`；OHLC不变 | 状态、分数和事件日期相同，仅原始量字段换单位。不能用原始手数决定强弱。时点间发生拆股并非这个全局单位合同，须由输入口径另作处理 |
| F10 价格单位缩放 | 全路径OHLC同时`×100`，量不变 | 非价格值输出相同，所有价格参照同倍缩放。不能用绝对价格高低冒充强度；不要求对数位移幅度×10也不变，那是不同问题 |
| F11 重复价格/同质量分位 | 价格相同项合并前后、同价项权重交换；若用分位，调用所定义的同一经验分布 | 不允许在没有新市场信息时因排序实现改变证据。不能把这种差异称为识别了顺序；对真实跨日顺序保留什么信息另作F01 |
| F12 前缀、串流、未知 | 完整一次计算、逐观察增量、各关键日真实截断；同前缀接相反未来；预热不足、缺失日和无效OHLC | 相同前缀逐行同值，串流与批量同值；事件不得回填到枢轴日；未知不是弱势或中性。缺失日不凭空制造成交量、推进或恢复；不暗中把跨缺口压成一天 |

F01、F02、F04、F05的评价单位是完整输出和证据，不是强迫一条标量同时满足所有排序。若模型只想显示一条强度线，也应保存完整诊断，避免同一个“7分”分别指代高可信慢涨、一次暴涨或下跌反弹却不给上下文。

还要检查两类伪要求：

1. **不要求放大涨幅必然更高分。** 若强度定义为相对噪声的优势，尺度不变可以合理；绝对推进另列。反之若声称显示绝对速度，就应反映变化。
2. **不要求所有假突破低分、所有后来的赢家高分。** 相同前缀只可能有相同输出；错误与撤销代价需要保留。历史图中的“正常整理”只是事后诊断名，不能当时作为输入。

## 4. 一个可保留的简洁原型方向

建议只做一个“方向进展与反向响应”原型：每次更新保留**新进展、尚未解除的反向压力及其发生/确认时间**；方向背景跨过内部往返存续，由新的反向证据改变。强度是这些证据的公开投影，原始项仍展示。使用波动只是统一尺度，不让大波动残留长期把后来的慢性走弱隐去；使用量只改变某次运动的接受或冲突，不当成方向正负的万能乘数。

最小新信息应是“此前反向事件尚未收复/已收复，而这次是旧区域重访还是新的方向扩张”。它不是要把所有历史位移做正权抵销求和，不是只取当前位置相对旧低点，也不是每条新摆动自动删掉父方向。它与E0已有事件/结构信息重叠并不构成否决；新增强度到底提供了什么，要用上述反例及真实全轨迹证明。

该方向尚非冻结公式。若主研究者已经有一个更简单且能通过合同的原型，不应因本建议再另开一家族。尤其不要为了兼顾每条案例增加“长短均线+RS+量比+分位+止盈”规则堆叠。

## 5. 对真实图检和本轮结项的要求

黄金、半导体和几只股票均画完整已授权时期，先看OHLCV，再叠E0与新强度。至少保留快速启动、慢涨、整理、下降反弹、转弱和长期无新推进的场景；场景可以事后标注，不能用来更新输出。先写当时证据、替代解释和将撤销解释的下一事实，再看后续结果。不能只截命中启动的几段。

评价分开写：局部响应是否及时、背景是否在反弹中丢失、整理期是否只降强度而没有伪造结构破坏、量的作用是否能追溯、最终有哪些合理但失败的判断。旧E0的结构存续可作同图参考，不能把新强度是否等同E0当通过条件，也不能把E0换名为新强度。

**本审查裁决：支持实现并图检一个语义明确的强度原型；不支持把单一归一化涨幅、状态权重或结构是否有效直接包装成完整强度。** 上述合同通过只表明语义和因果实现较可信，不证明未来有效或经济优势。本轮完成可止于算法/图检裁决，没有账户、换仓、买卖阈值或E0机制变更的自动后续。
