# 候选B：带暂时位移记忆的局部趋势滤波审查

2026-10-25。设计审查。没有实现或运行B，没有查看B真实轨迹，没有账户、交易规则或E0改动。三结构分量提案已在设计阶段否决，本文件不把它的运行数计入候选。

**裁决：B可以作为一个假设明确、范围有限的描述性强度原型进入实现和合成核验。** 它的测量对象可准确称为“相对于自身近期波动的底层推进估计”；不声称已经能可靠区分快速启动、慢涨、整理、跌势反弹和真正转弱。暂时分量的存在及未来衰减预测构成实质机制差别；是否有用仍待反例和图检。不能将模式名称或高斯形式当成市场事实和有效性保证。

## 1. 接受的设计及其语义

状态`x=[L,mu,T]`，观测对数价格`y=L+T+eps`：

```
F = [[1,1,0], [0,1,0], [0,0,rho]]
H = [1,0,1]
rho = 2^(-1/5)

Q_normal     / sigma² = diag(.01, 1/21², .01)
Q_persistent / sigma² = diag(a, a/5², .01)
Q_transient  / sigma² = diag(.01, 1/21², 4a)
R / sigma² = .25
prior_mode = [19/21,1/21,1/21]
a = clip(V_t/median(V_(t-21:t-1)), .25, 4)
sigma = RMS(前63个已完成的日对数收益)

S = 100*tanh(sqrt(21)*E[mu]/sigma)
```

L是允许水平创新的潜在价格水平，mu是允许变化的每观察日漂移，T是模型假设会回归的价格偏离。T在没有新冲击时5观察半衰，21观察后预期仅剩约5.4%；这不是从股票数据中识别得到的“市场暂时性周期”。

`21*E[mu]`另列为**当前估计速度在21期的线性幅度单位**，不应称为已实现21期涨幅或保证的未来21期涨幅。S不含漂移后验标准差，因此它不是显著性、上涨概率或风险调整收益；后验不确定性应旁列。S下降不产生卖出、减仓或止盈动作。

## 2. 相对旧实现，差异确实存在

已复核`research_rounds/pv-competing-state-20261020/code/trend_competing_state.py`。

- 旧模型状态只有`[level,drift]`。“暂时冲击”通过当日较大R吸收，下一日没有独立的偏离状态，也没有由该偏离自身回归产生的预测。
- B把T作为带衰减记忆的状态，暂时位移与永久水平的后续预测不同，未来可见的保持/回吐会影响二者分配。它不等于只把旧shock权重改名。
- 旧量只等比例增加两个稀有模式的先验，在固定旧状态和当前价格时，跳变与冲击模式的先验比不随量改变。B让量进入不同Q，能改变Kalman增益、预测方差和后验分配，变化可以延续到以后的L/mu/T估计。
- B主输出从旧`E[drift]/SD(drift)`改为`E[mu]/sigma`的有界映射，主动放弃“漂移置信分数”语义，保留推进相对自身波动的解释。它仍是归一化漂移估计，不能声称完全摆脱了漂移/斜率家族。

这些是实现与语义差异，不能直接推导量有效或B优于旧模型。

## 3. 必须公开的识别限制

### 当日分配来自假设，后续才提供额外证据

一根观测只看到L+T，永久和暂时创新都能解释同一价格残差。模式竞争主要比较不同Q产生的预测分布；它没有额外观测到冲击来源。相同前缀不可能提前知道此后是继续保持还是回归。

不能笼统说整个状态系统“不可观测”：可观测矩阵为

```
[1,0,1]
[1,1,rho]
[1,2,rho²]
```

行列式为`(1-rho)²>0`。无噪声、动力学固定的确定性系统可观测；但带随机创新的L/T分解，在有限、含噪数据中仍高度依赖rho、Q/R、初值和后续路径。数学可观测不等于已从真实市场识别出永久/暂时冲击。

### 模式权重不是经济类别概率

固定F下，不同当前模式主要通过Q改变同一个残差的解释尺度。大预测方差对非常大的残差惩罚较小，也要支付方差的似然惩罚；`4a`的T创新方差使大残差更容易被暂时分支解释，这是设计偏好，不能写成数据已证明“大冲击往往暂时”。量改变此分配也不意味着量单独识别了永久性。

如果每观察日都使用固定模式先验，它表达当日创新类型独立于上一日模式的假设，不是永久/暂时“市场阶段”的持续概率。跨日持续的是状态L/mu/T及其不确定性，而非模式标签必然持续。模式名称宜在报告中同时给出具体方差含义。

### 突然水平重估不等于正漂移

一个正向永久水平跳变后完全横盘，正确的底层漂移可以接近0；不要求S因价格一直处于新高位而持续很高。负漂移背景下的大幅抬价也可能先进入L或T，mu仍负；这和旧模型已见的“价格已重估而漂移仍旧”存在共同风险。B增加T不会自动解决快速转强问题，必须在图检中如实检查。

相反，如果T先吸收正跳变，模型会预测其衰减；随后价格保持不跌，持续正残差可被重新分配给L或mu。这可能产生延迟正漂移。不能把这种由固定回归假设产生的修正自动说成新市场推进。脉冲后回归、跳变后横盘、持续漂移是三条必须同时保留的反例。

## 4. 输出前必须补齐的实现决定

1. **矩匹配具体层级。** 是每个旧分量生成三个新模式的9分支，再压成3个条件混合，还是每天合成一个高斯后再开3支？两者不是同一滤波器，必须冻结。旧模型采用9→3；B可选其一，但不能运行后更换。
2. **不确定性包含模式间差异。** 混合协方差必须含`sum(w_j*(P_j+(m_j-mbar)(m_j-mbar)'))`。只平均分支协方差会删掉永久/暂时分歧，虚构较高确定性。若层级压缩，层层执行同一规则。
3. **初始化。** 明确第一输出日L、mu、T均值及P0。mu0=0和T0=0是先验，不是已知事实；63期sigma可算不等于潜在状态已经成熟。不应把首日0强度解释为市场中性。
4. **sigma和分母。** 明确前63个收益不含当日；固定正下限及何时标未知。长期横盘使sigma趋零时，应避免数值漂移经除法变满分；单次脉冲抬高其后63期sigma，可能机械压低后续S。保存原始mu、sigma和未映射比值以区分来源。
5. **时间单位与缺口。** rho、mu和Q究竟按有效观察日还是市场日更新，必须统一。没有观察的日子不能默认为零收益或造量；长缺口的衰减/重启规则事先写定，不能把几十个市场日压成一次普通更新。
6. **数值稳定。** 似然用log-sum-exp，分支协方差用稳定更新并保持对称、半正定；所有模式的先验质量均正。全局价格倍乘最好先做对数平移以免极小差误。不得用事后削平不喜欢的低分或跳变修模型。
7. **显示。** 保存L、mu、T、预测价、残差、sigma、相对量a、三模式权重、mu/T不确定性、完整混合不确定性和S。L/T可以在同图旁列，主S明确只测mu。未知、未成熟和后验均值0分别标记。

## 5. 敏感参数与有限反证

rho、`.01`、`1/21²`、`a/5²`、`4a`、`.25`、先验`19:1:1`、21/63/5尺度、量截断、P0、sigma下限和矩匹配压缩均是自由度。它们是一次选定的工程假设，没有经真实市场识别；不得用“沿用月/季尺度”掩盖全部敏感性。

不建议现在搜索这些参数。先固定B，再以既有定义合同测试因果、单位、同端点异顺序、单脉冲/水平跳变/持续漂移、慢涨、下跌反弹、整理与转弱。特别增加：

- 两条完全相同的冲击前缀，一条随后回归、一条随后保持：共同前缀输出相同，分叉后T与L/mu分配才分离。
- 同方向同速度但振幅整体缩放的路径：检查S的相对尺度含义；同时看`21*mu`，不要求同一个S兼作绝对速度。
- 相同价格、突破/反向日高量和常量量版本：具体列出Q、增益、状态分配及后续影响。不能只报告“曲线不同”。
- 高量单根暂时脉冲随后回归，与高量启动后持续慢推：不能把高量机械解释成同方向强度必增。
- 截断重算、串流与批量、缺口、常价、零/异常量、价格/量单位缩放；原E0身份不变。

这些技术/合成检查通过仅支持“B实现了自己宣称的因果机制”。如果以后要做参数敏感性，应另冻有限邻域，只用于说明结论是否脆弱，不按最好真实轨迹替换中心参数。本审查不要求为形式完整而立即增加多组参数运行。

**设计结项意见：有条件支持B作为一次算法/图检候选。** 条件是先写定以上实现细则和解释边界，而不是先证明B能完美分辨五种走势。参数先验和L/T可替代解释须伴随结果保留。没有账户准入、交易阈值、换仓或替换E0的自动授权。
