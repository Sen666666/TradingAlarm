# 候选 B：持续趋势与有记忆暂时价格状态的设计审查

日期：2026-10-25。审查仅使用提议公式、线性代数及旧实现源码；**没有读取新模型真实轨迹结果，没有运行账户，也没有修改模型或根文档。** 本文不是候选已通过图检或经济检验的声明。

## 裁决

**有条件准入一个有限轨迹原型；不在设计阶段否决。** 与旧 `competing_frame` 相比，保留跨日的暂时价格分量 T，确实让冲击在未来产生不同预测，而不是仅把当日异常观测当测量噪声。成交量进入过程协方差，会改变冲击分配及后续价格解释，满足值得进行 C04 机制核查的最低条件。

同时只可称为**固定动力学假设下的统计分解**。不应把 L、T 或模式名称写成已经识别真实永久重估、资金行为、知情交易或市场真实状态。理论可观测不等于有限 OHLCV 路径上经济含义已经识别；新公式有资格接受反例检验，不等于已解决五类走势表达。

主分数必须命名为类似“持续漂移强度”，而不是完整综合价格趋势、下一期上涨概率或交易资格。并列 T、原始 mu、模式权重及不确定性；分数下降不自动卖出。冻结 E0 保留只读对照。

## 待审公式

令 `x_t=(L_t,mu_t,T_t)'`，`y_t=log(C_t)`：

```text
x_t = F*x_(t-1) + eta_t
F = [[1,1,0], [0,1,0], [0,0,rho]]
y_t = H*x_t + epsilon_t, H=[1,0,1]
rho = 2^(-1/5)
```

以此前63个收益 RMS 为 `sigma_t`，当前量比 `a_t=clip(V_t/median(V_(t-21)..V_(t-1)), .25, 4)`；三种创新模式的 Q/sigma²：

```text
normal      diag(.01, 1/21², .01)
persistent  diag(a,   a/5²,  .01)
transient   diag(.01, 1/21², 4a)
R/sigma² = .25
模式先验 pi = (19/21,1/21,1/21)
score = 100*tanh(sqrt(21)*E[mu_t|past and current data]/sigma_t)
```

上述常数是研究者设定，不由文献推导为最优值。不得把5/21/63的熟悉尺度当作它们已正确的证明。

## 1. 识别：理论可观测，但短期弱分解

可观测矩阵为：

```text
O = [H; H*F; H*F²]
  = [[1,0,1], [1,1,rho], [1,2,rho²]]
det(O) = (1-rho)² ≈ .01676
```

当 rho≠1，且动力学和噪声规则已知，系统在形式上可观测；不能因此声称三个分量无法估计。这个结论也**没有**说明单根新 K 线能识别冲击性质。

- rho=1 时，L 与 T 的相加水平在观测上不可分。
- rho=0 时，T 不再把同一个冲击带到后面，接近额外白噪声观测冲击的解释。
- 这里 rho≈.87055，使 T 在较短片段中也相当持久。三至数个观察内，L 的变化、mu 的变化和 T 的变化可以给出近似相同路径。有限样本的分配会明显受 Q/R、初始协方差和模式先验影响。

这是“在假设下有唯一滤波规则”和“真实经济成分已被数据单独识别”的区别。永久/暂时只是模型的预测寿命标签，不能使用以后长期保留的价格去回写事件发生当天的 L/T。

## 2. T 的记忆是实质差异；后续收复/保留有可检验含义

在未来创新条件均值为0的假设下：

```text
E[y_(t+h)|data_through_t] = L_t + h*mu_t + rho^h*T_t
E[y_(t+h)-y_t|data_through_t] = h*mu_t + (rho^h-1)*T_t
```

同样幅度的观测残差若主要进入 L，模型预测该水平保留；若主要进入 T，则预测其逐步衰减。因此，后续保留、收复或继续偏离确实会反过来改变对 L/mu/T 的当前分配。

严格说，后续价格不需要在旧模式标签间重新“判案”，而是更新当前隐藏状态。若过去一个大冲击先放入 T，后来价格始终保留，模型可以逐步修正当前 L/mu；**过去输出仍不得重绘。** 这是允许早期解释失败再更新的滤波机制，不是事后识别正确率保证。

相同前缀的整理与真正反转，必须给出相同判断。rho的固定衰减会制造持续要求：模型每期都预测部分回复，未回复会不断形成新残差。这是机制，也可能是反复误分配的来源。

## 3. 成交量确实改变机制，但没有方向保证

某一分支的更新为：

```text
Pminus = F*Pprev*F' + Q_j(a)
S = H*Pminus*H' + R
K = Pminus*H'/S
mplus = F*mprev + K*(y-H*F*mprev)
branch_weight ∝ pi_j * Normal(residual;0,S)
```

增大 a 可令同一残差更多进入 L 或 T，从而改变后续预测；这不是最后分数乘一个量权重。由于 Q 的所有方向均为零均值，它不预设放量上涨利好，也不预设放量下跌利空。它更接近“高参与时允许两类更大的隐藏创新”的条件假设。

不过这里有三个容易误述的细节：

1. **a 同时扩大两种竞争冲击。** 量没有提供持续/暂时的直接标签。分配依赖本期残差、分支宽度、历史状态与随后路径。
2. **本期 Qmu 不直接吸收本期价格。** L_t 使用 mu_(t-1)，且 Q 为对角、H不观测mu。因此新增的本期 Qmu 不进入当前 S，也不直接增加本期 K_mu 的分子；它提高的是未来漂移的可变性。固定同一分支的先验时，提高 QL/QT 使 S 更大而 K_mu 分子不变，可能降低当日 mu 对残差的吸收。因此不可预先宣称放量启动会更快形成高强度。
3. **更宽的分支不总有更高权重。** 正态密度含1/sqrt(S)的宽度惩罚；固定残差而放大方差，既可提高也可降低相对似然。原量与常量量的输出差异必须逐事件解释，不用“放量增强信心”概括。

此外，a 使用当日 V，只能在收盘后参与当日过滤。若把这套规则当作收盘前预测，便越过信息时点。由于没有为 V 自身建立生成分布，模式权重最好称“给定活动量规则的内部滤波权重”；不能称完整联合 OHLCV 概率或已校准上涨概率。

## 4. 主强度的含义与可比较范围

`mu/sigma` 是局部风险尺度下的日对数漂移，乘 sqrt(21)再用 tanh 映射有界。它可跨价格和成交量计量单位比较，前提是复权、有效观察时钟和量单位口径一致。

它并非严格的21日预测信噪比：本模型预测方差含 L/mu/T 的状态不确定性与未来过程创新，通常不是21*sigma²。也不是mu的统计显著性，分母不是后验mu标准差。RMS包含漂移本身和过去冲击；同样mu下，sigma上升会降低分数，不能把所有分数下降都归因于趋势漂移变差。

主分数也忽略 T：当 T>0，模型预期暂时成分回落，即使mu>0也可能有负的短期总价格预期；T<0则可能反弹而mu仍为负。应并列展示 T，避免用户把高分理解成“当前全部价格动力都向上”。若要画上述h期条件位移，它只能是附加解释字段，不能在看图后偷偷换成新主分数。

另两个固有限制：

- 一次永久上跳后横盘，L可以较高而mu最终接近0，主分数也接近0。永久价格水平提高不等于持续上行斜率。
- tanh必然饱和。足够持续且噪声极低的慢涨也能接近100；不能把100解释为更大绝对涨幅、唯一极强状态或未来更大胜率。原始mu/sigma、mu、sigma及饱和比例应可见，不能靠重标分数隐藏。

## 5. 相对旧实现的新颖性和解释隔离

直接核对的旧源码：`TradingAlarm/research/results/pv-competing-state-20261020/code/trend_competing_state.py`。

旧模型有二维 L/mu；“jump”扩大 QL，“shock”扩大当日 R，没有可延续的冲击状态。它本身已经是前向高斯混合竞争解释，不能说本候选第一次使用竞争、状态记忆或贝叶斯更新。B 的实质增量是**第三个按已知rho衰减的价格状态**，让暂时冲击在后续日保有预测后果。

B 同时改了 Q、模式先验对量的作用和主评分分母。即便图检显示差异，也不能把全部变化归因于新增 T。旧分数是mu/后验mu标准差，本候选是mu/过去收益RMS再映射；两者不同语义。只读对照应明确说明这一点，不因分数更高或启动更早就认领信息增量。

这类持续/暂时分解在状态空间建模中并非新算法家族；本轮所需是针对项目旧失败的机制增量和可审查性，不是学术原创性。

## 6. 实现前必须补齐并冻结的假设

1. **模式时序。** 固定pi意味着每期重新抽取创新类型，并非一个持续21日的市场模式。持续记忆来自状态F。模式权重只能描述本期创新解释。
2. **混合近似的精确定义。** 若保留按当期模式分组的3个高斯，应从上期3分量展开9分支，再按当期模式匹配矩；若全部塌缩为单高斯，则历史多峰信息损失更大。两种做法不是同一算法，必须在看结果前选定。都不能叫完整无限高斯混合的精确后验。
3. **保留完整协方差。** L/T在同一观测中的替代会产生显著相关；不能每期把协方差强行对角化。矩匹配必须包含分支均值间的协方差项，否则会人为缩小不确定性。
4. **初始条件。** 何时预热完毕、L/mu/T初值、完整P初值和首期模式权重须固定。尚未准备完成应显示未知，不用强度0伪装已经观察到中性。冷启动影响不能靠首次画图后重设P消除。
5. **观察时钟与断档。** rho的半衰期是5个模型观察步，不必然等于一个自然周；停牌/缺口是否推进衰减必须明示。21/63也须同一时钟，不补造未知行情。
6. **噪声假设。** 三个过程创新、测量噪声的条件零均值、独立性/对角Q、固定R比例均为工作假设；对数收盘的“测量噪声”指模型观测残差，不是认定交易所收盘价有误。
7. **价格与量变换。** 使用同一审核复权坐标；价格尺度变化不应改输出。量比只消去固定单位，不能自动处理拆股、换成交量口径或成交活跃结构突变。
8. **输出职责。** 该分数不改E0支持/有效状态、不接RS或换仓、不产生订单；模式标签保留模型假设身份。

## 7. 仅建议的最小机制核查，不新增账户

使用共同前缀后才分叉的永久台阶/短暂脉冲、连续慢斜坡、上行中的整理、向下背景中的反弹、持续反向斜坡，检查mu、T、L及混合权重是否按提议含义更新。应同时保留“恢复前不可能提前区分”的代价。

固定价格只改原量/常量量，核查差异确实来自状态分配和后续预测；不要求每根改量都改变结论，也不把消融差异本身当经济增量。共同前缀、正价格单位缩放和量单位缩放必须保持输出定义。符号翻转可在对数路径合成例中核查，真实倒数OHLC并非新的可交易资产。

完成这一轮及固定真实面板图检后作支持/否定/证据不足裁决。高量启动迟、慢涨被过度放入L/T、整理中mu来回翻转，均是需保留的反例；不能自动触发rho/Q/模式先验搜索。
