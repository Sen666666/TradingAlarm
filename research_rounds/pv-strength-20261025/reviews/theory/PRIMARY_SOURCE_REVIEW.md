# OHLCV 趋势强度：第一手理论与机制审查

研究日期：2026-10-25。身份：独立理论审查，未运行任何账户、未取行情、未改 E0/R/R1、RS、换仓或共享源码。本文是研究建议，不是已冻结算法协议，也不含效果认领。

已读：`docs/RESEARCH_CONSENSUS.md` 的 C03/C04/C07、`docs/RESEARCH_PATH_LEDGER_DESIGN_2026_10_20.md`、`docs/RESEARCH_REGION_PATH_AUDIT_2026_10_20.md`，并核对 `docs/ALGORITHMS_E0_R_R1.md`、旧 `markov_trend_strength.py` 与 `volume_clock_strength.py`。研究仍是已见历史的开发研究。

## 审查结论

最有价值的机制原则是：**量改变需要检验的价格解释，后续价格响应决定该解释是否成立；趋势结构与当前推进强度分开输出。** 放量不能在发生当天自动等于趋势更强。高参与价格冲击可以是持续重估，也可以是暂时冲击；OHLCV 不足以观测交易动机。

三条可解释路线中，A 最适合作为 E0 旁的有限机制原型；B 具有覆盖快启动、慢涨、整理、反弹与转弱的建模空间，但识别及参数负担明显更大；C 适合检查表示是否丢失顺序，暂不适合直接认领为趋势强度。不要把三者拼成一个大模型。本轮只选一条做固定图检，或据此否决不合语义的现有候选。

算法可以输出 `结构状态 / 当前有符号推进 / 反证与未决程度`。若需要单一数值，必须解释其单位和合成依据。分数下降不自带卖出含义；阈值、持仓、退出属于后续独立策略层。横向排名也不反向定义绝对趋势。

## 第一手来源及适用边界

### 1. Llorente、Michaely、Saar、Wang（2002）

[作者 MIT 页面上的论文 PDF：Dynamic Volume-Return Relation of Individual Stocks](https://web.mit.edu/wangj/Public/Publication/Llorente-Michaely-Saar-Wang02.pdf)。发表于 *Review of Financial Studies* 15(4), 1005–1047。

原文用风险分担与私有信息交易的不同动力学，解释量与收益延续/反转关系。核心实证式为式(12)，PDF 第18页 / 期刊页1022；第20页表2也清晰重列：

```text
r_(t+1) = C0 + C1*r_t + C2*V_t*r_t + error_(t+1)
```

这里 `V_t` 是去趋势的对数换手率；原文以此前200个交易日均值去趋势，不是本项目日量比，也不是本轮必须照搬的窗口。`C2` 的符号取决于所建模的交易动机和样本，不能预设为正。原文使用的价差/市值等信息不属于本轮可引入的预测输入；不能把其横截面识别直接搬入 OHLCV。

**本轮可吸收的命题：** 量应改变“同一个价格变化更像哪一种后续动力学”的判断。**不能吸收的过度结论：** 放量即知情、低量即无效、这篇论文证明 A 股趋势强度可盈利。

### 2. Campbell、Grossman、Wang（1993）

[作者 MIT 页面上的论文 PDF：Trading Volume and Serial Correlation in Stock Returns](https://web.mit.edu/wangj/www/pap/CampbellGrossmanWang93.pdf)。发表于 *Quarterly Journal of Economics* 108(4), 905–939。

论文在风险厌恶承接者吸收非信息交易压力的模型中，得到高量价格下降可伴随预期收益提高的结果，并研究日收益自相关随量的变化。它是“放量下跌一律更坏”的直接理论反例。

**本轮用处：** 强制保留“暂时冲击后收复”的竞争解释。**边界：** 模型动机不能由单根日 K 识别，也不保证高量下跌应买入。

### 3. Blume、Easley、O’Hara（1994）

[期刊原文页：Market Statistics and Technical Analysis: The Role of Volume](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1994.tb04424.x)。发表于 *Journal of Finance* 49(1), 153–181。

其均衡模型允许价格与量的序列透露仅看价格无法恢复的信息质量。这里仅核对期刊页摘要，未用未核对的正文公式作设计依据。它支持“研究联合序列是否有增量”这个问题，不能证明任何量加权指标具有增量。

### 4. Hamilton：状态推断的方法文档

[作者 UCSD 文档：Regime-Switching Models](https://econweb.ucsd.edu/~jhamilto/palgrav1.pdf)，2005-05-18 稿，供 *New Palgrave Dictionary of Economics* 使用。PDF 第5页式(7)–(9)给出前向滤波：

```text
prior_t(j) = sum_i P(i,j)*posterior_(t-1)(i)
posterior_t(j) = prior_t(j)*f_j(y_t | history_(t-1))
                 / sum_k prior_t(k)*f_k(y_t | history_(t-1))
```

只引用这一推断工具；文档不证明股票状态是真实经济类别。参数与状态个数的识别、检验均有困难。实时前向过滤与使用全样本的事后平滑必须区分。

### 5. Chevyrev、Kormilitzin：顺序表示的方法文档

[作者论文：A Primer on the Signature Method in Machine Learning](https://arxiv.org/abs/1603.03788)，[PDF](https://arxiv.org/pdf/1603.03788)。核对了迭代积分、Chen 恒等式、时间反转及二阶面积；在线 PDF 为更新版本，引用以章节和公式含义为准，不冒称本次读的是2016首版全部页码。

签名是对多维路径的有序表示；二阶交叉项可表达部分先后关系，完整签名的辨识结论不自动适用于低阶截断。它没有赋予金融指标任何多空或盈利语义。

## A：带成交量标记、只结算一次的价格响应事件

这是本审查提出的设计草图，并非上述论文的原公式。它直接吸收“冲击含义需要由后续响应区分”，不把加权净位移当状态。

### 对象与因果更新

在某日收盘，用此前已知的波动尺度 `s_(i-1)` 和量基准 `B_(i-1)` 识别一个明确事件：

```text
u_i = log(C_i/C_(i-1)) / s_(i-1)
a_i = V_i/B_(i-1)
event_i = (abs(u_i) >= u0) and (a_i >= a0)
d_i = sign(u_i)
```

`u0/a0`、基准、最多未决对象数及观察上限均须在看新轨迹前固定；本文不建议按收益或图形调阈值。量直接控制是否生成一个“需要解释的高参与冲击”。当日只创建待验证对象，不能把其方向立即当成已经确认的持续趋势。

一个便于审查的响应定义是事件收盘两侧的固定、对称、以事件前波动计量的收盘障碍：

```text
upper_i = log(C_i) + k*s_(i-1)
lower_i = log(C_i) - k*s_(i-1)
tau_i = 首次收盘严格越过其中一条障碍的日期，或预先规定的到期日
```

上障碍先到说明该冲击后的首次可辨响应向上，下障碍先到说明向下；相对 `d_i` 分别记录延续或反转。两侧障碍均不触及时仍为未决，到期也不能偷填方向。使用收盘避免 OHLC 不知道同日高低先后的问题。普通量日可以完成响应，不需要再放量。

若用于强度审查，先保留“向上响应数、向下响应数、未决数、解决所需时间/活动量”等字段；每个事件最多结算一次，已否决对象不能因价格重访复活。同一价格运动产生的重叠事件不得当作多份独立证据：最小版本可限制未决区间互不重叠，代价是忽略期间新信息。另一种多对象方案须预先定义关联分组，不能直接相加。

### 量实际改变什么

同一价格、只把某根成交量从普通改成高量，会新增待验证对象，并可能在后来产生一次延续/反转记录；普通回调可以不创建同等级反证。高量下跌被普通量收复，可把最初下跌解释为未持续的冲击。高量上涨后很快下破响应障碍，则不能保留当初“高参与上涨更强”的信用。

### 相对 E0 的真实增量与失败边界

E0 已经有“高参与下跌→后续普通量跨日收复”的单个记忆；仅把它改成更漂亮的分数不构成增量。A 只有在**有效结构内部也记录正反向高参与事件、区分冲击的延续/反转、输出未决与反证**时才超出 E0 原功能。原 E0 结构与支持线仍只读保留，A 的减弱不能直接撤销 E0 或生成卖单。

它没有净位移恒等式，也不随最新摆动腿切换清空结构；但如果最后把事件正负简单累加再规定零线退出，仍可能变成新形式的证据累计，须另行否决这一步的语义跳跃。

**主要反例：** 很平稳、始终普通量的慢涨可能没有任何高参与事件，不能据此判成弱趋势；一个高量消息冲击后立即进入长时间整理，也可能长期未决。故 A 本身只是“参与冲击的兑现/反证维度”，不能单独覆盖完整强度。若本轮要求一条独立数值就能解释所有慢涨，不能把 A 当已完成答案，更不能临时加一条旧斜率补洞后宣称新理论成立。

## B：持续漂移与暂时冲击的竞争动力学过滤

这是统计路线草图，计算自由度比 A 大。目的不是把普通 HMM 重跑一遍，而是让不同状态对**量之后的价格响应方式**作出不同预测。

### 必要的实质差异

旧 `markov_trend_strength.py` 是三个固定均值的收益似然，成交量只作为正的似然倍率。把高量日判得更确定并没有识别“持续重估/暂时冲击”。只改正态为 Student、改自留概率或再做一次 MAP 不能算本路线。

一种待形式化的最小动力学为：

```text
u_t = mu_s + (phi_s + psi_s*a_(t-1))*u_(t-1) + epsilon_(s,t)
f_s = p(u_t, a_t | u_(t-1), a_(t-1), state_t=s)
posterior_t(s) 依 Hamilton 前向公式更新
```

`u_t` 为以此前波动标准化的日收益，`a_t` 为因果相对活动量；状态至少要区分持续向上、持续向下与暂时往返。核心是 `psi_s` 与状态特有的响应分布：同样前一日高量变化，在某状态支持继续，在另一个状态更支持反向响应。量改变预测均值/形状及竞争解释，不是把最后分数或共同似然乘大。

这只是方便说明的回归式，不能视作已解决永久/暂时分量识别的完整模型。若改用持续水平＋均值回复暂时分量的状态空间表达，也必须解释两个分量如何由 OHLCV 识别、参数如何在当时获得。全样本 EM 训练后再把平滑概率画回历史不合格。

### 输出与比较

先输出 `P(up), P(down), P(transient)` 和模型下的条件推进尺度；概率不是实际上涨胜率。跨股可比需要同一波动定义、同一观察时钟、同一固定参数或事先写定的因果估计/收缩规则。各股分别把自己的历史最弱最强重标为0–100，不提供绝对可比性。

快速启动可以由持续状态的似然快速改变体现；持续慢涨由小但持久的正漂移体现；整理由暂时分量吸收；跌势反弹需要在向下背景中与暂时正冲击竞争；真正转弱由后续分布持续支持不同状态体现。这些是**模型可表达性**，不是已经实现的识别能力。相同前缀必须同判断，无法在共同前缀提前知道后来是整理还是反转。

### 反例与停止

持续行情和多次同向暂时冲击可以在有限样本内难区分；趋势突变、涨跌停、波动跃迁、停牌后跳空会让预设分布失配。若只有量倍率发生变化、状态预测都相同，或主要结论由任意状态自留概率控制，就应判重复/证据不足，不为救轨迹增加状态。参数、标签识别、初始化负担使 B 不宜在本轮匆忙拼出多数候选。

## C：低阶联合路径签名，只作顺序表示审查

在固定、只到当天的路径段构造尺度无关的多维坐标，例如：

```text
X^1_k = log(C_k/C_start) / s_start
X^2_k = sum_(j<=k) q_j,  q_j 为用此前基准标准化的正活动量
X^3_k = k / N
S^(i,j) = integral_(start<u<v<end) dX^i_u dX^j_v
A^(1,2) = (S^(1,2)-S^(2,1))/2
```

逐段线性插值及归一化须固定；`s_start` 是当时已知尺度，不能用后来全段波动回改过去输出。时间坐标避免把不同耗时路径当作仅参数化不同；低阶截断仍可能碰撞。

对两个增量 `(delta x1,q1),(delta x2,q2)`，二阶反对称项为：

```text
A = (delta x1*q2 - q1*delta x2)/2
```

例如 `(+1,4),(-1,1)` 与 `(-1,1),(+1,4)`，端点净价格均0、总活动均5，A分别为+2.5和−2.5。这是表示能区分部分先涨后跌/先跌后涨的代数例子，绝不是交易优劣标签。它与“正权重净位移必与端点同号”的旧栈记账不同。

**关键限制：** `(价格,累计量)` 的二阶面积并不恢复全部顺序；某些闭合价格路径连同附着量按时间反转后，面积仍相同。面积正负也不普遍等于多空、吸筹/派发或推进效率。加入时间及更高阶可增加信息，但维度和解释负担上升。只有在提前写定“哪种交叉项如何创建/维持/反证哪类状态”后，才能转成趋势模型；当前它没有满足 C04 的完整机制，故只列为诊断备选，不晋升为本轮强度算法。

## 本轮应先写出的有限反事实

1. 固定价格，分别保留原量、常量量、只打乱配对量。逐事件解释创建/维持/反证哪里改变，不能只报分数相关性。
2. 固定净涨跌与总量，调换推进、回撤和活动先后；重复价格不得产生排序伪效应；已撤销的旧信用不得复活。
3. 同一个已建立结构中，让小幅普通量回调与同幅高量回调分支直到未来分叉前完全相同；允许判别尚不明确，不能偷看后续恢复。
4. 低量慢涨必须保留“证据不足”与“趋势弱”的区别；高量横盘也不能直接贴强/弱标签。
5. 对黄金、半导体和固定几只 A 股，先记录原量价的首选解释、替代解释与撤销条件，再叠加唯一原型；不以所有事后顶底都命中作通过条件。

这些属于轨迹与机制核查，本轮无账户、无阈值优化。若本轮唯一候选失败，完整保留失败，不把 A/B/C 顺序跑成一条自动模型队列。
