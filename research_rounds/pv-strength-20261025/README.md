**结论：PVS-B1保留为固定假设下的标准化潜在漂移原型，不晋升为统一趋势强度指标。** 七资产和合成反例显示部分推进与后段转弱有响应，但急跌可被归为暂时偏离、主分数仍接近最强，下降中的反弹也会转强。它没有可靠区分五类现象，不能通过修改交易阈值认领模型解释已完成。
