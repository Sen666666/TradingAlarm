使用本地已有13价格代理，两个窗口：2025-01-02—2026-10-13及2024全年；预热不计收益。结果后策略/参数修订0；507是政策×执行情景×资产×窗口账户数，不是507个独立候选。A股个股权息信号价不是真实分红现金账；AU0主连不是真实逐合约保证金账；详见协议与报告。
