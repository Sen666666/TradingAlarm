# DAP方向量价公式：三版均为研究候选，未晋升

本轮目录R1/R2/R3只表示DAP第1/2/3版，不是旧冻结算法R1。对照P1是纯价格消融。原E0-NR1与I-NR1不改。三版均使用真实每日成交金额CNY，价格采用原因果复权坐标，账户按原价及已知权息执行。

## 1. 价格必须独立足够，金额不能补偿价格不足

有效价格观察的收盘C、实际金额D。以候选极点e为锚，冻结：

```
r_t = ln(C_t / C_(t-1))
s_e = max(sqrt(mean(r_(e-63),...,r_(e-1) 的平方)), 1e-8)
B_e = median(D_(e-21),...,D_(e-1))
δ_e = sqrt(5) * s_e
```

s为均方根，不是去均值标准差；不包含候选日的收益或金额。63、21、sqrt(5)沿旧尺度固定，本轮不寻优。第65个有效观察后可准备。

观察上行时，e跟随更低收盘；创新低重置观察锚、价格前沿与信用。从e向上：

```
x_t = ln(C_t/C_e)
F_t = max(F_(t-1), x_t)
ΔF_t = max(0, x_t - F_(t-1))
w_t = min(1, sqrt(D_t/B_e))
Q_t = Q_(t-1) + w_t * ΔF_t
```

确认上行必须：当天ΔF>0，同时F≥δ且Q≥δ。同区间反复成交不重复记信用；无新价格推进，巨额成交不记新信用。下行摆动按负方向对称处理：上行阶段跟随更高收盘，x=ln(C_e/C_t)，仅新的向下前沿积累下行信用，不可增加上涨信用。

**相对金额为正常水平或更高，w最多为1；相对金额仅1/4，则w=.5，需要更多持续向上推进才能积够Q。** 因而缩额慢涨仍可确认，通常花更久，但并不是横盘等够天数自动确认。合成同路径例：正常额4月27日确认，缩额4月30日确认。金额单位整体倍乘不改变输出。

这一上限也意味着：普通额与极高额在单次推进权重上同为1；高额不会无限增强证据，超过正常额的增量主要在急跌规则中起作用。这是明确的保守研究约定，不是已证明最优的量价关系。

## 2. 放量且大跌，直接冷

每天以之前21观察金额中位数和之前63收益均方根计算：

```
q_t = D_t / median(D_(t-21),...,D_(t-1))
急跌 = (q_t ≥ 2) 且 (r_t ≤ -2*s_t)
```

满足时当天温度直接−2冷，覆盖旧暖/热和旧信用；重置向上观察锚点，不能同日转暖。2倍金额、2个日尺度均是本轮事前量化约定。下跌很大但金额不足2倍，不走“高额急跌”，仍可走累计向下确认，不能声称所有巨额亏损都能被这一条挡住。

缺金额不估算，不创造金额信用；正常价格结构风控仍能执行。本批407股有效观察金额无缺失，末日均2026-10-26。

## 3. 三次机制版本

**DAP1：** 上确认暖2，普通下确认或急跌冷−2。已暖且从本次确认低点推进达到sqrt(21)*冻结尺度则热3；热不改变仓位。方向上行中的新高提供fresh_up，用于实际账户后续有效候选，不必仅限最初一天。

**DAP2：** 修复“局部反弹等于趋势已暖”。增加有方向金额推进：

```
u_t = min(1, sqrt(q_t))
p_t = r_t * u_t
m_t = (20/22)*m_(t-1) + (2/22)*p_t
```

m为21观察尺度指数平滑，起点0，仍须65观察准备。m≤0时局部上确认仅为修复1；m>0且发生新上确认或当前上摆动的新高，才能暖。只经过时间不能升暖。急跌优先于m正负。

**DAP3：** 修复“上涨中的普通回调也立即判冷”。在DAP2之上，普通下确认时m>0只降温1；已经处于下摆动且m≤0才冷−2。高额急跌始终当天冷，不受正m抵消。已冷不能仅凭m变正自动升暖，仍须新的向上事实。

DAP2与DAP3的结构持有H政策应完全相同；此次账户精确核对相同，真正差异发生在冷退出C政策。

## 4. 两个明确交易政策

- **H结构持有**：新上确认建立支持=确认极点收盘；后续上确认只抬支持；收盘触及/跌破旧支持退出，同日不重入。转冷只禁止新买，存量仍按结构持有。
- **C冷退出**：相同支持规则之外，温度−2还要求退出；修复/降温1不要求卖出。未来新的上确认/上摆动新高且暖，才可再次参与。

两组新买都要求政策有效、温度暖/热、有fresh_up，再接受原行业/RS-H1/仓位/资金限制。T收盘决策，下一可执行开盘，原T+1/涨跌停/整手/费用/订单期限不变。没有当日收盘成交或自动实盘。

行业仍用旧E0-NR1；个股新模型统一替代原E0事件和G1温度判断，没有同时叠旧快启通道。适配文件的旧g_*列只留作旧对照，DAP决策只读新i_target/i_buy/i_floor；新温度与原因完整保存在traces。

P1价格消融令所有w/u=1，并把急跌条件变为仅r≤−2s，因此它消融的是金额的总体作用，包括急跌筛选；不能把P1差异全部归因于买点快慢。

## 5. 明确的不足

三版都只识别相对自身历史的局部方向事实，并不能从OHLC/金额证明交易者共识、资金净流入或未来上涨。DAP2的21尺度正值仍可能只反映下降中的局部反弹；DAP3允许普通回调持续持有也会承担趋势后期恶化。实际回测已显示这些代价，三版未达到用户同时保留赢家/避开2026H2亏损的目标。
