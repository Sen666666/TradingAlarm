## 为什么选这一版

不直接把新股几天涨幅与老股一年涨幅比较，不把短期涨幅年化，也不因不足一年而整只股票没有分数。每个目标有多少历史，参照股票就同样只看多少历史，最后比较它在相同长度下的强弱位置。

原四段63日权重保留为原始强弱测量；跨年龄排序使用长度匹配后的百分位。这样长历史股票在连续日线条件下仍沿用原始RS公式，新股不必等待253个收盘，也不需要按证券代码兜底。

## 公式与最少数据

至少6个真实有效交易收盘，形成至少5个收盘间区间；不足者保持未知。今天必须有真实正量报价。首日收盘是最早价格起点，发行价到首日收盘的涨幅不算作可获得收益。

设h=min(首个可核源收盘至今天的市场交易日间隔,252)，b_j=min(63j,h)，w=(0.4,0.2,0.2,0.2)。只对非空区段求和：

`M_i(t;h) = Σ w_j × [P_i(t−b_(j−1)) / P_i(t−b_j) − 1]`

价格使用上一轮冻结因果复权坐标。对每个目标h，让固定参照池内所有股票也使用同样的h，计算M；令N为可用参照数（含自己），L为M更低的数量，E为同分数量：

`RS-H1 = 100 × (L + 0.5E) / N`

M统一舍入12位后判并列。N少于20保持未知；20只是避免极小参照的技术下限，不是统计可靠性保证。最终分真正并列时才用稳定代码排序。个别未知不再使整批改成代码顺序。

- 新股只有45个收益区间：和其他股票的45日分段强弱相比。
- 老股有252个区间：和其他股票的252日分段强弱相比。
- 空白季度不虚构价格或收益，原始M也不直接跨年龄排序。h<63时0.4倍区间涨幅在同h参照中共同缩放，百分位不受这个共同系数影响。
- 市场日历计时保证相同h对应相同日期区间；与旧有效观察数计时不完全相同。历史锚点无真实报价或跨明确源分段时保持未知，不把旧股票的缺口当重新上市。

5个收益区间约一周，取作本版最少观察窗口，有公开RS短历史处理作参照，但并未证明一周已足以预测；不是用收益搜索出的最优参数。

## 公平的具体含义与未解决的风险

公平是**同长度、同时间、同公式、同参照池，再映射成共同的0—100位置尺度**，不等于不同年龄有相同未来收益或稳定性。本版不额外压低新股分数，保留早期尾部排序机会；短样本、IPO波动和单次跳空会造成高分，这是明确代价。历史长度、分段、参照数与涨跌幅必须并列显示。

中科仪第6个收盘（2026-05-11）上市后涨52.81%，RS99.85；到第64个收盘，上市后窗口已跌4.29%，RS仍65.52，说明相对强也可能是负收益，更不保证后续持续。

德明利同一主日期只有最近63日时约3.17分，采用252日分段强弱则87.97；它近63日已跌约36.25%。原四段记忆有滞后，H1没有据此另加短期过滤。这是期限定义的取舍，不能把长度匹配说成已经识别最优开仓点。

**E0在本例已完成预热的两只新股上，首次ready均为第65个有效收盘。** RS第6个收盘即可用只是消除RS额外等一年的限制，不等于第6天能按现有E0开仓。杰理科技46观察尚未完成E0预热。若要参与上市更早阶段，必须另立E0启动问题；本轮未改。

目前只确认公式可计算、意义明确及局部行为，未证明选股增益、盈利或风险改善，不晋升账户策略。当前存续/当前市值/行业快照的选样偏差及既有权息代理继续保留。
