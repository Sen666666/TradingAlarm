# 科技有限资金研究：成交金额1.5倍换仓组

[具体规则](PROTOCOL.md) · [成交金额字段核验](amount-audit.json) · [逐股覆盖](amount-coverage.csv)

用户明确采用当日成交金额：新股≥拟换持仓股的1.5倍，非成交股数、非自身量比。新增T-I-AMT15，与原T-I比较；其他政策不交叉叠加。本组在原18条拟议路径之外增加三情景，总上限21。

在出现原I买入信号且资金/名额受阻时，依原候选排序，选择可行持仓中成交金额最低的一只，满足1.5倍便发起一次一换一。日线先卖、后一个开盘买，各腿最多两个市场日，真实失败和成本保留；原六股/三行业/每行业两股限制不变。不能一换一释放行业名额的跨业挑战单列。

数据核验通过：407只、2024以来256773个真实观察，成交金额均为有效正人民币值；成交金额/股数隐含均价均在当天高低价0.5%容差内。全部原价来源哈希一致、无新取数，覆盖末日2026-10-22；这不是最新交易日已经补齐的声明。

当前完成规则细化与字段准入，新增资金账户0。完整换仓执行器、原始量价/金额轨迹复查、最新行情核查与正式资金冻结仍待随后执行；未把协议当成已有回测成绩。原研究设计与封存结果保留。
