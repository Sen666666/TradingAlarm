# 首轮10账户经济判读预注册提案

状态：**待主 agent 审定，尚未冻结，不能作为账户运行许可**。写于2026-10-23；研究截点仍为2026-10-22。本稿只读取已有共识、路线复评和本轮数据证据，新增经济账户0、联网0、算法改动0。旧协议的 `ordinary_loss_budget_and_rationale_before_account_freeze=null` 仍待正式冻结时替换，不能因本稿存在就视为已解决。

## 1. 问题、范围和固定比较

只问：在相同个股量价算法、资金和执行约束下，板块门控与两级分配能否改善尾部实际参与和普通试错代价的经济取舍？主账户为 **S0**，主要对照为 **T0**。T1−T0解释门控，S0−T1解释两级分配，S0−T0回答整体问题。T1较好而S0较差只能说明局部机制，不改称T1为主账户。

固定矩阵为T0/T1/S0各基础、双成本、额外延迟一有效成交事件，另B0基础，共10账户；本金各100万元人民币，既定6槽/3行业/每行业2公司及90%初始投入预算不改。B0按自身既定年度等额目标规则运行，不能因整手现金多而把打赢B0直接解释为选股优势。

原始池是2026-10-22观察冻结的存续A/H股票；策略池再按该日市值、南向资格和行业筛选。2013起预热，2015起至2026-10-22评价；固定分段为2015—2017、2018—2020、2021—2023、2024—截点。保留选样偏差，不称历史时点全池或样本外。缺数据不得静默删股、删行业、改起点。新上市股票的真实起点与旧股票的数据缺口分别处理。

## 2. 唯一普通损耗预算提案：尾部收益保留多数，绝不冒称相抵

本提案不再指定一个必须达到的账户收益率，也不从旧最好账户的19.94%尾部侵蚀率或11.99%本金损耗倒推门槛。提出唯一的、较粗的**经济否决预算**：

- 对完整2015—截点、成本后已经闭合的出资周期，尾部仍按该周期净收益率≥30%划分，其他闭合周期全部为普通。令尾部净利润为 `P_tail`，普通净损益为 `P_ordinary`，普通净损耗为 `L=max(0, -P_ordinary)`。
- 当 `P_tail>0` 时，普通损耗预算提案为 **`L ≤ 0.5 × P_tail`**。经济含义仅为：普通净损耗不能超过最终留下的尾部净利润，即 `L ≤ P_tail−L`，至少把尾部利润的一半保留给账户。这条边界来源于“尾部利润应主要留存”的会计取舍，不是从历史最优结果拟合，也不能证明50%最优。
- 这是拒绝“多数尾部被日常试错吞噬”的宽松上界，**不是把50%侵蚀叫作少量或基本相抵**。即便在预算内，仍必须展示 `P_ordinary/N0`、普通损耗金额、尾部金额、各固定时期普通损益，以及按当期账户规模观察的连续初次失败。只有普通净损益接近零这一事实存在时，才能描述接近相抵；不得由预算通过推得。
- 不另加一个固定累计人民币或年收益门槛：长短周期、资本增长和出资强度不同，固定初始本金比例会把复利扩大的正常试错机械判为失败。`L/N0` 必须展示，但本提案不把它擅自变成20%回撤的替代量。普通损耗与账户路径回撤不是同一概念。
- `P_tail=0` 且有普通损耗时，不能称尾部覆盖已成立；若尾部尚开放，判“尾部兑现证据不足”，不强制平仓制造闭合。不能用开放浮盈、最高浮盈、未出资的理想趋势或毛利润给已实现普通损耗提供预算。普通净盈利而无尾部，只能说明盈利，不能说明肥尾机制已得到支持。
- 预算只用于事前固定的全期经济判读，不写入交易引擎，不触发停买、缩仓、锁盈或缩紧退出，不要求每年/每个固定分段符合此比例。压力账户独立列出相同口径，不能把基础账户的尾部利润拿来补压力账户的普通损耗。

该预算须在看首轮结果前接受或明确拒绝；若拒绝，本轮先保留待审，不以同时提交多个数值供结果出来后挑选。冻结后超预算应如实记“本提案的收益结构未获支持”，不能扫描40%/60%、移动30%尾部界线或再加过滤器救结果。预算内仍不自动通过总体经济评价。

## 3. 同一张核账表，分清四件事

| 层次 | 必报和解释 | 不允许的推论 |
|---|---|---|
| 风险 | 全账户最大回撤、持续期、最大公司/相近行业暴露、连续初次失败；20%仍是既有回撤研究目标 | 不把20%变为保证、触线强平或提高风险额度；80%只列愿景观察，不作为通过/继续门槛 |
| 收益来源 | 净尾部、净普通、开放持仓估值与已计提未结权益、现金/汇率及其他归因逐项对账到账户净变动 | 不漏开放亏损，不二次扣费/计分红，不把最高浮盈≥30%重标为尾部，不优化正常右侧回吐 |
| 增量 | 每一执行情景分别列S0−T0、T1−T0、S0−T1；匹配同一事件的出资、未出资、错过和替代持仓 | 不换主要对照，不将较低投入带来的低回撤直接叫作算法更准，不按现金比例线性放大收益 |
| 不确定性 | 数据缺失、费用/权益/FX代理、开放尾部、行情/公司集中、成本和延迟敏感性 | 不把重叠行情窗或同一行情的多笔交易当独立样本，不要求删去最大赢家后仍盈利 |

同时给毛/净损益时保持同一套成本后标签。不同压力情景若某周期跨过30%分类边界，需单列“标签迁移”，再按同一事件对照金额，避免把成本造成的分类变化误读成新机制。未成交漏斗区分信号未发生、板块未确认、排名、槽位、现金、整手/容量和资料未知；未知不是看空信号。

胜率仅描述，不追逐30%—40%；少数大赢家集中贡献符合目标，既不是统计学上已证明肥尾，也不是自动缺陷。利润从最高点回吐是右侧持有代价，按已冻结结构退出，不把兑现率作为优化方向。

## 4. 首轮如何裁决：允许否定和证据不足，不承诺必有下一轮

先过真实输入、因果时钟、执行和独立核账，再判经济结果；工程通过不等于优势成立。

**支持本轮整体政策的历史经济证据**：S0在全期基础账户具有可解释的成本后优势，相对T0不是主要靠少投钱、错误遗漏或开放估值形成；普通损耗在上述预算内，尾部实际出资与净贡献支持该解释，风险结果符合20%研究目标。双成本和延迟下要明确检查同一优势是否仍存在。若两种压力均保持同方向增量且图检能追溯共同原因，可记“支持有限的历史机制结论”；仍不是前瞻已验证或最终目标已达成。若收益相近但回撤较低，只记风险取舍价值，并指出现金/暴露贡献，不升级成选股超额优势。

**否定当前整体政策/收益结构**：在输入完整、可比和核账成立的前提下，S0相对T0在基础及两种压力下均失去净收益，且尾部/普通/风险没有能够解释该代价的实际改善；或普通损耗超过已冻结预算，说明当前组合没有实现本提案接受的收益结构。否定的对象是当前固定政策与这一经济假说，不是量价趋势原理或所有未来方法。超过20%应明确“风险目标未达”，不以高收益自动豁免。

**证据不足/存在明确取舍**：压力后优势消失或相互矛盾，主要利益来自尚未闭合持仓，收益与回撤取舍不能由既定目标裁定，或重要数据/执行假设足以改变方向。不能把它改名为成功；也不要求每个市场/分段都赚钱。固定时期、A/H和尾部来源用于定位，而不是挑出赢家重算主账户。

首轮10项结束即形成一次裁决。没有共同新证据就停止当前扩展；有非重复、当时可实现且可否证的共同机制问题，才另行冻结一个有限追加问题。不因没到80%、单个反例、局部T1改善或换目录重置研究计数。预算失败不是自动调参许可。
