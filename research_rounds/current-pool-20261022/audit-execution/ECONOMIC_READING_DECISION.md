# 首轮经济判读审定说明

2026-10-23；按主 agent 明确审定方向记录。**这是对预注册提案的审定，不是经济协议最终冻结，也不授权运行账户。** 原[提案](ECONOMIC_READING_PROPOSED.md)全文保留；其中50%预算及依该预算作通过/否定的条款不采纳，本说明优先。其失败不能被覆盖成从未提出。

## 不采纳50%硬预算的理由

`L=max(0,-P_ordinary)`、`E=L/P_tail`（只在 `P_tail>0` 时有定义），以及 `P_tail−L` 的算术诊断继续保留。`E>50%` 说明普通净损耗超过最终留下的已闭合尾部利润，属于强警示描述；它不是新的策略晋升、继续搜索或否定一切的万能门槛。原提案的50%没有独立经济校准，作为硬门槛可能重演80%导致的达标搜索。无需再找40%、30%或另一个账户收益数替代。

普通交易成本后少量净损耗可接受，但“少量”必须由完整金额及比例事实说明：至少同报普通净损益/初始本金、普通损耗/尾部利润、全期与固定时期分布、连续初次失败、开放持仓和现金暴露。不能只因总账户盈利或尾部覆盖普通亏损，就泛称已经基本相抵。无尾部时不伪造分母；尚开放尾部不是已兑现的普通损耗预算。

## 事前固定的经济裁决

固定主S0、主要对照T0，T1仅作门控及两级分配归因。固定10账户、2015—2026-10-22全期及既定四段、基础/双成本/额外延迟、完整收益归因与未成交漏斗；不在结果后换对照、换池、换日期、改损耗标签或挑压力情景。80%只有愿景含义；20%仍为既有回撤研究目标，不变成触线强平，也不隐含扩大风险。正常右侧回吐不优化，胜率不设命中要求。

- **支持**须在完整可信输入及核账下，S0相对T0体现可解释的成本后经济价值，尾部参与、普通损耗、风险与资金使用共同支持解释，固定压力情景能说明其可靠程度。所有依据都随主结论披露；降低目标或只看收益形态不构成支持。低投入带来的低回撤按风险/暴露取舍描述，不夸成选股超额优势。
- **否定**依据事前比较形成：完整资料下，S0在主比较及压力中持续弱于T0，且所声称的尾部/损耗/风险改进未出现，或其实际代价反驳了相应机制解释。普通损耗比例连续披露，超过某个新比例本身不自动触发否定或新模型；20%风险目标未达仍须明确记录，不能用高收益抹去。
- **证据不足/取舍未定**用于主比较方向受缺项、开放权益、压力假设或暴露差影响而无法识别，或收益和风险改进互相交换、现有目标不足以决定优劣。不能改名为成功，也不要求每一市场/时期都盈利，不能以集中于少数大赢家为由自动否定。

首轮裁决必须引用同一组预注册结果及因果轨迹，不改成一个新的万能分数。首轮后无共同新证据即停止该扩展；只有非重复、当时可实现且可否证的共同问题，才另冻一个有限追加问题。保留失败及不确定结论，不能把有研究发现自动当成项目无进展计数归零。

正式冻结时，旧 `ordinary_loss_budget_and_rationale_before_account_freeze=null` 不应偷填50%；应记录本次选择的是“预注册比较和连续损耗披露，无新增固定比例晋升门槛”，并绑定本说明、完整比较表与停止条件。若协议schema要求数字，须先修正schema语义，不能为凑字段捏造一个可接受比例。

## 港股行业缺口及跨节点补查

原提案关于2015+完整A/H板块经济主问题目前证据不足的判断保留。数据池允许按真实覆盖与缺项结项；经济准入单独判定，不能静默缩成较短时期、仅A股或完整行业子池。

新增真实证据来自 `../diagnostics/crossnode-sector-fx-01/`：实际只发出首个9602金融行业请求；20秒读等待后记录 `NetworkFailure`，金融状态仍为pending、没有返回页。节点因此停止，后续信息技术与HKDCNY两项均为 `skipped_node_stopped`，未发送。不能把它们描述成两个空响应，不能推断其他节点或供应商不存在数据，更不能宣称HKDCNY历史已验证无数据。原9603金融/信息技术的有限缺口补查与这一次网络失败须分别记载。

当前结论只能是“已有资料不能闭合2015+完整板块输入，跨节点尝试未取得新增可用证据”。不因此自动重启更多源调查、改变算法或启动账户。
