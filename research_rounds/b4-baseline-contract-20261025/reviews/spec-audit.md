# B4 固定合同与 E0 复现边界独立审查

审查日期：2026-10-25。范围：只读既有 B4、E0 定义和实现，校对合同与逻辑分层；不改算法、不取数、不运行账户。本文件是审查意见，不是新的模型或交易政策。新规范、兼容文档及本轮逻辑反例到稿后已补静态验收，见末节。

## 裁决

1. **可固定 B4 为当前指标基线**，前提是固定下列输入、时钟、数值、候选处理顺序及输出语义。它没有总温度、买卖资格或仓位政策，也不因冻结而晋升为有效交易策略。
2. **仅凭 B4 自然输出，不能一般性地精确复现 E0。** B4 使用不同事件核，且不读取 E0 量收复所需的日最低价。B4 的双上、推进正负、急跌标记，不等于 E0 的 `target/entered/exited/floor`。
3. **E0 确有入场、持有和退出资格政策。** 它不依赖真实账户持仓或盈亏，但不能因此称为“完全没有策略的市场事实”。可以在逻辑上拆成事件检测、事实/候选记忆、参与资格、账户执行；要保持旧 E0 的行为，必须完整保留其原事件核及参与顺序。
4. **当前 B4 不是 E0 的严格增量超集。** 将两者并列保留、将来构建共享事实接口，与声称已经由 B4 简单推导 E0，是不同命题。前者可作架构方向，后者不成立。

## 冻结规范不可遗漏的合同

### 1. 输入和有效观察时钟

- 公共入口 `strength_frame(f, joint=True)` 必须使用 `close/volume/segment_id/valid_strength_observation` 四列。B4 本身不消费 open/high/low、账户持仓、入场价、RS、行业或账户收益。
- 索引须为无时区 `DatetimeIndex`，严格有序、唯一且无 NaT。代码验证的是完整时间戳唯一，并未额外验证“每个自然日只能一行”；日线来源保证属于适配层合同。
- `segment_id` 无空值；字符串不得仅为空白；一个身份只能出现在一个连续块中，不能 A→B→A。代码允许非空字符串或正常可分组身份，并非强制字符串 ID。
- validity 须是无空值的布尔列。有效行 C、V 转成 float 后须正且有限。去量模式仍要求有效正有限 V；不能把 `joint=False` 当作允许缺量的接口。
- 无效行全部数字输出 NaN、日期输出空、`phase='unknown'`，不推进有效时钟。它不是零推进、平衡或延续昨日信号。下一有效行以此前有效收盘为前值跨越这段价差；没有按相隔日数摊薄收益。
- 每个显式新段重启价格原点、EW、窗口和全部候选/结构。长自然日间隔不自动触发重启；不能把简单跳过无效行当作已经判明停牌/断档。
- 状态就绪后的跨段会产生 `source_discontinuity`，归档旧结构状态；此前段未满 65 有效收盘或没有有效行，`terminal` 为空，不保证每个段边界都有此事件。全无效的新段也会清空终态。
- 所有 observation 是本段有效观察的零基位置；journal 日期只保留 YYYY-MM-DD。完整复现需保存来源分段、valid 标志、原索引和价格/成交量坐标；不能只冻结一列收盘。

### 2. 初始化和公开时点

- `p_t=log(C_t/C_0)`；若直接比值溢出/下溢产生非有限值，用 `log(C_t)-log(C_0)` 回退。`r_0=NaN`，其余收益按相邻 `p` 的差计算。它不是 E0 的局部 `log_ratio` 实现。
- EW 自 t=1（第 2 个有效收盘）开始，以 `μ_h,1=r_1` 初始化，随后递推；在 t<64 所有公开指标仍未知。不能用公开第 1 行作为 EW 初始化重新计算。
- t=64（第 65 个有效收盘）首次公开 r、EW、冲击、结构和候选。结构在这一轮循环内才创建，初始方向 0；上、下候选的**锚观察 a=63，创建观察 created=64**，使用 s64、v64。它们不是在 t=63 当时已经公开存在的候选。
- t=64 当日先处理新极值，再推进候选，因此可以当日完成首次结构确认。E0 原始事件核 t=64 才设置初始极点，至少需要后续观察才可能确认，两者不可互换。
- 初始化候选 F=Q=0；`x=d(p_64-p_63)` 可非零。此后新极值或方向确认的重锚，均 a=created=t，x=F=Q=0。

原 PROTOCOL 的“初始在第64个有效收盘（t=63）建立”容易混淆锚点发生时间与候选创建时间；新规范应按上述代码语义澄清，旧冻结协议保留原件。

### 3. 量纲、归一化和数值比较

- `μ_h,t=(1−α_h)μ_h,t−1+α_h*r_t`，h∈{5,21}，α=2/(h+1)。μ 是每有效观察对数收益；bp=10000μ；方向为 `np.sign(μ)`，大小为 10000|μ|。方向没有容差、波动阈值或强弱等级映射。
- `s_t=max(1.4826*median(|r_(t−63)|,…,|r_(t−1)|),1e−8)`；量参照 `v_t=median(V_(t−21),…,V_(t−1))`；二者严格排除今天。此 s 是典型绝对变动尺度，非围绕均值的 MAD、RMS 或纯噪声估计。
- 日 `delta_h=√h*s_t` 只表示当天若新建候选的门槛；活跃候选继续使用其创建时冻结的 threshold 和 volume_reference，绝不每日替换。
- 所有结构、前沿和冲击比较使用 `tol(a,b)=32*eps64*max(1,|a|,|b|)`；ge 为 `a>=b−tol`、le 为 `a<=b+tol`，严格 gt/lt 必须越过正/负容差。`d*r_t>0`、μ 的符号使用直接比较，不套此容差。
- 同价极值保留较早点；不足容差的新前沿不改变 F 或 Q。不可仅更新 F 而不更新 Q。恒定价格时 EW 逐步衰减，不因时间到期突然归零。
- 单位一致是输入义务。常数价格缩放不改变理论的 p 差和结构规则，常数量单位缩放不改变量比；浮点边界不应扩称任意编码逐位恒等。极端但有限的有效 V 比值可能在 `activity` 诊断输出中溢出为 inf，乘数仍受 clip 限制；当前输入检查并不承诺所有派生诊断都有限。

### 4. 日内状态更新顺序

每个有效日依次：更新 EW → 若未公开则输出未知 → 计算滞后 s/v 与当日急性事件 → 按 h=21、63 分别处理结构 → 写收盘后候选/极值 → 映射 phase。

每个尺度必须保持以下顺序，不能只冻结几条公式而省略：

1. 必要时初始化 S=0、运行高/低与双向候选。
2. 读取 `before=S`。若 before≥0 且创新高，更新最高点并**仅**重置向下候选；若 before≤0 且创新低，更新最低点并**仅**重置向上候选。
3. 逐个推进当前候选，计算当前 x、量权重、前沿和信用；检查确认。
4. 每尺度每观察最多一个确认。先保存被消费候选的完整 receipt，再改 S，设置当日 confirmed/confirmed_direction。
5. 确认后只保留一个从今日收盘创建的反向候选，弃去旧方向的极值。S=+1 的新运行高/S=−1 的新运行低均从今日开始。
6. 写入的是步骤 5 后的收盘状态；确认日表中的新反向候选不代表刚才确认用的旧门槛和信用。旧确认依据必须查 receipt。

S=0 时追踪两侧运行极值与双候选；S=+1 时只追踪新高及向下候选，S=−1 镜像。相同方向持续推进不会产生重复同向确认；结构只有待确认、向上、向下三态，不因日龄、冲击消失、波动下降或窗口滚出归零/升级。

### 5. 新前沿信用与量的精确作用

候选冻结方向 d、锚 p_a/原价/日期/观察、created、δ=√h*s_create、s_create、v_create；动态保留 F、Q、x、当日前沿及信用增量、量权重。`scale_at_anchor` 字段实际保存创建时传入的 scale；初始候选 a=63 而它是 s64，字段名不能掩盖此例外。

- `x=d(p_t−p_a)`。仅当 x 严格越过旧 F，且 `d*r_t>0`，才接受 `ΔF=x−F`，更新 F=x 与 `Q←Q+w*ΔF`。
- 量版 `w=clip(sqrt(V_t/v_create),0.5,2)`；只对今日首次接受的新价格范围计量。回访旧价、高量原地成交、退回后重走，均不重新加信用。F/Q 不回退、不衰减、不积负债；候选重置时一起清零。
- 确认须今日有合格新前沿、x≥δ、Q≥δ，三者缺一不可。高量不能豁免真实价格门槛，也不能单凭尺度下降或旧量离窗触发确认。
- `.5F≤Q≤2F` 为当前信用边界。若同一候选不断推进，最迟到约 2δ 足够信用，但不保证日历时间内必然确认；候选可能被新极值重置，价格也可能不推进。
- 全部前沿权重≥1 时，量版不能比纯价 δ 门槛更早；高量只能补足此前低量留下的信用不足。此结论针对相同候选起点，路径依赖造成重锚差异后不能机械逐日比较两个版本门槛。
- `joint=False` 同时将结构权重和急性事件乘数设为 1；其余逻辑保持，仍计算 s、量参照、activity。必须称显式消融，不是自动替换主版本。

### 6. 急性事件与结构描述

- `q=r/s`，`activity=V/v`，量版 `qeff=q*sqrt(clip(activity,1,4))`。qeff≤−2 为 acute_down，≥2 为 acute_up，按上述包容比较；去量时 qeff=q。
- 低量不减轻冲击，急性事件乘数范围 [1,2]；结构信用权重范围 [.5,2]。这两种量作用不同，不能合并写成同一量权重。
- 冲击每观察独立标记，无解除日、无“21日恢复”、无累计冲击债。事件只进入日志，不改变 S、F、Q、μ，也不触发买卖。
- local=S21，background=S63。双0=`unconfirmed`；恰一尺度0=`building`，building_direction 为已确认那一尺度方向；双上=`aligned_up`、双下=`aligned_down`、局部上/背景下=`rebound`、局部下/背景上=`pullback`。非 building 情况 building_direction=0。
- `S=0` 是尚无结构确认，不是横盘；`phase=unknown` 是预热/无效/缺失，不是 S=0。S 双上是最近方向确认仍在，允许同时 μ21<0 或近零，不自动表示高强度。

### 7. 输出、日志与继续计算边界

- 自然输出包括收益/EW、s/v/activity/q/qeff、急性标记、S/phase、每日参考 δ、当日确认标记、运行极值、两侧候选完整字段及 journal。无 `target/entered/exited/floor`。
- 非活跃候选 `active=0`，其余候选数值保持 NaN、日期空；不能把未出现候选的空值前填为仍活跃。公开行未确认日的 confirmed=0、confirmed_direction=0，与预热的 NaN 不同。
- journal 至少区分 candidate_reset（含 reason/previous_candidate）、frontier_extended、structure_confirmed（含完整 receipt）、acute_up/down、source_discontinuity。不能只保存 S 翻转而丢掉证据。
- `out.attrs['terminal']` 只保存结构 states，**不是完整可续算快照**：缺 EW、滞后收益/量缓冲、价格原点等。本版函数没有从 terminal 恢复的入口。当前精确复现方式是保留并重放完整来源段；将来若要增量流式接口须另定序列化合同并证明身份。
- 固定源码身份和输出字段，不等于承诺将任意 source、复权方式或接续初始化接入后仍同一结果。各实际输入沿用既有来源和哈希边界。

## B4 与 E0 的差异及复现裁决

| 项目 | 当前 B4 | 固定 E0 |
|---|---|---|
| 事件使用的输入 | C、V | 原事件 C、V；收复记忆还用当日 L，O/H作记忆审计字段 |
| 初始状态 | 首次公开 t64，以 t63 为锚的双候选 | t64 初始方向 −1、极点 t64 |
| 价格尺度 | 1.4826×前63绝对收益中位数，√21/√63 | 前63收益 RMS，√5 |
| 数值价格比较 | 原点对数坐标、32eps 容差 | 原价 γ4 容差、局部 log_ratio |
| 量证据 | 新前沿到达日量，累计信用；真实 δ 不豁免 | 极点之后至今的全段均量，直接乘反摆幅度 |
| 确认条件 | 当日同向新前沿＋位移δ＋信用δ | 反摆×量因子达到1，无 B4 同向新前沿条件 |
| 市场结构/参与 | 最近两尺度确认方向，无支持资格 | 向上事件建态/抬支持；收盘≤旧支持退出 |
| 跨日收复 | 无 E0 类型记忆 | 空闲高参与下跌→lower/reclaim；普通量后续可收复 |
| 退出定义 | 无交易退出 | 有资格退出；向下事件自身不退出 |

`study.py:24–27` 将 B3 既有结果中的 `e0_ready/e0_target/e0_entered/e0_exited/e0_floor` join 到原输入及 B4 自然输出上；`price_*` 又是另外一次去量运行。整张结果表不是单个 B4 函数的自然输出空间。直接读 join 的 e0_*，或保留整段 OHLCV 再重跑 E0，均不能证明“简单读取 B4 状态即可得到 E0”。

信息不足可作严格反证：保持所有 C、V、segment 和 valid 相同，仅改变某个高参与下跌日合法的 L，B4 的全部自然输出和日志完全不变；E0 创建的 pending_lower 会不同。设当时空闲、无原向上事件介入，C 从100降到95、V达到2倍参照，合法 L 可为94或90；后续收盘93会否决前一种记忆而保留后一种。再于无原事件介入时上穿 reclaim=100，后一种能由收复入场，前一种不能。这不是挑阈值拟合，而是 E0 依赖 B4 未读取变量的不可识别性。即使某些有限已见路径恰好状态相同，也不能推广为普遍等价。

只保留 E0 原向上事件通道、删去收复分支，仍不由 B4 自然 S/μ简单推出：尺度、量度量、初始化和事件顺序均已变。声称严格扩展至少要证明存在固定投影，在相同有效输入与初始化下逐观察重现旧事件、资格和支持；当前 B4 没有这样的证明，机制本身也不支持这种说法。

## 建议的分层措辞与保留条件

| 层 | 合理职责 | 保持 E0 身份必须注意 |
|---|---|---|
| 事件检测 | 原始极点、原量价确认、准备完成等量价事实 | 保留原 `event_frame_numeric` 事件核；其内部 target 不是最终 E0 |
| 事实与候选记忆 | 高参与下跌事实、价格否决/收复响应、候选边界和发生时间 | 原 pending 的创建被“空闲”门控，消费被原建态门控，其整个生命周期并非不带参与政策的事实层；仍不依赖实际账户 |
| E0参与资格 | 原事件/收复入场，支持只抬高，旧支持优先退出，同日不重入 | active不是实盘持仓，但 entered/exited确为政策决策；顺序不变才能逐行等价 |
| 选股/仓位/执行 | 排序、共享资金、槽位、手数、下一可成交时点、费用及成交失败 | 不应倒灌影响市场事实或把资格=1当作实际已买入 |

可把原高参与下跌检测和严格价格响应检测抽成可复用函数；但若统一事实账在所有状态记录全部下跌，再由适配器选择使用，须证明它对 E0 的 pending 创建、等待、否决、消费、退出日新建的行为等价。仅把旧状态字段改名、或把 `active` 全放入“市场状态”，并未完成职责拆分。

把 E0 定义为“事件检测与记忆驱动的结构参与政策，外接独立账户执行”，兼容其固定名称与实际代码。B4 则是当前方向/推进/事件结构/急性冲击指标层。二者可以并列成为研究基线；本次无需也不应为满足“B4可复现E0”的表述去改变任一冻结机制。
