# 换仓修复与I延迟：结论和机制分析

2026-10-26。用户授权EXE-001修复后重测，并研究原I延迟表现骤降。复用2024年初—2026-10-26的407科技股、11行业，各路径一个100万元有限复利账户；原1709股/90行业只作排名参照。9条新增机制路径＋3条完整恒等控制，经济一次、重跑0、结果后规则修订0。原算法/池/数据/排序/仓位不改；已见开发与当前快照偏差保留。

核心判断：EXE-001已修复，基础换仓不再因卖后收盘温度复核而空仓；修复后的1.5倍成交额换仓仍未稳定优于I。I延迟崩坏主要来自入场日有效事件与买单到期重竞、有限资源路径共同改变实际持仓，不能解释成同批股票买贵一天。两日买单候选有较强增量证据，但基础收益—回撤稍差、延迟回撤仍超过50%，不晋升为成熟统一策略。

## 1．修复范围及真实结果

原版：T收盘决定，T+1卖出，S收盘复核候选仍暖，最早S+1买入。

修复SD：T收盘锁定原I事件、换仓对象、1.5倍人民币成交额、预算/最大数量/结构支持；下一早盘先卖，卖款可用后办理原意图的买入。去掉卖出日收盘重新要求仍暖。部分卖出未完不买、原开盘破支持拒绝、整手/费用/真实现金和容量限制保持。各腿两市场日有效，新买腿从实际完整卖出日算起。新的每日路径重新选择全部机会，不是机械挪动旧189对。

只有日线，无分钟/逐笔资料。09:30卖、09:30:01买是模拟事件先后，第二个时间不是观察到的秒级行情。基础仍以各自开盘±5bps估价；配对买入额外25bps组用于有限压力，不证明真实卖后买的价格。原完整规则见PROTOCOL.md。

|同100万元|原跨日换仓收益/回撤|修复SD收益/回撤|原I收益/回撤|
|---|---:|---:|---:|
|基础|109.47% / 50.19%|115.46% / 45.37%|139.14% / 41.05%|
|双可变成本|99.85% / 52.75%|105.58% / 45.78%|132.58% / 41.18%|
|双腿额外延迟|65.79% / 40.51%|94.35% / 47.53%|3.37% / 58.67%|

基础SD期末215.46万元。相对原跨日版多5.99个百分点收益、回撤少4.82个百分点；相对I仍少23.68个百分点收益、回撤多4.32个百分点。延迟情景收益改善同时回撤增加，不能称所有风险都因修复下降。

基础235次发起，235次完整卖出且235次实际换入，卖后零买入0；双成本233对全部换入，配对买入25bps组222对全部换入。后者收益109.92%、回撤45.72%。这回答了原42次温度复核未承接的执行问题，但不等于逐一追回旧42次损益，新的组合和现金已经改变。

SD延迟组158次卖出、142次完成配对买入、16次配对未买：10次等待期间结构/行业/交易继续资格失效，3次已有普通买单占用同一候选而配对资金预约被拒，3次买单有效期内未买成。自然后续买入不冒充锁定配对完成。普通买单与换仓意图的身份争用仍需后续统一；本轮没有据结果改约或重跑。

### 换仓为什么仍落后

基础SD的尾部闭合净利润289.54万元，略高于I的282.16万元；普通闭合损耗173.43万元，高于I的155.09万元；开放/权益未结损益−0.64万元，而I为+12.07万元。尾部多7.38万，普通损耗多18.34万，未结少12.72万，合为净利润少23.68万。

显式费用6.54万元，I为1.79万元；闭合周期307对98，胜率41.69%对31.63%。价格滑点已经在买卖价中，显式费用也已含于净损益，不能再重复扣除。尾部/全部闭合亏损SD为0.89、I为1.62：SD仍需普通盈利交易补充才能覆盖全部闭合亏损；不能因为胜率提高而判定试错结构更好。

基础SD 2024/2025/2026截至期末分别33.95%/74.91%/−8.03%。它在前两年明显有效、后来被追赶，不是从未盈利。绝对成交金额与固定容量仍偏向当时的大活动规模，一换一仍无法释放三个各两股行业的第四行业名额；本轮没有改成量比或放宽行业，也没有因结果否定全部换仓。

## 2．原I延迟下降：首先是买入参与政策，而非卖出单独晚一天

保持原I每日买单和重竞政策的2×2机制拆解：

|买入额外等待|卖出额外等待|收益|最大回撤|
|---|---|---:|---:|
|0|0|139.14%|41.05%|
|1|0|−13.97%|52.70%|
|0|1|123.19%|47.35%|
|1|1|3.37%|58.67%|

只延迟买入已令结果明显恶化；只延迟卖出仍有123.19%收益。两个差额不可简单相加：退出时间会影响下一可用名额、行业配额、资本和之后买到的股票。双腿组合的收益反而高于只买延迟，是路径交互，不是卖出越晚越好。

### A．一次性市场事件与订单寿命混在一起

原I在E0结构有效且暖以上时，需要原建态或新量价证据fresh_up才产生买点；已有结构可以继续存在而不每天重新出现买点。原账户普通买单仅下一市场日有效。额外延迟会先跳过该日可成交机会，收盘旧单到期，后续还要通过当日信号/资格/排序/最小数量重新竞争；等待信用不保留原名额、金额或优先级。

基础I预约104单，102单有真实买入；延迟I预约379单，只有73单有买入，306单零买入，其中304单到期、2单期末尚待。304个已到期零成交中，303个已消耗等待事件；301个I结构仍有效，236个仍暖，114个仍暖且结构有效但没有新买点。故大量丢失来自执行机会到来前原事件不再重复，不应当全解释为市场判断失败。

相同股票＋相同决策日只匹配到36组订单；其中34组基础成交、延迟零成交，只有2组双方都成交，且这两组实际成交时刻一致（已有等待信用）。当前3.37%情景不能当成固定成交名单全部晚一天的纯价格压力，也无法从这2组得到可靠的纯一天价差估计。

### B．有限名额把早期小差异放大为长期机会差异

对基础I的102个有成交起源，在延迟账户同日的决策后状态：64个被股票/行业容量占用，34个相同起源已预约但未成交，2个已经持有，2个同起源成交。该分类描述真实路径，容量可能是更早分歧的下游结果，不能把64个都看作独立可追回机会。

源杰2025-07-02在延迟账户仍合格，但奥比中光、国民技术、ST合力泰、宇信科技、恒玄科技、宏景科技六持仓占满，光学光电子/半导体/IT服务各两股；没有源杰订单，不是把它晚一天买贵。腾景2025-10-24亦合格，但四持股加两待买占满六名额、三行业。原I源杰实际贡献112.66万元，腾景33.78万元；其它贡献正负抵消后，整户差135.77万元。不能将两个事后赢家金额直接加回账户，也不要求后续方案必须捕获它们。

### C．尾部参与损失超过普通试错减少

|万元，成本已含|基础I|延迟I|变化|
|---|---:|---:|---:|
|尾部闭合净利润|282.16|123.62|减少158.55|
|普通闭合净损益|−155.09|−105.78|损耗减少49.31|
|开放/权益未结|+12.07|−14.46|减少26.54|
|净利润|139.14|3.37|减少135.77|

延迟I胜率反而39.44%高于31.63%，费用也更少、平均仓位75.18%低于83.27%。收益下降不能归结为手续费增多、亏损单更多或投入更多；主要是少了足够金额的尾部贡献，普通交易少亏不足以抵补。

### D．58.67%回撤同时涉及净值基数、持仓和初始风险距离

基础I在2026-06-25峰值405.64万元至10-26的239.14万元，减少166.50万元；延迟I06-30峰值250.11万元至103.37万元，减少146.73万元。延迟组金额回撤更小、百分比更大，因为此前赚到的净值更少且持仓不同，不能将17.62个百分点回撤差全归为某次晚卖一天。

延迟I该回撤段主要净损耗包括宏和36.57万、金海通13.10万、海星12.74万、长光9.49万、有研硅9.19万、香农8.90万。基础I对应自己的回撤窗口源杰/海星回吐占比较大。见逐股实际日净贡献，不用事后最高价定义卖点。

在原失效位不变情况下，基础I实际首入距离中位12.07%，延迟I20.71%；超过20%的为25/102与40/73。这里混有股票/时段/数量选择变化，不能当同股买晚一天的纯距离效应，但清楚说明相同15%初仓未等风险。长光延迟入场距原支持41.20%；持有期间正常结构回吐与初始失败风险需分开管理。

## 3．可调整空间：先保留有限买入意图，再单独检验风险定仓

本轮只加入一个I-L2参与候选：T日原I事件创建买单，最多保留到T+2收盘；原预算/最大股数/支持位冻结、占用原名额，结构或行业/交易继续资格失效撤销，不要求T+1再出现新事件/仍暖。到期不无限延长，原E0趋势持有/退出不改。

|情景|原I收益/回撤|I-L2收益/回撤|
|---|---:|---:|
|基础|139.14% / 41.05%|128.35% / 43.92%|
|双成本|132.58% / 41.18%|125.18% / 44.13%|
|双腿延迟|3.37% / 58.67%|91.29% / 51.70%|

基础损失10.79个百分点收益、回撤增加2.88个百分点；延迟收益改善87.92个百分点、回撤减少6.97个百分点。基础与延迟收益落差从135.77缩到37.05个百分点。延迟平均仓位80.34%对原75.18%，低回撤不是通过少投入得来。但它仍有51.70%回撤，不是通过20%目标。

I-L2延迟尾部利润251.62万元、普通净损耗148.80万元、开放亏损11.53万元；比原延迟I多承担43.02万元普通损耗，换来128.01万元额外尾部贡献。新增试错成本确实保留并由新增尾部覆盖，支持有限承接研究价值，不支持把增加的普通损耗藏掉。

它没有“神奇补回源杰”：2025-07-02仍六股满仓，未参与原长趋势；后在2026-09-22买源杰，实际亏17.89万元。新增尾部主要来自德明利、腾景、光智、华特气体等真实持仓。仅卖延迟组同样没参与源杰原大行情仍盈利，说明不应按源杰专门改算法。

建议研究顺序（本轮不自动续跑）：

1. 将原I市场事件与两日有效交易意图区分，保留I-L2候选及原I对照。已经有可量化机制与有限经济证据，不需要先改G1量价公式、加入均线或更多过滤。
2. 下一有限仓位问题可把该候选与已验证的RB1首次风险预算单独组合检验，保持原支持/E0持有。不是简单用“距离>20%不买”过滤：原I源杰赢家首次失效距离35.04%，这种阈值也会挡掉大赢家。预算如何控制全部试错，须由新实验回答，不能把两轮各自优点相加。
3. 固定三行业/六股票/每业两股仍会阻塞后续有效候选。若研究资源交接，单独比较行业/个股机会与承接身份，保留1.5倍为原实验，不同时改配额、排序、退出和算法。现在没有证据支持将绝对成交额当作唯一普适换仓标准。
4. E0持有仍可能容忍较深回吐和持仓自然集中；本轮最高单股I-L2基础47.99%、延迟41.10%。不为压回吐加事后止盈、不因几个失败股票改变名单。算法机制调整需回到量价轨迹、背景/结构/新证据语义单独研究，延迟账户不是量价事实算法已经失败的充分证据。
