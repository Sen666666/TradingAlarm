# E0-AMT-P1：成交金额口径计算候选与收复逻辑审阅

2026-10-26用户正在逐项审阅E0，建议由成交股数改为实际成交金额，并质疑高参与下跌后的普通量收复。当前按“同一股票每天真实成交总额，人民币元”理解，不是全市场合计，也不是资金净流入。

## 金额口径

D_t为行情源实际记录的当日成交金额（CNY），不以收盘价乘成交股数合成。价格坐标/候选极点/支持/门槛/状态顺序暂不改。

原事件活动系数改为：

```
B^D_e = median(D_(e-21), ..., D_(e-1))
A_D(e,t) = clip(sqrt(mean(D_(e+1), ..., D_t) / B^D_e), 0.5, 2)
```

原收复记忆创建比值改为：

```
q^D_t = D_t / median(D_(t-21), ..., D_(t-1))
```

两个时间基准分别是候选极点e与创建下跌记录日t，均不包含基准日。√5/63/21、2倍记忆阈值不在同一轮顺手修改。

code/e0_amount.py显式basis=amount/shares，输出activity_basis/unit，原核内部legacy volume参数接收该明确活动输入。接口只接收已核实有效OHLC及正且已知金额的有序序列；缺金额明确报错，不静默回退股数。来源分段、有效观察时钟和权息/股数口径适配尚未在全池接入验证，因此不能宣称可直接部署到原I。

## 金额与股数的作用边界

- 横向绝对成交额统一货币单位，适合描述成交规模和流动性；不同股价导致绝对股数不可直接等同现金规模。
- E0原先使用同股相对自身历史的比值。若全段股数都乘同一常数，比值不变，已有一部分尺度归一；原逻辑没有拿A股票1000万股直接与B股票100万股判强弱。
- D=实际成交均价×成交股数，因此换金额也把价格水平及其变化纳入活动系数。金额没有消除公司/流通盘大小，绝对金额大不直接等于趋势强或净流入。
- 1.5倍跨股票换仓已沿用户要求使用人民币成交金额；本轮审阅的是E0内部活动口径，两层不要混淆。

## E0-REC-01：收复假设仍待验证

高额下跌只登记待观察记忆，不当日建立上行结构，也不自动买入。原条件只有C_t<C_(t-1)及相对活动>=2，不计算下跌是否正在加速，不能给它自动贴恐慌见底、吸筹或派发标签。

以后价格超过下跌前收盘，表示当时那段收盘跌幅被价格收复；普通量也可提供这一价格事实。当前假设不要求第二次巨量，因而可能接纳卖压减弱后的恢复，也可能接纳缩量反抽。单凭现有条件无法区分，不能把价格收复直接等同于持续上涨已经确认。

保留未收复/跌破低点的否决；若普通上行事件同日确认，原通道优先，不能把机会全记为额外收复贡献。金额替换不自动解决下降反弹问题。本轮不自行删除该通道，也不擅自添加收复日>=2倍活动；下一步若继续，先原始图核验、把该通道有/无作为单独问题，未经验证不晋升。
