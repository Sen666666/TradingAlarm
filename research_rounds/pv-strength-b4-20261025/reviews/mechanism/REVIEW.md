# B4 机制设计审查：只累计真实新价格前沿的参与证据

2026-10-25，独立设计审查者 `/root/b4_mechanism`。本文件是实现前的机制建议与反驳，不是 B4 实测结果。只读 AGENTS、研究共识及 B3 协议、结论和既有原始量价审阅；未独立重算 B3 数字，未运行 B4 模型、账户或下载行情，未修改 E0/R/R1。原有七标的和全部固定正反例不变；已见历史是开发材料。

## 判断

支持主 agent 讨论后提出的一个最小候选：**事件方向用固定价格锚与固定反转门槛判断；量只累计反转候选首次探索的新价格前沿；当前价格速度和日冲击另报。** 不再把滚动拟合 z 的改善解释成新上行证据，不设置按日数释放的上行许可，不把方向、速度和未收复历史重新压成万能温度。

最初独立建议是有界带符号位移账本。经反驳，单纯裁剪仍不能消除不同量/尺度权重造成的循环刷分；现更支持真实价格锚方案。下面给出明确理由，不把讨论中未采用方案混作第二个正式候选。

该机制可以进入同一批有限图检，但没有保证同时解决阴跌、箱体和快速启动。它解决的是“新确认必须有新价格推进”的逻辑问题；位移分辨率的取舍仍须接受反例。

## B3 失败对应的机制约束

按 B3 已保存结论，黄金缓跌受到历史巨大收益平方抬高 RMS 的影响，德明利有当日下跌却因窗口组成改变而 cold→warm，旧冲击到期也能回到 warm。这些事实只作问题定位，不作为日期规则。

新候选应满足：

1. 原价不动、仅量基准或波动估计改变，不得产生新的上行确认。
2. 当天价格下降，不得产生新的向上事件方向；静止更不能如此。
3. 对已经启动的反转候选，门槛不因旧异常离窗而降低。
4. 旧上涨累积了几年，不能增加新反转必须偿还的累计收益债。
5. 阴跌不需要巨量；低量只允许有限延迟，不能否认持续真实下移。
6. 价格静止可保留先前事件方向的历史身份，但当前速度应为零或趋近零；这不能命名为仍在强推进。

## 可计算的候选骨架

以下是主 agent 提出的待冻结机制，本文支持其核心。初始化、零尺度和比较容差必须由正式协议明确，不能留到看图后再决定。

以有效观察为时钟，`p_t=log(C_t/C_first)`、`r_t=p_t-p_(t-1)`。每个方向尺度维护：

- 已确认事件方向 `d∈{-1,+1}`；初始化阶段另用 unknown/未定，不填成已确认方向。
- 顺该方向的运行极值 `E` 及其产生观察 `a`。
- 在 `a` 时冻结的典型绝对日变动尺度 `s_a=median(|r|，严格在 a 之前的 63 个收益)`。
- 在 `a` 时冻结的量基准 `M_a=median(V，严格在 a 之前的 21 个观察)`。
- 固定反转位移门槛 `δ_h=sqrt(h)*s_a`，候选 `h∈{21,63}`。
- 当前反转候选的新价格前沿 `F=0` 和参与证据 `Q=0`。

`h` 只决定位移门槛，**不是 21/63 个观察的记忆寿命**。两个事件方向可以存续超过这些天数；报告应称小/大位移尺度，不能自动称月/季趋势。两门槛仅相差 `sqrt(3)`，不保证会形成彼此独立的局部与背景。

当新收盘沿 `d` 创造严格新极值时，以今日实际新价重锚 `E`，冻结新的滞后 `s_a/M_a/δ_h`，重置尚未确认的反转候选 `F/Q`。这是新价格证据替换旧候选，归档原因不能写“恢复了所有旧冲击”。

否则计算反向价差与新前沿：

```
x_t  = -d * (p_t - E)                 # 从顺向极值真实反向走出的 log 位移
ΔF_t = max(0, x_t - F_(t-1))
w_t  = clip(sqrt(V_t / M_a), 0.5, 2)
Q_t  = Q_(t-1) + ΔF_t * w_t
F_t  = max(F_(t-1), x_t)
```

只有 `ΔF_t>0`、`x_t>=δ_h` 且 `Q_t>=δ_h` 同时成立，才确认 `d_new=-d`。确认日归档旧候选并以今日收盘为新方向的极值，建立新候选；不得把刚发生的整段反转信用带进新方向的下一次反转。

普通量 `V=M_a` 时，`Q=F`，真实反向位移达到 `δ_h` 可确认。四倍量及以上最多使新前沿信用按两倍计，但仍必须真实走到 `δ_h`；四分之一量及以下按一半计，仍能随真实推进确认。量在实际方向事件的建立时点发挥作用，不能只把 `Q` 作为附属颜色。

**量效应的范围必须如实收窄：** 若某候选所有首次新前沿观察均有 `w>=1`，其确认与纯价格 `δ_h` 对照相同。高量不能比纯价格门槛更早确认，只能补偿同一候选先前低量前沿的信用不足。主要量增量是延迟低参与的新前沿；这仍是可证伪假说，不能宣传为一般放量加速识别或已证明经济增量。

当前速度可另报 EW5/EW21 的有符号 log 收益及原始日收益。其函数和预热须正式冻结；它们不反向更改 `E/δ/F/Q/d`。EW 速度变得较不负可以由权重衰减产生，那是速度估计变化，**不能命名为新的上行价格证据或结构恢复**。事件方向可以仍上，而当前速度已经负；这应同时展示，不由旧事件方向覆盖新负速度。

急性冲击应是独立的当日量价事件/幅度信息。历史冲击实际收复与新局部方向建立分别记录；不再要求每个旧冲击锚全部收复后才允许形成新方向，也不靠年龄到期宣称修复。若另保留持续 freeze 标签，必须另写完整生命周期；不能把旧 B3 的 21 日自动释放悄悄带入本候选。

## 可在实现前证明的性质

### 没有无限量价债，也不能用往返反复刷信用

因 `w∈[0.5,2]` 且只对 `ΔF>=0` 累计，任何未重置候选都有：

```
0.5 * F <= Q <= 2 * F
```

因此相同价格区域重复来回不会产生新 `Q`；只有真正扩展反向价格前沿才有新增证据。没有负信用债。只要有效输入持续、`δ` 为有限正值、真实反向前沿推进到 `2δ`，最低允许量权重也足以确认。这是有限延迟界，不是保证在有限天数内确认。

单纯带符号量价积分没有该性质。例如在不刷新原极值的区间中，反复低量上涨/高量下跌，净价格可以近零而积分趋向负无穷；反过来可刷出正信用。给积分加最终价格门槛只能挡一部分错误确认，仍留下历史负债。裁剪能限制债务，却仍使其经济/方向含义随路径权重偏移。

### 新向上确认不能在负价或零价日产生

当 `d=-1` 时，向上候选的 `x=p-E`。`ΔF>0` 表示今日价格严格超过该候选全部已见向上前沿，必然高于昨天价格。因此向上确认不能由当日下跌、横盘、量基准变化或分母变化单独引发。向下确认有对称性质。

这只证明“方向事件”的更新性质，不证明所有显示数值都逐日同号，也不证明事件方向就是当天涨跌方向。

### 旧大赢家不会无限保护新下降

一旦处于上行方向，反向确认距离总从最近真实运行高点开始测量，不从该方向最早低点或全部历史累计涨幅计算。过去上涨十倍与上涨 10%，若具有同一最近高点、同一冻结尺度和随后相同路径，则下一次反向确认相同。

该性质不意味着没有延迟：冻结 `δ` 很大时，后续缓跌仍要走出至少 `δ`。只是旧总涨幅没有进入偿还要求。

## 主动反驳与不能隐瞒的代价

| 反例/限制 | 机制实际会做什么 | 应如何解释 |
|---|---|---|
| 一次巨跌后连续小跌 | median 对少数极值不敏感，且当前反向候选门槛固定；持续位移最终跨线 | 比 RMS 更抗少数极端值，不等于方向不再依赖幅度 |
| 低量真反转 | 在 `δ` 与 `2δ` 之间才确认，具体取决于首次新前沿时的量 | 承认低量新趋势的确认延迟；不能把晚确认包装成质量保证 |
| 低量先探索，随后高量重访同一前沿 | 重访没有 `ΔF`，不能补记信用 | 量语义被严格限定为首次新价格探索的参与；不声称描述全部成交吸收或高量二次检验 |
| 大振幅箱体反复穿过两门槛 | 两方向可以反复切换 | 该算法没有“箱体检测器”；不能要求所有箱体永久中性，也不能按黄金日期加例外 |
| 极窄箱体且新极值频繁 | 重锚会改变下一次冻结尺度；低波动可令门槛收缩 | 这是价格触发的尺度更新，但仍可能让箱体敏感；须保留同一批图的实际结果 |
| 多年静止后仍保留旧上行方向 | 事件方向不因时间自动消失 | 必须同时显示无推进/零速度与事件年龄；不能称 hot 或当前仍在上涨 |
| 恒定小幅单边走势 | median(abs r) 包含趋势漂移本身 | 该尺度不是纯噪声、标准差、置信区间或统计显著性 |
| 一次跳升既过小门槛又过大门槛 | 可同日直接转为两个尺度向上 | 允许跳变；不等于已证明新平台一定保持，也不自动触发买入 |
| 下降中的强反弹超过大门槛 | 两尺度可转上而后又失败 | 阈值事件没有未来身份；不能拿随后失败倒推当时不得确认 |
| 连续主连换月量异常 | 首次新前沿的参与信用受供应商量口径影响 | AU0 已有口径限制继续披露，不能冒称真实资金流 |

本候选将“方向是否在当前位移分辨率上反转”与“每日移动多快”分开，但没有消除方向识别所需的幅度分辨率。若仍把 `d=+1` 独自绘成高温，黄金慢跌中可能继续得到用户反对的陈旧热背景；换公式不会修复错误展示语义。

## 冻结前必须补全的技术合同

1. **初始化与零尺度。** 无完整历史、median(abs r)=0、全静止后首次启动如何处理须事前写定。若用数值地板，明示尺度含义并严格要求真实新前沿；若沿用最近正尺度或输出 unknown，明示纯静止后启动的代价。不能让 `δ=0` 和相等价格制造确认，不能把 unknown 填成 neutral。
2. **严格滞后。** 冻结在极值日的 `s_a/M_a` 不能包含极值日自身，否则大变动会当日修改随后门槛，量也会污染自己的相对基准。
3. **状态顺序。** 先判断同向严格新极值；否则扩展候选前沿并测试确认；确认后新方向的 `E/F/Q` 如何初始化只执行一次。不能同日循环切换。
4. **缺失与 source segment。** 无效行输出未知，不把缺行情当 0 收益或 0 量；跨段重启与同段缺口桥接沿既有输入合同，分别记录。
5. **量下限不是观察事实。** 0.5 是使低量最终可确认的固定研究假设；不能称其为数据证明。正量但极低量仍按这一假设计入。
6. **读出分工。** 方向事件、当前有符号速度、实际幅度、急性冲击、未收复历史分别命名。不要再次压成声称跨标的等距、未来机会大小或概率的 0—100 分。

## 同一有限图检中的必要反例

仅列机制验收，不授权增加标的、日期、账户或寻参：

- 原有 24 条合成全部保留；同价同量前缀、单位变换、价格方向镜像、真实物理前缀保持。
- 固定价横盘任意长、历史尖峰逐步离开尺度窗口：无向上新确认，无实际收复记录。
- 从高点连续极小下降，量为普通和四分之一以下各一组：观察至 `δ/2δ` 边界，核对有限位移界，不能以天数要求调门槛。
- 相同区间高量上涨/低量下跌与反向组合反复循环：新前沿不变时 `Q` 必须不再增长。
- 低量先探、随后高量重访但未创新前沿：保留“不会补信用”的预期代价。
- 巨跌后静止、巨跌后反弹未回旧高、完整 V 修复、低量快速启动：新局部方向与旧锚收复日志不得混称。
- 同一冻结前沿和尺度下，只改量：价格门槛不变，资格时点按 `Q` 改变；普通量应退化为纯价格门槛对照。

真实图必须回看同七资产全部窗口；不能只把 B3 的具体失败日期改对。技术性质通过与语义支持分开，正常回吐不当成待消除缺陷，强度下降不默认卖出。
