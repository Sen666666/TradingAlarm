# B4 独立语义审查：方向、大小与新证据

审查日期：2026-10-25。范围：阅读项目交接规则、研究共识、强度/策略分层共识及 B3 协议和结论，对 B4 提出测量合同与事前可证伪条件。本文件是设计审查意见，不是已经实现、冻结或通过检验的 B4 算法；未写新算法源码，未修改旧产物，未运行账户。本审查没有独立重算 B3 数字，引用的失败以 B3 保存结论为据。

## 一、主裁决

1. **freeze 应作为“当前急性破坏”属性，与方向/上行证据分开。freeze→cold 不称升温。** 它只表示急性事件退出描述优先级，由持续下降接管。即使显示代码由 −2 变 −1，也没有新增向上证据，不能进入升温统计。
2. **方向与运动大小分开估计。** “向下运动较弱”仍然是向下；不能因为此前巨跌抬高 RMS，就把连续阴跌改称没有方向。强度若指大小，必须为非负量并同时显示方向；若指做多证据，必须另行命名，不能同时冒充绝对幅度。
3. **上行证据只能由新观察建立或增强。** 旧点离窗、波动分母降低、旧下降记忆释放、冲击年龄到期，最多改变旧证据的适用范围或可信度；不能单独给出向上转态。每次真正升温必须有可复核的新增量价证据记录。
4. **崩跌后的局部上行可以在旧高点之下重新建立。** “旧损伤价格已收复”与“当前有新的向上推进”是两个不同命题。不得用未收复历史高点永久否决新上行，也不得把新上行直接改名为旧结构已修复。

单条负收益之后仍保持上行判断，不自动构成错误；一段持续负向新行情却仅因滚窗机制从 cold 升 warm，才是本轮必须修复的证据矛盾。真正的新反弹后来失败，也不自动推翻当时的因果描述。

## 二、最小对外测量合同

以下是职责划分，不要求实现五套独立算法。公式可共享数据，但不能共享一个含义不明的读数。

| 输出 | 必须回答的问题 | 不允许偷换为 |
|---|---|---|
| 当前方向 D | 在声明的尺度内，已见价格主要向上、向下、静止还是冲突？ | 涨跌是否足够剧烈、未来方向概率 |
| 运动大小 M | 当前推进/回撤有多大，单位是什么？ | 有无方向、做多是否合格 |
| 上行证据 U | 当前上行判断建立到什么程度，最近被什么新证据增强或反证？ | 绝对机会大小、收益排序或账户仓位 |
| 急性破坏 A | 是否有当前仍支配描述的急性负向事件？ | 有序温度最冷档、必然长期下降 |
| 背景/未修复事实 H | 哪个已知较大尺度背景或损伤尚存？ | 永久禁止新方向建立、需要保住的浮盈 |

若最终界面保留 cold/neutral/warm/hot，必须说明它们究竟编码 D 还是 U；freeze 建议作为覆盖标志或单独带。复合显示例如“当前下行 / 低幅度 / 急性事件已结束”和“局部上行建立 / 历史下降背景仍在”比把两者硬塞进一个等距数值更忠实。允许保留一个显示代码，但不能据代码大小推导物理强度或把全部代码上升计作升温。

缺失、预热、源分段均独立显示 unknown，不能填 neutral，也不能靠重启抹掉不利证据。方向与强度不读取持仓、入场价、浮盈、E0 有效状态；E0 只作冻结对照。

## 三、方向、阴跌与静止

方向的基础量应有正负号和原始价格意义，例如声明尺度内的有符号推进；幅度、波动与参与程度可以描述其大小、可信度或确认程度。**低于某个 RMS 门槛，不等于方向等于零。** 若需要噪声容忍区或持续确认，须单独公开“未确认”及其原始负向数值，不能把它写成静止，也不能让旧正向背景自动占据空位。

因此必须分清三种观察：

- 静止：新增收盘完全不动时，新增有符号价格推进为零；量再大也不能创造向上或向下位移。历史拟合可以尚有惯性，但必须注明其窗口来源。
- 阴跌：连续小幅负向收盘累计下降，负向方向证据在积累；此前极端冲击可以降低标准化剧烈程度，不能把所有新增负向位移删除。
- 箱体：正负位移抵消、仍有振幅，与完全静止不同。不能为了区分阴跌而把所有小波动都判成趋势，也不能为了整理稳定而抹去持续累计下降。

方向层允许平滑和确认延迟，不能保证第一根小跌就转向。必须在真实输出前写定“持续同向输入在多少观察内应被当前方向表达”的有限响应条件；不得看完黄金、半导体或德明利后另选期限。滞后与误报应并列，不以切换少作为正确性证明。

微幅慢涨和同形大幅慢涨可以同方向、同相对形状，但 M 的原单位推进必须不同。标准化强度相同并不矛盾；宣称二者机会大小相同则越过合同。相同原则适用于微幅阴跌与急跌。

## 四、什么才算新量价证据

必要条件不是“今天又读了一行数据”。升温事件应保存一个证据凭据，至少含：旧状态及成立日、本次确认日、所用新观察区间、事先可知的参照、实际有符号价格推进、量的具体作用、仍未撤销的反证、转态理由。

| 字段 | 最低要求 |
|---|---|
| 新鲜性 | 证据的确认必须发生在待改变判断之后；旧上涨证据的再利用不能改写为新建立。初始化不计作升温。 |
| 价格贡献 | 存在实际新增向上位移或向上结构形成；纯静止、纯负向新行情、删除旧负向样本均不满足。 |
| 参照可得性 | 比较锚点/边界在当时已知，或由因果更新生成；不能用未来确认的局部低点倒填确认日期。 |
| 量的作用 | 明确量改变了何种证据的创建、存续、否决或恢复；只把当天量抄进日志不算。 |
| 撤销条件 | 说明后续什么价格/量变化会否决这条证据；不得用“未来上涨了”回头证明其成立。 |

这些是必要条件，不是“任意一根上涨就足够”的充分条件。实现仍须冻结一个普遍的确认规则，说明单日冲击、普通量连续推进、回撤后再推进分别如何读出。该规则不能含资产代码或失败日期，也不能因看见反弹后来失败便临时提高标准。

“新量价证据”**不等于必须放量上涨**。普通量上的价格推进可以撤销此前由高参与下跌创建的反证；但应能逐事件解释量为何影响旧反证的存在或释放。若声称量直接参与正向确认，还须给出相同价格、不同量导致不同确认结果的反事实。不能为了满足措辞强行让任何量变化都改变状态。

最重要的不可违背条件是：从某状态起点开始，若新增有效收盘全都不高于上一收盘，则期间不能仅靠旧数据离窗、分母变化或年龄到期产生新的正向证据。此条件不禁止急性事件退出，也不禁止置信度下降；它禁止把这些变化命名为向上恢复或升温。

## 五、到期、降级与恢复必须分开记账

建议把变化原因至少分成 `new_up_evidence`、`new_down_evidence`、`price_recovered`、`downtrend_takeover`、`evidence_expired`、`source_reset`。这些是语义类别示例，并不要求使用同名代码。

| 变化 | 合理解释 | 是否属于升温 |
|---|---|---|
| freeze→cold，局部下降接管 | 急性损伤变成持续下降描述 | 否 |
| freeze 标志到期且当前静止 | 当前无新冲击；旧损伤仍未价格收复 | 否 |
| cold 的旧证据老化、当前已静止 | 现在无继续下降证据；历史下降仍保留 | 否，属于方向/确定性重新描述 |
| 旧冲击前价格被真实收复 | 指定事件在价格上修复 | 是新增正向事实，但不自动达到最强上行档 |
| 历史高点下出现新的局部上行结构 | 新上行建立，较大尺度损伤可同时存在 | 可以，须有新凭据 |
| 冲击到期后显示 warm，而没有新正向凭据 | 旧反证消失冒充新支持 | 不合格 |

如果界面把 cold→neutral 机械呈现为“温度上升”，就不能再用一句“其实不是恢复”消除歧义。要么将这类变化移出升温序列，要么保持 U 不升并另显示 D 已静止。否则只是把 B3 已知问题改名。反过来，为禁止假升温而让静止价格永久 cold/freeze，也不合格。

## 六、从崩跌恢复的合理局部参照

局部重建可围绕崩跌后的因果低点、随后反弹和再测试形成的支持，或一个由新数据形成的推进段。参照必须在当时已知，且不能通过新低不断降低“旧事件已收复”的目标。应分别保留：

1. 原事件锚与未收复差额：回答历史损伤是否修复；不能被新事件覆盖。
2. 新局部参照与确认日期：回答现在是否形成新的上行证据；无需等到旧峰值。

V 形上行可以形成新方向，不应仅因没有第二次回踩就被定义为永远不可恢复；若唯一候选确实选择等待回踩，须把 V 形延迟列作事前代价。新局部上行仍在下降大背景中时，可同时显示“局部上行/较大尺度下降”，不能利用未来继续涨或继续跌决定今天该叫“反弹”还是“反转”。

本轮不宜把“更高低点”写成唯一强制公式。这是一个可解释的证据家族；最终采用的规则及无回踩的处理要在输出前统一冻结。高位旧结构尚未修复与低位新上行正在形成可以同时为真。

## 七、事前可证伪条件

技术通过与行为支持分别出具。下列测试针对一般机制，不按真实失败日期调整输入或门槛。

| 测试 | 事前要求或失败含义 |
|---|---|
| 冲击后追加完全静止 | 急性标志可以退出；方向在声明的有限记忆后为静止；不得产生新正向凭据。若只能靠永久 freeze 防止假暖，同样失败。 |
| 冲击后追加连续微跌 | 方向须在预先冻结的有限时限内表达下降；相对强度可低。若仅因前期 RMS 高而长期 neutral/warm，重现根因一。 |
| 旧大负点离窗、今日仍负 | 可以改变拟合数值；不得凭此建立/增强 U。若 cold→warm 而无新正向凭据，重现根因二。 |
| 固定价格，仅改变成交量 | 不得创造价格方向；若规则使用量确认，则只能改变已存在价证据的资格或程度。 |
| 单位变换 | 全部价格同乘常数、成交量同乘常数不改变方向和状态；量相对口径与价格百分比口径应保持。 |
| 同形幅度变换 | 对数收益乘正数，方向应一致；原单位幅度按比例改变。若声明相对强度可比，应另核对其行为，不能把同温误写成同机会。 |
| 对数价格反射 | 若方向核心声明对称，应方向反号、运动大小不变；做多证据或负冲击覆盖允许不对称，但须预先声明。 |
| 崩跌后持续真实上行、仍低于旧高点 | 允许形成新的局部上行，须给有限响应约束；若只能收复历史高点才成立，则承认测量的是旧损伤恢复而非当前趋势。 |
| 崩跌后单次小反弹再下跌 | 正向凭据须能够被新负向证据撤销；不能因一条旧凭据长期保护。后来失败本身不否定当时已经发生的局部上行。 |
| 相同价格不同量 | 至少检验已声明的量作用环节，证明它实际改变证据生命周期；无变化须按声明范围如实解释。 |
| 共同前缀与源分段 | 追加未来不改变过去；缺口/换源不能产生虚假的向上恢复。 |

逐日审计须分别列出：显示代码上升次数、真正 U 升温次数、急性退出次数、方向由下降变静止次数，以及每条原因和凭据。不能只报总切换次数来证明改善。

## 九、对 EW 净推进＋事件锚结构方案的追加评议

主 agent 提出：原单位 EW5/EW21 净 logreturn μ 的方向/大小单列；另用事件锚定双尺度结构确认；升档须真实价格跨越固定门槛和当日同向量价证据；freeze 只标当日急跌。该组合可以符合本合同，条件是各层在报告和数据中始终并列，各自接受反证，不能最后再混成一个无法归因的总温度。

最小可用输出为：`μ5、μ21`（signed，大小直接取绝对值）、`结构确认 S`（附锚点和确认凭据）、`当日急跌 A`。无需再制造第五个综合分数。μ 的图例应叫“平滑净推进”，S 的图例应叫“事件锚定结构确认”；两者相反时公开冲突，不用一种覆盖另一种。两结构尺度如果只是不同门槛的同一证据，不能宣传为两个相互独立的支持来源。

对于 `μ_t=(1−α)μ_{t−1}+αr_t`：

- 若旧 μ≤0 且新 r≤0，则新 μ 不可能转正。这项代数性质直接支持“不靠窗口删除从负变正”；但它不阻止负 μ 变得较不负，所以该变化只能称下行速度减弱，不能单独称新的上行建立。
- 完全静止后 μ 只按 `(1−α)^k` 趋近零，数学上不会在有限观察变为零，sign 可能无限保留。若要在图上将静止单列，需明确原价已静止而 EW 尚有历史尾迹；若另设数值零容差，必须公开其性质，不能把经济幅度过滤器隐藏在“零”里。
- 常数微跌 −δ 接在正 μ0 之后，`μ_k=(1−α)^k(μ0+δ)−δ`。转负延迟仍取决于 μ0/δ，不能由“已移除 RMS”推出任意旧路径之后都在固定天数识别任意微跌。必须保留“大旧上涨→微幅连续阴跌”的有限合成反例，报告真实延迟。

事件锚的“固定门槛”应是事先可知的价格边界；若门槛可因今日分母、过往窗口或时间流逝自行降低，必须另证当日穿越确由新价格造成，不能把阈值移动误写为价格突破。单有当日正收益仍不足以声称全部旧损伤修复；它只可能提供本地新确认的候选证据。

因此此方案的可支持主张是：把平滑方向、运动大小、结构确认和急跌事实分开，使假升温可以被逐条定位并禁止。尚不能先验主张：阴跌响应已无滞后、任何价格静止后方向严格归零、崩跌恢复与旧损伤已统一解决。
