# IX用于A股板块→个股选股：研究设计

2026-10-25。用户认为IX的收益/回撤取舍值得推进，不要求每个场景同时提高收益和降低回撤；要求结合此前E0全市场失败，研究IX如何指导全市场选股。本轮为分析和设计，只读旧结果并在4条已有B5个股样本应用冻结G1/IX作示例，无新账户、无算法修改、无行情下载、无换仓或仓位调整。

## 判断

IX值得作为下一轮全市场政策候选。它已经定义新买、退出和恢复；全市场还需定义当日多个机会之间的板块/个股优先顺序和有限资金分配。IX单资产收益不是选股能力的证明；相同的风险收益取舍在全市场组合中仍须直接检验。

之前全市场最后有效基线是RS-H1修正后的T0/T1/S0/S1，而非更早含整批代码回退/陈旧买单的结果。2015—2026-10-22四基础收益分别−66.64%/−65.84%/−85.92%/−56.57%，回撤75.58%/83.33%/92.33%/77.45%。程序问题修好没有形成策略收益边际。

旧只读诊断提供较强线索：T1有189/361个亏损周期，持仓收盘价MFE不足5%，贡献58.53%的亏损金额。RS-H1后其结构年龄中位25观察、距支持中位11.63%（原14、6.86%）；历史强排名、E0尚有效、当前值得新买是不同问题。不能把全市场失败只解释为赢家回吐或缺换仓。

## 推荐的完整职责分工（研究候选，尚未接入）

1. 板块层：行业指数独立计算B5-G1/IX，以该板块IX参与资格作为新买门控；不要求板块和个股同一天发出首次信号，保留板块行情中陆续启动的个股。
2. 个股层：候选来自个股IX的当日buy_event，而非只取IX.target、E0.target或温度>=50的所有股票。仍须满足数据、市场身份、未持仓和执行条件。未成交次日重新计算和竞争；有新证据则可再申请，不继承旧预算或优先级。
3. 相对排序层：资格与排序分开。首个移植对照保留RS-H1以识别IX净增量。随后可把既有`z21=sqrt(21)*mu21/s`在合格板块内/个股内排名作为一个有限替代假说；这是当前标准化推进的排序，不保证未来回报高，也可能将快启动但慢推进未转正的候选排后，必须记录代价。
4. 新建/恢复/延续分别标记：当前IX把结构内创新高也算新事实，故新信号不一定早。记录原结构年龄、已运行涨幅、保护距离、信号种类和实际成交。不能宣称IX已经排除了“涨了数周后才买”。首启不自动优先于所有恢复或延续，先检查各类是否有不同后续推进/损耗。
5. 持有退出：已有股票按自身IX冷/急跌或原结构硬边界退出；行业门控首先只影响新开仓，行业排名降低不另触发全行业清仓。恢复需新合格证据。槽满时等待自然退出，ROT-01换仓仍单列。
6. 资金：保持原6槽、最多3行业×2股（S1原单行业6股）、单股初仓15%、新增90%上限；上限不是必须投满。温度是顺序编码，不据100/50机械翻倍仓位。保护距离先列作入场风险诊断，不在本轮临时设距离过滤或风险仓位公式。

本轮未指定z21排序已经优于RS-H1；也未把“100分>50分”直接当作未来赔率排序。理论上，自身时间序列趋势与跨股票强弱比较是不同职责，可参考Moskowitz/Ooi/Pedersen原文：https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum 。该文期货结果不能用于证明本项目A股或IX收益。

## 最重要的组合风险

单标的IX离场后等待现金，全市场离场后往往还有其他暖股可买。若不断买入不同反弹，组合仍可接近满仓且承担连续试错。因此不能将单标的平均38.82%持仓日或16.88%平均回撤搬成全市场预期。

未来需首先记录每日合格板块/新候选数量、旧持仓退出后多久又被新股填满、熊市暴露、交易次数和普通亏损。板块内暖股比例/新进退出比可以先作量价背景诊断；未验证前不立即加入全市场开关、宏观因子或新的条件组。

RS-H1最低6收盘不绕过B5/E0的65有效收盘预热，上市头几周仍不在当前政策范围。第一轮继续沿用1709股/90行业、当前市值>100亿元及当前行业快照的开发口径，保留选择偏差；不以缺历史PIT资料再次阻断，也不静默取消市值门槛扩池。

## 建议的有限验证顺序（仅提案，非自动队列）

1. 先全池重放信号，不分资金：展示板块→个股→当日动作候选漏斗和初启/恢复/延续类型。检验单股退出、恢复是否与已冻结IX一致；特别保留A股T+1、涨跌停、整手、权息/复权与开盘破支持的执行差异说明。既有数据复用，无新下载。
2. 固定原RS-H1、行业门控、仓位和A股执行器，先只把个股E0政策换为IX，T0/T1/S0/S1各100万元、三执行情景；若另获执行授权，是12新账户、12旧RS-H1/E0只读对照。原行业门控暂保留E0，以隔离个股IX的增量。此处不是复用单标的分数份额引擎当A股账户。
3. 若信号/账户证据支持，再在固定S0框架单独比较行业E0门控→行业IX门控，随后才对照一个当前推进排序与RS-H1；不同时更换三层，不按收益挑板块或日期。是否追加由实际证据和后续授权决定。
4. 评价收益/回撤取舍、暴露、成本、普通/尾部贡献、槽位占用、错过大赢家及原因。接受更低收益换更低回撤的方案有价值；不以两项同时胜出作为唯一门槛。仍需看收益损失是否过大、风险目标与结果稳健性，而非只看总均值。
