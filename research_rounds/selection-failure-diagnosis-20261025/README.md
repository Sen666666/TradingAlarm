# 全市场失败原因：选股入场优先、风险预算放大、换仓未证

用户2026-10-25询问为何全市场账户显著弱于此前固定震荡/牛熊场景。本轮只读已有四基础账户，共1700实际持仓周期，无新账户、行情或算法修改。[事前诊断口径](PROTOCOL.md)、[结果明细](results/funded-paths.csv)、[统计](results/summary.json)、[核对](results/verification.json)。

研究优先级判断：先核对E0从固定资产到全市场个股的适用性、选股排序与入场位置的衔接，再研究初始风险预算；缺少换仓是明确的机会分配缺口，未证明是巨亏的主要原因。不是已量化的三项因果贡献比例。

## 以前的证据应该如何理解

先前固定场景检验指定了标的、区间，主要比较退出姿态；不是全股票池中选择、资金竞争、连续持有与再入场的验证。全市场账户跨度2015—2026年，不能与一两年窗口直接比较累计收益。

旧E0在2021—2026连续沪深300ETF−13.74%/DD38.38%，京东−86.50%/DD90.28%，并非所有标的或完整周期都好。半导体2025—2026上半年E0+162.01%，同期被动+199.00%，支持特定上涨行情中的持有能力，不足以证明自动选股产生超额。以上为已有结果只读引用，未新跑港股或其他账户。

E0源码一致不能证明个股量价结构也有效。过去的相对退出选择结论需要保留其有限范围；E0在全池个股上的适用性仍应待验证，而不能把失败全部分配给外围策略。

## 选股与开仓衔接：目前最强的研究线索

RS-H1是可计算、同h比较的排序假设，没有证明短历史与长历史同分位拥有相同的未来赔率。过去强、当前E0仍有效、现在适合新开仓是不同问题。等待候选每天重排，买单虽仅一天，仍可买入已经运行数周的E0结构。

T1原E0结构年龄中位14→25观察，决策收盘距支持中位6.86%→11.63%、P90 17.73%→31.70%。T0中位保护距离5.54%→10.95%。这支持入场位置后移/失效空间加宽的线索，不是RS或时效单项效应的因果估计。

对T1已结清472个实际周期，111赚、361亏；盈利周期净收益率算术均值31.87%，亏损周期−10.80%，平均盈亏幅度比约2.95，按23.52%胜率的等本金示例需要约3.25才相抵。实际各笔资本不同，账户应以逐笔现金损益为准：盈利周期合计198.64万元，亏损周期合计−262.38万元，利润因子0.757。仅换一套更公平的排序，没有形成正收益边际。

持有期间收盘价路径显示：T1有189/361个亏损周期MFE不足5%，贡献亏损153.58万元，占全部亏损金额58.53%；曾达30%收盘价格MFE再亏损的12个，贡献亏损3.83万元，占1.46%。其他账户不足5%组占亏损金额：T0 59.76%、S0 55.27%、S1 67.06%。这不是“普通亏损都属初次失败”的说法，也未测日内最高浮盈；支持优先检查入场后能否有效推进，而非优先收紧正常趋势回吐。

S0三种执行情景均弱于T0，行业过滤/行业RS两级排序尚未形成稳定的经济增量。此观察不自动授权删除板块主线或改成新行业过滤器。

## 仓位：资金上限未构成失败风险预算

初仓接近等金额，不是按距E0支持的失效空间等风险。按实际首笔成交价/股份与决策时净值计算、把已知支持转换到成交日因果权息坐标（开盘已破支持的单子另列），初始价格风险中位/P90：

|策略|初始价格风险/净值中位|P90|
|---|---:|---:|
|T0|1.48%|4.13%|
|T1|1.49%|4.17%|
|S0|1.67%|4.03%|
|S1|1.74%|4.27%|

这些是建仓时的价格距离测量，不是实际或保证最大止损；费用、跳空、停牌和无法成交可使损失扩大。不代表每只都同时承担P90风险，也不能把六个P90直接相加当成真实组合风险。T1按结清时间有24个连续亏损周期，当前没有明确的连续试错总预算。只有六槽/15%金额/90%投入约束，无法自行保证20%最大回撤。

应独立检验初始失败风险预算，而不是根据赢家浮盈去缩紧E0退出或锁盈。降低仓位也会减少尾部利润，效果尚未通过账户对照验证。

## 换仓：有缺口，但不是已证明的解药

T1有157个年度赢家窗口的主阻碍为槽位已满，说明机会分配受到已持仓约束。但有限资金账户本来就不能买所有赢家；事后知道赢家不等于当时能识别可替代哪只。

若继续按同一滞后的RS把旧强势股换成已涨很多的新强势股，可能增加买高卖低与交易成本。因此换仓需先验证候选相对现持仓的后续推进与初始风险差异，并检验持久性/成本，不能仅凭遗漏数量认定换仓能救活账户。本轮未设计、实现或回测ROT-01。

## 执行差异已查，不能拿它解释全部亏损

此前单标的引擎有首次开盘低于保护点的否决，本次全池引擎未加入。实际受此现象涉及周期及账面净贡献：T0 10个/−3.36万元，T1 7个/−0.88万元，S0 3个/+0.13万元，S1 1个/−0.07万元。不是当前全部实际亏损的直接主要账面来源。删除某交易会改变后续资金路径，不能直接把这些数当作修复后收益；仍须作为桥接一致性问题单列。

手续费亦不是全部解释：T1明确账面费用4.34万元，相比净亏65.84万元，已成交轨迹上的收益不足并非费用一项造成；没有计算零费用替代账户。

## 有限的下一诊断顺序

1. 相同股票、相同期间、相同数据和成本下，桥接旧单标的执行与全池适配，先隔离执行语义差异。
2. 用独立有限对照检验E0个股结构和RS排序是否提供入场后的推进优势，以及首次信号、迟入场的差异，不能把高分直接当开仓理由。
3. 固定信号，仅改变初始失败与连续试错风险预算，评价普通成本和尾部同时变化。
4. 在前两层有可解释证据后，研究ROT-01现持仓与新候选替换，不自动启动复杂换仓搜索。

以上为研究优先级建议，不是已授权的新增账户队列。本次保留E0、RS-H1及所有旧结果，交易改动和新账户均0。
