# 三维量价原型的独立机制建议与反对意见

2026-10-25。设计讨论稿，未冻结为正式候选，未运行真实新轨迹、寻参或账户。只在本目录写审查材料；E0、R、R1、RS、换仓、旧结果均未修改。范围仍为上一轮相同七条本地资产、已见历史开发材料。

已读共识 C02—C08、强度/策略分层共识、旧区域路径失败、旧顺序位移失败及 PVS-B1 协议/结论。后文公式是可实现建议，不是已经通过市场检验的结论。

## 1. 主张

建议保留三个独立职责，先不合成一个总分：

1. **推进 P**：最近实际价格路径以什么速度、什么方向移动。它不能单独认定长期背景已经反转。
2. **结构 R**：一个已成立的方向结构，保留了多少从固定起点到有利极值的位移；其支持是否仍成立、证据是否新鲜。一次摆动换腿不重置结构。
3. **冲击 D**：当前真实反向运动有多大，以及此前有成交参与的位移中，哪些价格区间尚未被反向运动收复。当前冲击与历史未结记录分开显示。

不把三者相减或取加权平均。这样“推进放慢但结构保留”“局部向上但旧下降结构未破”“结构暂存但刚发生大幅负向冲击”都能被直接表达。价格急跌时，即使局部 OLS 仍因之前上涨而为正，负向冲击必须当期出现，不能再被潜在暂时项吸收后只展示接近最强的正分。

**最强反对意见**：三个量并不自动成为统一可用强度。若后来拿高 R 抵消大幅负向 D，或用正 P 覆盖仍有效的下降背景，会重新制造 B1 的解释矛盾。当前建议解决的是职责与证据记账；它尚未证明横向排序能力、反弹/反转识别能力或经济价值。

## 2. 输入、尺度与初值

令 t 是同一明确数据段内的真实有效观察编号，p_t=log(C_t)，r_t=p_t-p_(t-1)。只用已有因果复权价量；不能用今天才知道的复权/分类修订过去。

共同滞后尺度为：

```
sigma_t = max(sqrt(mean(r_j^2, j=t-63,...,t-1)), 1e-8)
B_t     = median(V_j, j=t-21,...,t-1)
a_t     = V_t / B_t
```

sigma 是过去收益 RMS，不是去均值标准差。今天的大跌不先抬大今天的分母。量只相对同一资产的过去归一，不能把 AU0、ETF、股票原始量横比。

需要 64 个有效收盘才能取得 63 个已发生收益；第 64 个观察结束时初始化，不给结构方向，第 65 个观察开始给新输出。初始化价格 min=max=p_64，初始 DC 式阈值 delta_0=2*sqrt(mean(r_2^2,...,r_64^2))，下限与 sigma 相同。账本为空，不能把空账本写成已知所有旧冲击均已收复；状态注明“仅覆盖本段预热后的事件”。

5/21/63 是周/月/季度级有效观察的工作尺度；2 倍 RMS、2 倍过去通常量、1 倍 RMS 的事件门槛都是本轮待否证的探索规定，不是文献校准值或最优值。只建议一组，不按七资产结果调整。

零波动使用数值下限，原始速度必须并列；不能把低波动下的高标准化值解释为绝对推进很快。价格乘正数、成交量单位乘正数，应保持状态和相对量不变。

## 3. 推进：直接观察路径，不设暂时冲击回归先验

采用主协调者提出的 5/21 观察 OLS 斜率是可接受的最小选择。对 n∈{5,21}，令 x_i=i，i=0,...,n-1：

```
beta_(n,t) = sum((x_i-xbar)*(p_(t-n+1+i)-pbar))
             / sum((x_i-xbar)^2)
raw_(n,t)  = 21 * beta_(n,t)
z_(n,t)    = sqrt(n) * beta_(n,t) / sigma_t
```

raw 是按 21 观察单位表达的实际局部 log 速度，不是随后 21 观察的收益预测；z 是规定的相对波动显示尺度，不是 t 检验、上涨概率或真正已识别的底层漂移。n 个价格点只有 n−1 个相邻收益，必须在实现和图注保留这项身份，不把 sqrt(n) 误称精确统计标准误。无需 tanh，不把不同推进速度挤在 ±100。

这一个推进轴保留两个固定观察分辨率：快速启动通常先在 5 观察可见；缓慢单边可有较小 raw、较一致正向斜率；整理可在两个分辨率趋近零或相互冲突。后两类不能仅按标准化 z 的大小区分。

**反对意见**：OLS 会受窗口端点和跳空影响，急跌当日也未必立即转负；21 观察斜率会延续把较早的大涨算作正速度。接受这一明确局部语义，但 D 当期冲击及 R 结构必须完整展示。不得宣称“两条 OLS 线已经识别持续性”，也不靠再添第三、第四窗口修补每个案例。

## 4. 结构：固定 episode 起点，支持只在完整回撤收复后递进

建议用一个冻结尺度的 DC 式回撤/收复骨架。它借用了成熟的“从运行极值回撤达到阈值才确认事件”原语，**不是文献固定百分比 DC 原式**，也不是把 DC 换腿直接当市场方向。

每个结构 episode 保存：方向 d∈{−1,+1}、固定起点 A、有利极值 E、有效支持 S、其价格日期和确认日期、最近真实进展日、待收复 checkpoint K 及其回撤最深点 L。用方向坐标 q=d*p、e=d*E、s=d*S、a=d*A，可对上下行共用一套规则。

### 4.1 首次建立

从第 64 观察起维护实际价格 min/max，初始 delta_0 不随时间下降。第一次 p_t−min≥delta_0，建立 d=+1、A=S=min、E=p_t；第一次 max−p_t≥delta_0，建立镜像下降结构。建立当天为新 E 冻结 delta_E=2*sigma_t，后续反向建立也同样初始化。只有确认日 t 才有方向，极值发生日只作元数据，不能回填历史信号。等价极值保留首次日期，避免相同价任意排列改变锚点身份。

第一段方向只表示这个阈值尺度的已发生结构，不是假称取得了完整更长历史背景。没有越过阈值时输出“结构未成立”，不是中性零分。

### 4.2 一般更新顺序

每个有效观察严格按下列顺序处理，避免同一根价格既先抬支持、又利用新支持制造自己的破坏：

1. **先检查旧支持**：若 q<s，旧 episode 当期被价格破坏。归档旧结构及破坏时证据。反向新 episode 以旧 E 为固定 A 和初始 S，以当前价格为新 E；d 取反。新旧 episode ID 均写入该日记录。不能把新 R=1 伪称强度从弱直接恢复最强；它只表示新方向已发生位移尚未回吐。
2. **没有破坏才检查真实进展**：若 q>e，E 更新为当前价。只在这个价格真的刷新有利极值的时刻，冻结 delta_E=2*sigma_t；E 不变时 delta_E 不变。不能只因滚动波动率下降，原本未确认的旧回撤自动达到新阈值。
3. **确认回撤**：没有待收复 checkpoint，且 e−q≥delta_E 时，在今天确认旧 E 的一次足够大回撤，设 K=E，L=当前价。E 的发生日早于今天也不回填事件。
4. **保存回撤过程**：有 K 时，L 保存自该极值以来最深的方向回撤，即令 d*L 为最小值。后续低一些的反弹高点不能覆盖尚未收复的 K。
5. **确认新的支持**：只有当前 q≥d*K，才将该完整回撤的最低点确认。若 d*L>s，令 S=L；否则支持不变。K 清空。A 始终不动。这里低点是在重返 K 的今天才具有确认身份，不能提前在低点日给出支持。

上下行完全镜像：下降结构的 S 是有效反弹高点/阻力，只有新低收复完成后才可下移。等于支持不破坏；等于 K 可以确认收复，皆为事前边界约定。

### 4.3 保留与新鲜度

活跃结构的保留比例是：

```
R_t = d*(p_t-A) / (d*(E-A))
```

分母为正，活跃结构通常有 0≤R≤1。**支持 S 的递进不改变 A，不改变该比例的分母。** 新极值改变 E 是真实价格进展；摆动腿转换只建 checkpoint，不中性清零。输出还必须有距离支持的原始 log 距离 d*(p_t−S)、A/E/S 的身份、episode 方向与存续状态；单看 R 无法知道支持刚被破坏。

最近真实进展日只在“刷新有利极值”或“有效支持严格递进”时更新。63 个有效观察没有这两种进展，标记 `stale`：仍展示原方向/几何价位及最后证据日期，不能填成中性、删除结构或当成今天又确认。未来真实进展可恢复 fresh。这个 63 是证据新鲜度显示，不是价格自动治愈，也不自动使另一个方向成立。

### 4.4 为什么不只是旧摆动失败改名

原语确有重合：旧 `swing_structure_strength.py` 已有换腿、高低点比较，旧迟滞状态已有高点回撤。没有新颖性主张。

实质约束是：不在换腿时更换统一评分比较对象；固定 A 跨腿存续，S 只由已完成的回撤/收复推进，R 不承担当前推进或卖出职责。支持更新、episode 换代和新鲜度全部作为显式事件，不隐藏在一条“统一强度”里。若实现最后仍把最近两高低点均值作为 R 或把腿方向直接复制给 episode，便违反这个设计，不能沿用其解释。

**最强反对意见**：平滑上涨很久而无足够回撤时，S 可能远离当前价；旧大涨后的明显走弱也可能仍保留较高 R。它只表示旧几何结构没有被指定证据撤销，绝不等于当前趋势健康。P 与 D 正是为了暴露这一差别。若要求 R 单独既宽容整理又及时认定所有转弱，仍会回到不可统一的尺度取舍。

## 5. 冲击：价格当期可见；量创建可逐段结清的事件

### 5.1 当期价格冲击不受量保护

```
J_t = r_t / sigma_t
Jplus_t  = max(J_t,0)
Jminus_t = max(-J_t,0)
```

该 signed 冲击不依赖刚刚切换后的结构方向，避免一次急跌把结构翻成下降后，“相对新下降方向没有反向冲击”而在图上消失。低量跌停、跳空或连续下降仍必须显示。禁止“低量所以安全”的许可。

### 5.2 量门控持久事件

建议沿用主协调者的唯一组创建条件：

```
a_t >= 2  且  abs(r_t) >= sigma_t
```

满足时，当前 bar 创建一个有方向、有起点/终点、有确认日的位移事件。负向事件 p_(t−1)→p_t 创建价格区间 [p_t,p_(t−1)]；正向事件镜像。记录 event ID、birth episode ID、原始区间、冻结 sigma_t、a_t、创建日和每次结清日。a_t 只决定事件是否取得持久记忆身份，**不再乘最后分数**。

这是假说：“在同样至少一个过去典型波动的位移里，相对通常量至少两倍的运动，值得保存为可追溯、须经价格反向收复的证据。”不是说高量永远正确或低量没有信息。没有满足量门槛的价格运动仍进入 P、J 与结构破坏。

### 5.3 单调结清，防止旧证据复活

每步先用当前已知价格结清旧事件，再创建当前新事件：

- 负向事件的未结区间初为 [l,h]。令 l←max(l,p_t)；若 l≥h，事件结清。l 只升不降。后来价格再跌不能把 l 降回去。
- 正向事件的未结区间初为 [l,h]。令 h←min(h,p_t)；若 h≤l，事件结清。h 只降不升。

因此 100→96 的量价负向事件，反弹至 98 后只剩 [98,100] 未结；后来跌至 94，旧事件仍只剩 [98,100]，不能重新恢复 [96,98]，也不能把新跌的 [94,96] 算到旧 bar。新的运动若满足条件，另建新事件。普通量或低量的真实价格收复都可以结清，避免强制等另一次放量而漏掉恢复。

对每个方向，聚合的是所有未结区间的**并集原始 log 长度**：

```
Uplus_t  = length(union(正向事件的未结区间))
Uminus_t = length(union(负向事件的未结区间))
```

同一区域多个事件重叠只算一次；事件 ID 仍完整保存供审计。不能逐事件求和重复累加，不能用“旧起点减当前价”把后续不同 bar 的位移全归旧冲击。两个方向独立输出，不相减成净方向，因此不退化成已否决的窗口端点净位移。

### 5.4 旧账、新结构与过期

**不按 63 日过期删除，不因新 episode 形成清账。** 只有价格实际反向收复对应区间，才结清该位移。保留 age、最后部分结清日、出生 episode 和仍未结区间；数据段终止记 `unresolved_segment_end`，不是 recovered。

旧下跌在新上涨结构里可以仍有未结区间。其语义是“历史有量下移尚未全部反向收复”，不是“新上涨不可能成立”，更不是必须回到原价的目标。它不能作为压制一切新上行的硬门槛。图表须区分当前 J 与旧 U，并给出最老事件年龄和事件出生身份，不能把十个月前的遗留账当今天新冲击。

这是不合成总分的一个关键原因：若未来要求 U 对新趋势有多少否决权，须另行冻结问题，不能在看图后用衰减、过期或切新结构清账悄悄解决。

### 5.5 相同价格、不同量的可否证反事实

在同一已成立上行结构内，价格依次为 100→96→98→99→100。令第一步 abs(r)≥sigma，第一组 a=2.1，第二组 a=0.5，其他输入一致：

- 两组急跌当天的 J 和价格结构完全相同，低量组没有安全豁免。
- 第一组创建持久负向区间；到 99 尚有 [log99,log100] 未结。第二组没有这个量门控持久事件。两组近端 P 已可能相同转正。
- 到 100，两组关于该事件的未结负向量价位移均为零；第一组有完整恢复记录，第二组是未曾建立该持久证据。恢复当天不要求再放量。

若同一价格下的量互换只改变最终分数乘数、没有改变事件身份或存续，则实现没有完成此机制。反之，出现状态差异也仅证明量实际进入机制，不证明其判断更好。

**最强反对意见**：高量位移可能由风险分担引起、随后反转；低量位移可能因流动性枯竭而更危险。两倍量门槛没有自动的经济正当性。持续事件还可能只是价格几何的冗余表示；只有反事实、去量和真实路径审查可决定保留其解释。不能由“量改变事件日期”直接认领有效。

## 6. 五类现象，以及不能承诺的部分

| 现象 | 建议如何描述 | 主要反证/边界 |
|---|---|---|
| 快速启动 | 短 P 与正向 J 当期显露，结构可后确认；新事件有原始量依据 | 不预知启动能否延续；结构尚未确认要直接显示 |
| 持续慢涨 | raw P 较小而方向持续，结构极值/支持递进、fresh | 小但极平滑的涨幅 z 可大，不能冒称绝对速度快 |
| 趋势内整理 | P 放慢或相互冲突，旧结构仍存续；checkpoint 未收复可见 | 不能以后来再涨认定这时必须持有；持续无进展会 stale |
| 下跌中的反弹 | P 可真实为正，同时旧下降结构、旧负向事件未结 | 这是一组冲突证据，不应直接贴“整体强多头” |
| 真正转弱 | 负向 J 立即出现，P 后续转弱，支持破坏/反向结构依次确认 | 不承诺每次急跌都成长期反转；也不靠量小把下跌抹去 |

**长期背景不能漏掉 V 的设计约束**：P、J 与收复事件没有等待 252 日的背景门槛；V 的第一段上涨立即有正向运动描述。旧下降结构可以继续存续，须显示冲突，不让它封死局部新上行输出。后续突破当时有效阻力后结构再转换。如果某策略坚持只有旧下降结构完整撤销才买，则会承担早期 V 漏参与代价，那是后续策略取舍。

**不能同时许诺**：在共同前缀的早期 V 和下跌反弹之间，既永不把反弹说成新趋势、又必在 V 起点确认长期反转。量价信息相同即输出相同；因此本轮要检验的是解释一致和反证响应，不是提前命名未来结局。

## 7. 缺失、数据段与可重复性

- 非有限/非正价格、OHLC 次序不成立、重复/倒序日期不能形成新事件或分数，输出 unknown 并保留原因，不填中性、不用未来值补齐。
- 确认是真实报价但量缺失时，P/J/价格结构可独立更新；量门控创建状态是 unknown，不能当成 a<2。已存在事件仍可按真实已知价格部分结清，同时标记该段量证据不完整。若不能确认是真实观察，则整行不推进有效观察时钟。
- 停牌不伪造观察。下一真实观察的 r 是跨有效观察变化，不能冒称单一自然日冲击。不能把不明来源缺口静默当停牌；源分段明确时重启预热，旧结构/未结事件归档为边界未决，不能写成价格收复。
- 不以自然时间过去推断结构恢复。长休市只增加日历陈旧提示，不创造交易价格或结清旧区间。
- AU0 连续拼接与换月规则未独立认证，量和跳空可能含合约切换。它仍是开发机制案例，不能当可成交单合约或实盘证明。

建议保存每个结构事件和量价事件的发生日、确认日、旧新字段、更新理由以及数值前后值。前缀因果验证须物理截断输入；图上不在确认前画出已经生效的 pivot/S。

## 8. 事前合成否证例清单（尚未运行）

以下是语义断言，不是收益断言。失败先记录；本设计审查不为让断言通过而寻参。

1. **单台阶后横盘**：p 从 0 跳至 0.10 后恒定。短/长 P 在各自窗口移出台阶后应归零；R 可以保留。不能永久把旧台阶算成当前速度。
2. **慢涨与无漂移往返**：连续小等幅上涨，与相同振幅的 +a,−a 往返。前者 raw P 小而持续；后者端点回归、P 不应永久正；不能只因波动小就把二者都称最大强度。
3. **大涨后急跌、尚未破旧支持**：让 21 观察 P 仍正。Jminus 必须立刻大于零；不能让高 R 与正长 P 隐藏已发生的负向运动。
4. **普通量/低量连续大跌**：a<2，连续负 r。量账本可能无新事件，但 J、P 与支持破坏必须反应；不得给“无量价负债所以安全”的整体标签。
5. **同端点反序路径**：先涨后跌与先跌后涨，末端相同。P、checkpoint、部分结清轨迹应可不同，不能只由窗口净位移决定所有输出。
6. **部分收复再创新低**：100→96（量门控事件）→98→94（无新量事件）。旧未结区间只剩 [98,100]，不得重新生长到 [94,100]；这是旧位移复活的直接否证例。
7. **相邻事件与原始重叠**：第一负向 [96,100]，部分恢复至 98 后再产生 [94,98]。两条活跃未结区间为 [98,100] 与 [94,98]，并集为 [94,100]，长度不是两个原始区间之和；事件 ID 均保留。严格先结清再新建时，同向活跃区间不应内部重叠，见第二轮审查补充证明。任意输入区间的 overlap union 工具测试与这项真实路径不变量分开。
8. **完整收复后再次下跌**：100→96→100→96。第一事件已结清；最后一步只有满足条件才创建新事件，不能恢复旧 ID/原量权重。
9. **换腿但未破支持**：一个完整小回撤/收复。结构不在腿转换时变中性；S 只在确认收复后提高，A 与 R 公式不因 S 更新改变。
10. **相同价格的锚点与量排列**：相等高/低反复出现、不同成交量附着。相同几何分布下等价高低点的任意排序不得改变结构价格/支持；量事件本身允许因时序不同而不同，但原因必须来自实际事件顺序。
11. **尺度下降而极值不变**：高波动形成极值后价格无新极值、sigma 逐渐下降。delta_E 不变，不得凭分母下降自动确认过去回撤。
12. **长整理与陈旧结构**：超过 63 观察没有新极值/支持递进。只标 stale；R 不归零，旧区间不自动结清，重新突破才恢复 fresh。
13. **长期下降后 V、与同前缀反弹后再跌**：分叉前所有输出逐字段相同；正向 P/J 先显露，旧结构冲突保留。不要求正确提前命名未来真反转。
14. **新上行结构仍有旧下跌事件未结**：不允许换 episode 清账；也不允许旧 U 硬封顶新 P/R。事件年龄和 birth episode 必须可见。
15. **量单位/价格单位/物理前缀**：单位缩放恒等；未来追加不改变历史事件；重复行不能重复建债；缺失量不是低量。

若三元组最后仍只能用“这几个案例图上看着合理”支持，应停留在原型；不自动追加阈值、回测账户或全市场排序。

## 9. 来源与推断边界

- [Glattfelder、Dupuis、Olsen，Patterns in high-frequency FX data，§3.2 Algorithm 2](https://arxiv.org/html/0809.1040v2)：提供从运行极值出发、达到固定百分比阈值才切换的 DC 算法。这里借用事件抽取原语；把阈值锚定为滞后 RMS、保留独立结构 episode、支持推进和三维输出，均是本稿另立的设计规定。原论文的高频外汇规律不证明 A 股/ETF 日线规则有效。
- [Glattfelder 与 Olsen，The Theory of Intrinsic Time，§2](https://arxiv.org/html/2406.07354v1)：说明按阈值确认方向变化及不同阈值分辨率。此处只引用结构抽取含义；不把所谓平均 overshoot 规律移植成单次行情预测，也不由此认领成交量机制。
- [Llorente、Michaely、Saar、Wang，Dynamic Volume-Return Relation of Individual Stocks](https://web.mit.edu/wangj/Public/Publication/Llorente-Michaely-Saar-Wang02.pdf)：模型中不同交易动机可对应延续或反转，研究价量的后续动力学关系。它支持“不预设放量永远延续”的审慎边界；**不支持仅凭 bar 量识别知情交易、资金流入流出或吸筹/派发，也不推出本稿的 2 倍量门控与区间记忆公式**。

来源只为明确原语与限制。可靠性仍须由同一组固定原始图、反事实、独立实现和失败记录评价。本文未下载新行情，未跑真实候选，账户 0。
