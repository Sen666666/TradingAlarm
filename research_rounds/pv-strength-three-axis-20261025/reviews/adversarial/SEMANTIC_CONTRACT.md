# 三维量价：独立语义与不可识别性审查

2026-10-25。独立审查角色：adversarial。依据 `docs/RESEARCH_CONSENSUS.md` C02—C08、`docs/TREND_STRENGTH_SCOPE_2026_10_25.md`、PVS-B1 的结论、语义补充与定义输出复评。本文是下一原型的建议合同，不是用户永久定义，也不是已验证的算法。

仅写本审查目录；不实现真实模型、不生成信号、不寻参、不运行账户、不改变 E0/RS/换仓。旧结果完整保留。真实图检固定池为 AU0/518880/512480/001309.SZ/688981.SH/600036.SH/600519.SH，主展示 2021 年以后，使用全源历史因果预热；这七条既有材料全部仍是开发历史。本文件没有新增真实看图或认领新的实测结果。

## 1. 核心裁决

三轴应回答三个不同问题，而不强迫它们同时翻向：

1. **推进 P：最近声明尺度内，实际量价路径朝哪边、以多大速度推进？**
2. **保留 R：之前已经建立、身份固定的某一方向结构，现在还有多少可见证据未被破坏？**
3. **冲击 D：相对该结构方向，已经发生的反向压力有多大，哪些部分仍未由实际后续价格收复？**

`P>0、旧上行结构R低或未建、相对旧下行结构的反向冲击D高` 可以是一个完全合理的熊市反弹前缀。`P接近0、旧上行结构R高、D较低` 可以是高位整理。`P中期仍正、R尚存、D当日显著增大` 可以是趋势内急跌，不能立即被强制归为结构反转，也不能称为“当前各方面仍最强”。

**建议本轮优先输出三轴及其原始单位，不急于压成单个总分。** 三轴同时显示能消除“把局部速度误称为全部趋势”这一解释错误；不自动证明新的结构定义有识别力，也不证明经济增量。

## 2. 最小可检验合同

### 2.1 输出对象与必要元数据

允许一个声明尺度的显示元组 `P_h、R_(a,d)、D_(a,d)`，但必须同时记录：

| 项 | 必须声明的内容 |
|---|---|
| h | 观察时钟、推进响应尺度/有效记忆；日历日和有效交易观察不得混用 |
| a | 结构证据身份、形成和首次可知时间、当时可知的支持/阻力或等价证据集 |
| d | 结构方向 +1/-1；尚未建立结构时为 unknown |
| 生存状态 | 未建立/存续/受损/已破坏/替代，以及每次转换的证据 |
| 量作用 | 哪个价格条件下，量改变了建立、存续、否决或恢复；不是“量更高所以总分更高” |
| 单位 | P 的原始每观察对数速度及尺度；R/D 的原始证据量和显示映射 |
| 数据有效性 | 预热、缺失、零量、陈旧报价、无效 OHLCV 的处理；未知不能填中性 |

方向和锚点身份属于解释元数据，不是额外强度轴。若只肯显示三个有符号数，可显示 `P_h、dR、-dD`，仍须保留 d/a，否则结构换向时同一个数的含义会偷偷改变。不要随着 P 每次变号重置 d，这会把未收复的反向冲击一键清掉。

若需要多尺度，同一尺度内遵循同一合同，不许在某张图用短周期 P 解释、另一张图改用长周期 P 免责。当前 E0 只作独立、只读的结构参考；不能用“E0有效→R高”来声称新结构已获得独立验证。

### 2.2 推进 P：已实现路径的速度，不是方向确定性

- 必须包含实际发生的最近价格变化及其时间，不是仅估计一个假定未来会恢复的潜在漂移。
- 可以降速、直接跳变、跨零，也可以在单日急跌后仍为中期正值；后者须和 h 一起说明。
- 对共同前缀追加一根实质负冲击，在固定事前尺度诊断中，不能让“当前向上推进”反而增强；幅度很小的输入变化可因阈值而无变化。要求反映方向性证据，不要求一次下跌必须翻负。
- 必须另存原始速度。相对低波动的慢涨得高标准化 P，只说明速度相对自身噪声高，不能解释为绝对涨幅大、持续概率高或横截面优先级高。
- h 内长期横盘后，持续推进应衰减至中性附近。是否保留旧结构由 R 解释，不能靠让 P 长期维持强正替代 R。

### 2.3 保留 R：已建立证据的存续，不是当前位置比入场价高

- R 依赖市场证据，独立于账户、买入价、最高浮盈；禁止按持仓定义“还有多少利润可回吐”。
- 新结构尚未建立时为“未建立/不可评价”，而非自动 0 分；旧结构被破坏后的 0 与从未有结构不是同一事实。
- 支持/阻力、高低点或事件都必须当时可知。使用右侧确认的拐点，要到确认时才建立，不能回画到拐点日。
- 结构阈值或证据集必须计算前声明。没有越过声明的破坏条件，单根反向冲击可以只降低 R 或保持 R；越过已声明的充分破坏条件，不能仍报告“同一旧结构完好”。
- “结构保留”不等于“仍在上涨”，也不必强求横盘越久 R 越低。若 R 是几何存续，就可长期保留，但必须显示证据年龄；若 R 还代表当前活跃支持，必须预先声明证据如何过期。不能看见漫长横盘后临时换口径。
- 新建结构、抬升锚点和替代旧结构须有显式事件。R 由于换锚大幅跳升时，要分开报告“同一证据变好”和“换了一个证据对象”，不能把每次换锚后的满格当成连续强度改善。
- 不必等价格收复全部历史跌幅才允许新的局部上行结构建立；也不能凭一根反弹便假定全部旧损伤已被修复。

### 2.4 冲击 D：可见损伤及未收复部分，不是未来会跌的概率

- 方向必须相对固定 d，既可有下跌中的向上反击，也可有上涨中的向下冲击，不能仅为多头定制。
- 对同一前缀和方向，发生超出事前材料性尺度的反向价格运动时，D 必须在该收盘后有可追溯增加；不能因低量而认定价格损伤没有发生。
- 量可影响该损伤的证据置信、建立阈值或持续性解释；不预设放量更坏、缩量必然可忽略。一次高量急跌与后续低量收复都应按当时新证据更新。
- 若 D 声称“未收复冲击”，只能由实际反向缺口收复、结构替代或事前明确的记忆到期处理；不能仅靠时间过去或假定均值回归便写成“已收复”。记忆到期应记为遗忘，结构替代应记为旧债终止，二者都不是价格修复。
- 若 D 实际只代表近期冲击速率，可以按固定规则衰减，但必须改称“近期压力”，不能继续拿它证明旧结构已被修复。
- 即使 R 二值保持有效，D 仍可很高。R 与 D 不要求互补，也不要求总和为常数。

### 2.5 三轴的相关性不应被掩饰

同一跌幅可能同时降低 P、损坏 R、抬高 D，这不是三个独立证据投票。如果 R 和 D 都是同一支持到峰值区间的单调函数，它们可能只是重复编码。应检查在相同 R 的配对前缀中 D 能否表达近期冲击/恢复过程，在相同 D 中 R 能否区别原有结构与从未建立结构；不要求统计正交，不把“三条线不同”自动称为三种独立信息。

## 3. 急跌后高分：何时矛盾，何时只是尺度取舍

### 不应判为矛盾

- 一根下跌后 21/63 观察的净推进仍为正，P 声明测该尺度，且其原始速度已有下降、D 同日记录冲击。
- 急跌尚未穿透事前结构破坏条件，R 高但 D 高；这表示旧结构受压，不能由未来结果倒判当时必须看空。
- 结构完好且近期推进慢，R 高而 P 低。用它持有或退出是策略的另一个问题。

### 应作为语义阻断项

1. 面向用户称“当前综合强度接近最强”，但一连串可见反向运动几乎不改变任何轴，冲击只被埋在一个预计会自动衰减的隐变量中。
2. 同一旧结构已满足冻结的充分破坏条件，R 仍称完好；或换成更低锚点后又满格，却不报告身份替换。
3. 原始当前推进已明显下降，仅因当期分母改变或饱和映射仍接近满格，却把满格解释为没有转弱。
4. 明明没有价格收复，D 随时间自行消失后被解释为“已经修复”。
5. 模型在反弹时将 d 改为上行，把旧下行背景及恢复缺口从输出中消除，再宣称已经区分熊反弹与新上行。

第 1 项不是要求给某次急跌预设固定负分；必须先明确总分究竟声称什么及哪些轴可否决这个声称。若没有该合同，“看起来过高”只能记作解释不足，不能伪造精确应得分。

## 4. 熊反弹与 V 形恢复：不预知，仍可更新

一个已建立下降结构中出现连续可见上行时，局部 P 应可为正，而且幅度可以很大。此时有两个不同对象：

- 旧下降结构：R 可能被削弱，D 表示相对下降方向的反击已兑现多少；
- 潜在新上行结构：尚未建立或证据初生，不能从 P 的正值直接继承成熟 R。

新上行可以在低于旧峰值的地方独立建立；这不是把所有熊反弹永远压成负值。需要的是事先明确新结构的出生、撤销与替代事件，而不是等未来涨够后回填它早已成立。

**“熊市反弹”和“V形真反转”是带未来结局的场景名称，不是每一共同前缀都有可观测真值。** 相同 OHLCV 前缀，无论后面下跌还是持续上涨，所有输出、证据对象和不确定性必须完全相同。分岔之后可逐步或跳变更新；不能同时要求“第一根就认出真反转”与“绝不把同前缀假反弹认强”。

## 5. 稳定：固定证据的行为稳定，不是曲线平滑

| 应评什么 | 为什么比少变号有意义 |
|---|---|
| 前缀恒等 | 排除未来重绘；未来成功或失败不能改变旧判断 |
| 不跨证据边界的小幅微扰 | 评价相同可见情形是否无故改变结构身份；不是禁止边界附近跳变 |
| 重大新证据的响应 | 一根大冲击可以合理跳变，不能为平滑而延迟记录 |
| 结构状态切换的证据一致性 | 整理中允许 P 正负变化，R 的破坏/重建应有对应事件 |
| 非收复期间的记忆 | 评价损伤是否被偷偷遗忘；不能奖励更快自动回归强势 |
| 收复后更新的代价 | 既测反击响应，也测旧背景能否在真恢复中解除，避免永远停留弱势 |
| 显示可分辨性 | 端点饱和可能把真实变化抹掉；少变号可能只是信息丢失 |

不把全路径总变差、相邻变号数、分类次数的最小化列为目标。这些只能描述显示和尺度，不能解释策略优劣。评价需同时展示“噪声微扰的额外切换”与“材料性冲击的响应”，单独优化任何一边都会奖励迟钝或过敏。

## 6. 公平尺度对照

1. 所有候选使用同源完整前缀、同一观察时钟、同样预热可用性。短历史未预热标未知；不能把旧候选未知日填0后与新模型比较。
2. 同时保留每观察原始对数速度、一个公共经济观察跨度的等效幅度、各自标准化值；后者不冒充已实现或保证实现的收益。
3. 响应延迟同时以观察数和 `延迟/h` 展示。比较不同 h 不能只奖励最短响应，也不能以长 h 为所有冲击不响应免责。
4. 分母本身是机制。共同前缀分岔首日可使用完全相同的滞后尺度做诊断；后续另展示原生尺度与统一事前尺度，分开“速度改了”和“标准化改了”。统一尺度是诊断面板，不可结果后替换正式输出。
5. 价位平移/价格单位变化、成交量单位倍乘应保持语义；波动幅度、持续时间、时间压缩并非天然不变量，必须分别声明。把 21 根涨幅压成 1 根跳空不是相同趋势证据。
6. AU0主连、ETF与股票的量不能直接当同一交易参与单位。单证券的相对量和波动标准化可做内部证据，不能据此认领横截面经济可比或全市场排名有效。
7. 不按事后最合意的模型尺度挑例子；固定主尺度和有限诊断尺度，报告每个尺度的相同完整反事实。

## 7. 不可识别性与不可要求的前缀

- 仅凭相同 OHLCV，无法唯一确定一个急跌是暂时冲击还是永久信息、某次放量是吸筹还是派发、下一次反弹能否延续。可以保留竞争解释，不能把模型内部权重写成真实概率。
- “潜在价格、暂时项、持续漂移”具有分解自由度；拟合好不说明每项经济含义被识别。三轴同样需要可见证据约束，不能只是重命名三个隐变量。
- 日线 OHLCV 对盘中先后顺序不完整：同一 OHLCV 可以来自先创新高后急跌，也可以先急跌后收复。未增加可用盘中数据前，不能要求两者产生不同日线输出。
- 跳空后的“永久台阶”与“次日回补”在跳空日完全同前缀；“长期横盘后上破”与“横盘后下破”在分岔前也是如此。对这些前缀只评已见推进/冲击及不确定，不评是否预言结局。
- 零期望噪声能实现局部单向路径。P 对已见路径为正不等于错误；把它解释成未来胜率才越界。
- 相同端点不必同分，相同收益多重集也不必同分；但输出差别必须能归因于顺序与当时可见尺度，而不能选择性叙述。

## 8. 原型进入图检前的有限准入

只建议准入一个明确公式和固定自由度的原型。先完整写出上述口径、有限合成场景及预期关系，再算并一次保留全部结果。硬阻断：未来重绘、方向镜像不符合合同、未知被伪造为中性、锚点回画/身份偷换、低量清除已经发生的价格损伤、实际未收复被说成已收复、同前缀按未来标签产生不同输出。

其余慢涨、反弹、整理中的取舍必须列为支持/否定/证据不足，不能因一项失败自动叠加过滤器，也不能因为全部技术不变量通过就晋升统一强度。合成之后再对固定七资产做原图解释与模型叠加复查；不添加赢家日期条件，不启动阈值或账户。本建议本身没有授权 E0 修改或任何交易。
