# 固定位置的量价响应研究

本轮以18个已见开发案例中的预定日期冻结价格边界，观察首次触及、退回和再次触及。目的在于辨别新的观察信息是否有用，不是输出另一套未经解释的主导趋势标签。

**已完成：** 18窗口、22审阅时点、83张唯一分层图全部看完；21份阶段判断锁定。OHLC有明确新增信息，量主要补充条件解释，尚未证明方向区分增量。5个无触界窗口暴露固定外边界遗漏内部结构的问题；美团两次下探后反弹、重庆燃气放量收回后次日失效均保留。没有新趋势分类器、参数修订或账户。

结论与后续唯一任务见[正式报告](../../docs/RESEARCH_BOUNDARY_RESPONSE_2026_10_20.md)。下一步先做参照位置候选的旧机制等价性审查，不直接接另一个完整模型。

- [冻结协议](protocol-v0.json)与[冻结摘要](protocol-freeze.json)：先于本轮事件输出保存；21观察尺度只为限制实验，不是优化结果。
- [数据来源](inputs/manifest.json)：14条原始来源可追溯的OHLCV，价格复权因子与量的股数调整分别记录；未补数或联网。
- `results/v0/`：每日双边界事实、预定事件的分层图、另存的后续响应。生成程序拒绝覆盖。
- `reviews/`：按共同边界下的收盘视图P、增加OHLC的H、增加成交量的V，分别锁定判断；首次触及完成后才审再次触及，最后揭示后续O。见[看图前的顺序修正](review-order-addendum.json)。
- `code/`：有限观察器和验证代码；不导入账户模块，不生成交易或净值。
- [精确事件表](event-evidence-summary.csv)：分层审阅完成后汇总，包含未来响应标签，不可作为当日特征。
- [观察器验证](validation.json)与[审阅锁验证](review-lock-validation.json)：前者核对因果机械性质，后者核对21份阶段文字未变及保存顺序，均不证明预测能力。

## 这一轮能回答什么

能检查同一已知位置的推进是否停留在日内、收盘后是否保留、回到内侧后如何再试，以及成交活跃是否改变当时的竞争解释。尤其检验“低量等于健康”和“高量等于突破可信”这两种过度简化。

不能由18个窗口验证主导趋势已经解决，不能估计量能的普遍预测优势。P也不是独立的纯收盘算法：三个视图共用先前OHLC边界，事件日期由OHLC触及规则决定。分层揭示减少本次解释中的信息混用，不能使已经研究过的历史变成盲测或样本外。

## 观察与机制的边界

1. OHLC不能还原日内高低先后；同日触及两边必须保留未知。
2. 持续在边界外运行不是多次独立突破。只有经过完整未触及观察后的再接触，才进入本轮的再次触及记录。
3. 一次越界收回只是一项事实，不自动称为假突破、吸筹或派发。
4. 成交量只在其对应价格响应和位置上解释；量低不能抹掉已经发生的价格破坏。
5. 后续1、5观察响应仅用于核对先前解释，不能回写当日判断。研究目标仍是未来可能支持简单策略的量价状态，而不是直接预测下五日涨跌。

21观察限制的是事件扫描；事先约定的+1/+5响应可超出扫描末日，但不可越过原案例结束日。378扫描观察不包含额外响应观察。

本轮观察结束后记录是否值得进入一个有限机制；没有新增区分力就保留失败，不为了交付而增加版本。账户回测继续暂停。
