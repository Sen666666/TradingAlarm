## 输入与层次

`grade.classify(evidence) -> (frame, events)`只读取B5量价事实及原B4强度，不读取E0持仓资格、保护点、pending或账户结果。可单独复算。`policies_g1.project(evidence, e0_state, grade, kind)`才消费等级并决定参与；执行器最后决定成交。

输入和预热沿B5：8显式输入、来源段、价格/事件/强度三时序，强度第65个有效收盘开始公开。无效观察输出未知且不推进等级；来源段变化重置。未知与0严格不同。

记m5/m21为冻结B4的EW对数收益推进，s为当日之前63收益绝对值中位数×1.4826（下限1e−8）；S21/S63是按√21/√63固定门槛、真实新前沿与成交量信用确认的结构方向，**不是简单过去21/63日涨跌**。

```text
z5  = sqrt(5)  × m5  / s
z21 = sqrt(21) × m21 / s
score = 25 × grade
```

z=1表示把当前平均推进外推h个观察，其位移等于已有s√h结构尺度；不是t检验、置信度或预期收益。

## 提案等级与优先顺序

先按以下互斥分支生成提案：

| 条件（依次判断） | 提案 |
|---|---:|
| S21=S63=0 | 0 |
| m21<0且m5≤0；两结构都下／其他结构 | −3／−2 |
| m21<0且m5>0；S21上／其他 | +1／−1 |
| m21>0；两结构上／仅S21上／S21未上但m5>0／其余 | +3／+2／+1／−1 |
| m21=0；m5正／负／零 | +1／−1／0 |

然后按顺序覆盖：

1. 两结构上且z5≥1、z21≥1：提案+4。
2. 当日acute_up且纯事件event=+1且m5>0：提案至少+2，保留快速启动通道。
3. z5≤−1：提案至多−2；急跌acute_down：至多−3。反向破坏优先于旧上结构。

八档分数与标签为：−75强冷、−50冷、−25弱冷、0未立/中性、25修复、50暖、75热、100扩张。是**有序证据编码**，25分间距不代表等量力度或经济差异。成交量通过原事件、结构方向及冲击改变创建/确认/升温准入；不是只用于画量柱。

## 新证据升温锁

提案高于上一次实际等级时，当日须有以下任意一项新上行事实：

- 原B5纯量价上事件event=+1；
- 任一尺度当日新确认上行；
- S21已经上行，且其运行高点相对前一有效观察严格创新高。实现比较容差为32×eps64×max(|新高|,|旧高|,1)。

无新事实则保留旧等级，公开`proposal`和`promotion_blocked`。首次准备完成公开初始化提案，不伪称一次升温。负推进自然衰减、过去负值离窗、相对尺度变小或acute消失，单独均不能升分。降级可直接跳档。

这项记忆独立于任何交易；同一市场历史给不同策略时分数相同。它也有代价：价格静止后旧热/旧冷可长期保留，不能把“无假升温”称为已经获得完美的中性度量。

## 阶段与输出

`phase`描述分量状态，包括急性下冲、快速启动、急性上冲、扩张、局部修复、下降反弹、下行、上涨结构内整理、上涨延续、上结构建立中、结构未立和分歧。它是升温锁之前的分量解释，可能与更保守的最终等级不同。

`acute_down`单独作为当日freeze标记，可显示`freeze·强冷`。次日标记消失不意味着结构已修复，基础等级仍须按新证据规则恢复。没有固定冷却天数。

逐日输出：`ready/proposal/grade/score/label/display/phase/z5/z21/fresh_up/up_reasons/transition/promotion_blocked/acute_down/acute_up/reason/segment_id`。事件日志保留前级、提案、实际级、新证据和升/降/拒升原因。

## 四政策

| 政策 | 入场 | 退出与恢复 |
|---|---|---|
| E0 | 原兼容政策 | 原支持/记忆/结构规则 |
| G1_I | 影子E0有效，等级≥2，且当日E0新入或新上行事实 | 已参与后只按E0结构退出；新证据可建立延迟入场 |
| G1_X | 原E0新建一段时参与 | 额外等级≤−2或acute_down退出；原E0该段结束前不再进入 |
| G1_IX | 同I | 同X的退出；但新合格暖证据允许结构内恢复 |

增强政策的支持来自影子E0当时支持，持有时只升不降；原E0结束或旧支持被触及仍退出。同日退出不再入。X的额外退出检查在已建立资格时执行，新建当日不虚构成交前往返；具体执行顺序见源码。

I/IX买单只能由当日证据申请（执行器现有buy_event入口），未成交后不能仅凭仍热自动申请。X与E0保留原状态式执行口。X段内等待与IX恢复是显式政策差异，不能把全部收益差异算成退出点本身的价值。

评分、政策先沿全来源历史计算；增强政策继承窗口前自身状态；I/IX首日carry另须前级≥2。E0继承与旧账相同的原状态。窗口前初始化不同的carry公开，各组连续长窗用于同时观察此限制。

各账户初始净值1、全额多头/现金、无杠杆、无每日再平衡。乘100万元仅换金额尺度，不改变仓位。每边手续费5bp＋滑点5bp；成本倍增和额外一开盘延迟按旧协议。预设末日清算单列。范围仍为原固定场景及单资产代理，不称全市场选股或真实可成交组合。
