## 2. 目前设计的实际选择流程

本轮研究使用2026-10-22观察到的存续A/H证券，以该日当前公司总市值严格大于100亿元人民币、港股当前南向资格、当前行业归属固定筛选。保留存续及当前分类选样偏差；不称历史时点全市场，也不重新要求完整历史退市/市值/行业成员链。

```mermaid
flowchart LR
    A[当前快照策略池] --> B[逐日因果板块与个股状态]
    B --> C[双重趋势资格]
    C --> D[行业RS排序]
    D --> E[行业内个股RS排序]
    E --> F[跨行业轮询竞争槽位]
    F --> G[共享现金和初仓预算]
    G --> H[下一可成交时点执行]
    H --> I[持有及个股失效退出]
    I --> F
```

S0主版的既定方案是：

1. 板块和股票均采用冻结E0，个股同时满足当前研究资格、板块趋势有效和自身趋势有效，形成候选。数据未知不当作看空，也不能买入。
2. 板块按各自RS排队，再按板块内个股RS排队；先每板块一只，再第二轮补位。RS是过去四段63观察收益的加权和，公式见[E0/R/R1统一文档](ALGORITHMS_E0_R_R1.md)。排名不是买入概率评分。
3. 候选仍有效但没有槽位/现金时保留等待，后续按当时排名重新竞争。已有持仓不因排名下降而机械换股；未完成部分成交有自己的已冻结目标。
4. 首版最多同时3个行业、每行业2家公司，共6槽；同一A/H发行人不重复占用。它不是固定只研究6只股票。
5. 每个新仓初始预算上限`0.90×决策NAV/6`，通常15%，再受可用现金、费用和90%总投入剩余限制。每次冻结目标股数与预算，不因开盘低开自动扩大数量。
6. 首版不主动加仓、不浮盈减仓、不每日等权。赢家自然变重不强制卖回；初始15%不是持仓期间的绝对权重上限。无候选/不可成交时留现金。
7. 个股E0结构失效产生锁存卖出意图，下一可成交时点执行。板块变弱仅停止新买，首版不据此强卖个股；板块卖出属于未运行的独立对照。

3×2、90%和通常15%只是第一版待检验配置，不是成熟最优值或用户永久参数。R/R1固定为对照版本，尚未默认接入板块与个股的两层组合，也不自动扩大首轮矩阵。

## 3. 什么关键问题还没回答

固定资产回测提前给出了资产身份。全市场策略必须额外验证：

- 大赢家起涨时是否被板块门控挡住、行业或个股排名是否足够靠前。
- 槽位被哪些普通交易占用，真正的大赢家到来时是否还有现金与风险容量。
- 等待补位是否已经太晚；被排除或未成交的大趋势必须保留在漏斗中。
- 选中的多只股票是否集中在相近风险来源；整户回撤不能由单股回撤直接平均推出。
- 停牌、跳空、涨跌停、整手、费用、A/H交收、权息与现金可用性是否改变收益判断。
- 相对同池简单个股趋势、同池被动，优势究竟来自选股、参与时间、资金暴露还是一次幸运持有。

目前还没有新全池S0主账户结果来回答这些问题。旧A485/ETF或九资产共享账户是可复用研究材料，不能代替当前存续A/H两级策略的验证。

## 5. 回到主线应如何推进

下一项应是完成**选择到持仓的完整链路验证**，而不是继续挑单只黄金/半导体扩展退出模型：

1. 先复用已经完成的名册、量价、权息与队列终态，列出真实未完成项；依既有授权和节点停止规则处理有限补缺，不能重复全量下载或无限重试。
2. 对数据池给出明确覆盖/缺失结项，并对港股行业输入给有限可行性裁决。若完整AH范围仍不足，明确报告不能完成原问题；不自行改成仅A股、短区间或完整行业子池。
3. 使用冻结E0完成真实生产信号、排名、候选、预算和执行包，先复查“何时有资格→为何被选中/等待→何时实际成交”的因果路径。
4. 按原定有限矩阵运行：T0个股趋势选择、T1增加板块门控、S0板块优先＋板块内选择，各基础/双成本/额外延迟，加同池B0被动，共10账户。S0主账户，T0主要对照，T1拆机制。不把R/R1命名固定解释为新开三倍组合矩阵。
5. 报告完整净收益/回撤、普通损耗与尾部贡献、现金/行业/公司暴露、未成交及错过的大赢家，进行逐笔主观复盘，再判支持/否定/证据不足。当前80%仅愿景、20%风险研究目标，不能因未达标自动追加策略。

这是对已有主线依赖和首轮设计的整理，不是本次已启动执行的声明。单资产算法对照先收口；没有新增账户、数据请求或实盘操作。
