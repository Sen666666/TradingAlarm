# E0 / R / R1：统一名称、详细逻辑与公式 v1

固定日期：2026-10-24。依据用户本次决定，今后持续使用 **E0、R、R1** 指代下列三个版本，大小写不影响称呼。此次固定名称、定义、参数和源代码身份，不修改算法、不重新回测、不将R1晋升。

统一登记与SHA256：[registry.json](../research_rounds/algorithm-baselines-20261024/registry.json)。既有冻结源码为执行依据；若文字与代码出现不一致，应报告并纠正文档，不静默改代码。今后发生机制/常数/时钟变更，须另起明确版本，不能仍用裸名称覆盖本版。旧研究中其他同名R1不追溯改名，引用时保留其旧轮次路径。

## 1. 三者共同点与差别

| 名称 | 本版固定含义 | 首次资格 | 退出 | 退出后恢复 |
|---|---|---|---|---|
| E0 | 量价事件确认＋结构存续＋高参与下跌跨日收复 | 向上量价事件，或高参与下跌记忆被收复 | 收盘跌至既有结构支持 | 原事件/收复通道重新建态 |
| R | 独立影子E0＋敏感退出＋整段重建后再入 | 影子E0新建态 | 影子E0失效、结构支持失守，或单向2波幅保护线 | 只等待下一次E0新建态；原周期内不重试 |
| R1 | R＋结构内恢复 | 与R相同 | 与R相同 | 原E0仍有效，退出后新低点经向上量价事件确认后可恢复 |

E0是市场结构状态；R/R1包含退出及重入记忆，是围绕E0的参与政策。它们都不是完整的全市场选股、排序和仓位系统。`target=1`表示该版本参与资格有效，不等于账户已经成交或应在每只合格股票上满仓。

## 2. 输入、时间与数值口径

- `O_t,H_t,L_t,C_t,V_t`是按日期有序、单位一致的日线开高低收量。所有市场证据只使用量价及其因果派生量；开盘原价另外用于执行。
- 下标`t`按有效观察计数，不是自然日。缺失、停牌、真实断档与非上市期不补造新观察；数据适配层保留未知和来源分段。核心事件函数只在正且有限的收盘与量上计算，随后对齐原索引；不能把核心函数的对齐填充误称断档已解决。
- 使用已审核的同一价格坐标计算极点、支持、波幅和比较。信号复权坐标与实际成交原价分开，不能把未来权息回填成过去已知；具体资产的数据、量单位和调整方法须沿用相应输入清单，不因名称固定就自动兼容任意数据源。
- 比较函数`cmp(a,b)`：若`|a−b| ≤ γ4 max(a,b)`，视作相等；否则按数值大小。`u=eps64/2`，`γ4=4u/(1−4u)`。这只是浮点误差约定，不是价格止损容差。等价极点保留更早者，等价支持保留原值。
- 对数收益用`log_ratio(a,b)`：比较相等返回0；`0.5≤a/b≤2`时用`log1p((a−b)/b)`，其余用`log(a)−log(b)`。不承诺任意独立舍入缩放下逐位不变。

核心入口：[numeric.py](../research_rounds/pv-participation-response-20261020/code/numeric.py)、[participation.py](../research_rounds/pv-participation-response-20261020/code/participation.py)。

## 3. 原始量价事件公式（三者共享）

定义局部对数收益和此前63观察的RMS：

```text
r_j = log_ratio(C_j, C_(j−1))
σ_t = max(sqrt((Σ[j=t−63..t−1] r_j²) / 63), 1e−8)
B_t = median(V_(t−21), …, V_(t−1))
```

均不含当日收益/成交量。代码从零基索引`t=64`开始具备摆动识别准备；预热前事件为0，不能提前建立趋势。初始摆动方向`d=−1`，初始极点为首个准备完成的观察。

`e`为正在发展的摆动极点：`d=−1`时，遇到严格更低收盘才更新`e`；`d=+1`时遇到严格更高收盘才更新。并列价格保留旧极点。当`t>e`：

```text
A(e,t) = clip(sqrt(mean(V_(e+1), …, V_t) / B_e), 0.5, 2.0)
K_t    = (−d) × log_ratio(C_t, C_e) × A(e,t) / (sqrt(5) × σ_e)
```

`σ_e`与`B_e`取极点时已经可得的基准，不滚动换成今天的基准。若`cmp(max(K_t,0),1)≥0`，确认一个方向为`−d`的事件，确认极点为`(e,C_e)`，记录确认日`t`；然后令`d←−d,e←t`，开始下一摆动。

- 从向下摆动确认向上事件：`event=+1`，被确认的是前面的回调低点。
- 从向上摆动确认向下事件：`event=−1`，被确认的是前面的高点。
- 低点发生日不是当时已知的买点；只能在确认日收盘后使用。
- 量通过`A(e,t)`改变事件是否及何时确认。不是“放量一律买入”，也不要求每次确认日量比大于2。

`event_frame_numeric`内部也输出一组事件/结构字段；**本版E0以随后`participation_frame(mode='volume')`的状态为准**，不能误用前者的内部`target`替代E0。

## 4. E0：结构持有与量收复记忆

状态为`active`、结构支持`F`、至多一项等待记忆`M=(lower,reclaim)`；初始空闲、无记忆。每观察严格依次处理：

1. **先检验旧支持**：若已有效且`cmp(C_t,F)≤0`，退出，当日禁止重新建态。向下事件本身不触发E0退出。
2. **检查旧记忆的价格响应**：若`C_t<lower`，记忆否决；若`C_t>reclaim`，记忆收复；等于两条边界均不算响应。
3. **原向上事件优先**：若`event=+1`且原结构还有效，`F←higher(F,C_e)`；若空闲且当日未退出，则建态，`F←C_e`。原通道不会被等待记忆阻塞。
4. **处理等待记忆**：否决则清除；若原通道已经建态，也清除并记录由原通道消费；否则若出现收复响应，独立建态，`F←lower`，然后清除。收复日不另设放量门槛。
5. **最后才可创建新记忆**：空闲、没有未决记忆、原事件已准备完成，且满足下面条件时，记`lower=L_t,reclaim=C_(t−1)`：

```text
C_t < C_(t−1)
q_t = V_t / median(V_(t−21), …, V_(t−1)) ≥ 2
```

量比和价格比较沿用`cmp`。新记忆当日不收复；已有未决记忆不被后来另一根大量下跌悄悄替换，没有另加时间到期。退出当天可以在最后一步建立等待记忆，但不能同日重入。

由向上事件更新的支持只能提高，不随普通回落降低。没有固定止盈、回吐比例止盈、排名止盈或向下事件直接卖出。量收复分支是额外建态通道，不等于它已被证明能抵消全部普通损耗。

## 5. R：敏感退出与完整结构重建

始终独立计算完整E0影子状态`b_t`及支持`F^E0_t`，R空仓不停止影子更新。E0新建态包含原向上事件和量收复两条来源。

相对真实波幅与滞后均值：

```text
TR_j = max((H_j−L_j)/C_(j−1),
           abs(H_j/C_(j−1)−1),
           abs(L_j/C_(j−1)−1))
a_t  = mean(TR_(t−14), …, TR_(t−1))
```

这是14观察的**滞后相对真实波幅算术均值**，不是Wilder平滑ATR，也不是绝对价格ATR。开仓资格日收盘初始化：

```text
F ← 当日E0支持
P ← log(C_t)
S ← P − 2a_t
```

以后有效期间先继承当日已提高的E0支持，随后：

```text
P_t = max(P_(t−1), log(C_t))
S_t = max(S_(t−1), P_t − 2a_t)
```

`S`为对数保护线，只能提高。退出优先级：

1. 若影子E0无效，或`cmp(C_t,F)≤0`，结构退出。
2. 否则若`log(C_t)≤S_t`，波幅退出。这里沿用源码直接浮点比较，不额外套价格容差。

R的空闲资格仅在当天影子E0的`entered=1`且当天R未退出时新建。波幅退出后，就算E0仍有效、又确认了更高低点，R也不在同一E0周期内恢复；须等E0失效再新建。此规则既减少试错，也可能错过长趋势。

参考实现：[legacy.context](../research_rounds/strategy-switching-20261024/legacy.py)和[model.combined(policy='R')](../research_rounds/strategy-switching-20261024/model.py)。不要用E2自主重试替代R，不要把锁定事后E0真实买点的M诊断当作R的实时资格。

## 6. R1：结构内恢复

完整标识保留`R1-IR-20261024`。首次资格、结构支持、峰值、2波幅保护线及退出优先级均与R相同，仅增加：

1. 波幅退出且影子E0仍有效时，记录退出**信号日**`t_x`和当日已更新影子支持`F_x`。结构退出不建立恢复记忆。
2. 以后空闲、当天未退出、影子E0仍有效，且当天不是E0新建态时，若新事件满足：

```text
event_t = +1
t_x < t_pivot < t
cmp(C_pivot, F_x) > 0
```

则产生恢复资格。退出信号当天形成的低点也不合格；实际卖出延迟不改变`t_x`。不能回填在低点日开仓。

3. 恢复时用当日E0支持作本次支持，以当日收盘重置`P,S`，下一可成交开盘排队；资格记忆立即消费，不等实际成交后再消费。
4. 再次波幅退出，记录新的退出日和支持。影子E0失效立即清空。E0新周期的原通道优先、不受旧记忆阻挡，同日退出禁止恢复。

在连续E0有效的真实数据中，“低点高于退出支持”大多已由结构存续保证；它不是已经验证的独立机会质量分数。严格新低点会漏V形恢复，原2波幅出口仍可能切碎持续趋势。二者是固定规则的已知代价，不在本次记录后放松。

参考实现：[r1_state](../research_rounds/r1-structural-reentry-20261024/model.py)。

## 7. 初始化、信号与成交必须分开

本次固定场景参考实现按每个窗口前一观察的E0承接：若E0有效，则E0/R/R1都初始化为有效；R/R1的峰值取前收盘对数，保护线取该峰值减`2a_(前日)`，R1恢复记忆为空。这是已测的窗口初始化，不代表保存了窗口外R/R1的全部交易历史。持续运行须保留状态；若采用不同初始化或预热承接方法，必须明确记录版本和与本回测的差异。

固定场景的统一研究执行器：[engine.py](../research_rounds/r1-structural-reentry-20261024/engine.py)。

- 普通信号收盘可知，基础为下一观察开盘，延迟情景为第二个后续观察开盘。起始承接订单在窗口首开盘处理；末日预设收盘清算单列行政退出，不当作算法卖顶。
- 一条待执行订单：卖单锁存；买单因资格失效或开盘原价不高于已知支持取消。资格仍有效、账户空闲且没有待单时，执行器仍可再次排队；这不凭空创造新的量价事件。
- 峰值和退出资格从信号状态计算，不从实际入场成本、浮盈或已赚多少钱定义。实际延迟、取消和挂单占用可能使成交路径与理论事件路径不同。
- 最新18窗的股票/ETF代理账户初始资金1、全额多头或现金、分数份额、不每日再平衡；每边费率`f=0.0005`、不利滑点`s=0.0005`。成本加倍分别变成0.001。旧AU0专项有不同执行单位，不能自动套用这里的股票/ETF成本。

```text
买价 = 原开盘 × (1+s)
买数量 = 可用现金 / [买价 × (1+f)]
卖价 = 原开盘 × (1−s)
卖后现金 = 数量 × 卖价 × (1−f)
NAV_t = 现金_t + 数量_t × 原收盘_t
收益 = NAV_末 / NAV_初 − 1
最大回撤 = max_t(1 − NAV_t / max(NAV_初, NAV_0,…,NAV_t))
```

费用与滑点均已进入收益，不在尾部/普通贡献中再扣一次。单笔净收益≥30%只是尾部归因线，不是止盈线。自然胜率排除行政清算，未闭合权益另列。

这些全额单资产代理执行参数**不固定为全市场仓位管理规则**。完整股票策略另需共享现金、槽位、整手、税费、交收、停牌和涨跌停等执行约束。

## 8. 与选股和仓位的连接

三个名称只固定趋势/参与政策，不包含候选池和排序。全市场策略版本另命名，例如`S0 + E0`，不能只报“E0收益”而省略选股、资金与执行口径。R/R1尚未完成全市场组合接入验证，不默认将其替换进板块和个股层。

现有独立RS排序公式固定记录为：

```text
RS_t = 0.4(C_t/C_(t−63)−1)
     + 0.2(C_(t−63)/C_(t−126)−1)
     + 0.2(C_(t−126)/C_(t−189)−1)
     + 0.2(C_(t−189)/C_(t−252)−1)
```

至少253个有效价格观察；排序比较键四舍六入五成双至12位小数，同分按明确稳定ID处理。全池适配器和旧小池归一排名输出须区分；该RS是价格相对排序，不是E0/R/R1的趋势有效条件，也不是量价事件公式。某批缺RS的全批ID降级政策见全市场方案，不能静默把缺失者排最后或删掉新股。
