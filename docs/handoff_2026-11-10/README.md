## 3 目标与用户交易哲学

长期共识来源：主工程 `docs/RESEARCH_CONSENSUS.md`，最新全流程要求在 `docs/RESEARCH_REVIEW_CHECKLIST.md`。当前具体机制以11/09合同为准，旧阶段“永久冻结”或“自动下一步”不能覆盖新决定。

- 以价格、成交量及因果派生量研究趋势、强度与转变；允许跳变，不把平滑、高胜率或每次方向正确当目标。
- 行业趋势先发现机会，再研究行业内股票趋势与开仓、持有、退出、仓位。不能把少数ETF/科技股永久当全市场。
- 通过稀疏大赢家获得主要利润。普通交易成本后基本相抵是理想方向，少量普通净亏可接受，必须完整展示累计代价。
- 正常趋势回吐是持有代价；不以锁住峰值、浮盈兑现率或紧缩退出作为默认优化目标。初始试错损耗与成熟持仓回吐分开评价。
- 30%是尾部分类界线，不是止盈线；整户80%仅大行情愿景，不是每轮通过门槛；20%回撤是研究目标，不是保证硬上限或自动强平定义。
- 当前主线强调广泛小种子观察、买后证据与实际费后盈利支持扩张，不预设只选两只，不默认PVR排序正确，也不能用共享试错风险池堵住全部信号。取消风险名额不等于无限现金。
- 量必须有可追溯的机制作用并接受去量对照；目前个股M3里的量只负责有效性，不能因此称已验证量价优势。
- 市场状态、横向排名、持仓、买入成本、CP确认与真实ADD要分开；信息确认不能依赖先拿到资金，CP仅真实ADD时消费。
- 保留费用、法定手数、T+1、真实可用现金、权益、UNKNOWN与前缀因果检查。所有已看历史继续是开发材料，换版本/切分不恢复样本外身份。
- 不自动实盘；交易台的券商委托仍由用户执行。
