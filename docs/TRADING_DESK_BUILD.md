# TradingAlarm 科技股交易工作台

2026-10-27，DESK-ACT20-1 已实现并完成本机验收。用户要求暂存研究、推进产品，并选择从空仓录入实际可用资金。ACT20_BREAK 规则、407科技股/11行业池及原RS-H1参照保持冻结；本次新研究资金回测0。

## 日常使用

打开 http://127.0.0.1:8765 ，首次填写真实可用资金。平台不预填100万元，也不继承回测仓位或暂停状态。2026-10-27用户指定真实账户从INACTIVE开始；新建真实账户也默认先等待市场恢复条件，满足后才启用。

服务运行时每日15:30增量获取本人同花顺日线及权益，计算收盘指引。先看账户参与状态，再看开仓/持有/卖出。开仓可以输入下一开盘原价测算股数；开盘原价不高于保护位则放弃。买单当日有效，部分成交不自动次日补仓；未完成的退出继续锁定。

在券商完成实际委托后，录入真实成交时间、股数、价格和费用。建议不会自动记为成交。现金、FIFO含费持仓成本、已实现损益和下一收盘账户阶段峰均以实际记录重建；已实现损益包含到账权益现金。参考资产使用当前实际持仓乘最近收盘价，和收盘风险净值分开展示。

成交和权益录错可修正；原始记录保留。分红、送转等持仓权益须按券商记录确认，未到账现金可记为待收，到账后转为实际现金。待收现金计入净值，不重复算收益；新增股数受录入的可卖日期约束。存在未核对权益时暂缓生成新指引。

## 文件与运行

正式本地入口 http://127.0.0.1:8765 。双击 `TradingAlarm/start.command`；或仓库根目录运行 `TradingAlarm/research/.venv/bin/python TradingAlarm/server.py`。需要已有pandas/numpy/pyarrow环境。

正式账本：`TradingAlarm/runtime/account.sqlite3`。行情发布、增量响应、失败回执均在同目录下。runtime不进入Git；备份SQLite应包含WAL，或在服务停止后备份整个runtime目录。旧研究只读、不覆盖。

代码入口：`TradingAlarm/desk/service.py`、`strategy.py`、`store.py`、`data.py`、`refresh.py`、`execution.py`。原选股准入代码原样保留在 `admission.py`。版本身份及依赖哈希在 `desk/contract.json`；身份登记本身不代替验收。

## 已知运行边界

服务需要保持运行，电脑睡眠/关机时不能更新；重开后会检查当日定时状态，失败可手动续接。同花顺会话过期或被拒绝须在本人官方客户端正常登录；本机程序不会独立续签。数据缺失、源冲突或权益无法识别时保留旧资料，并明确显示未完成。

交易池和市值/行业仍为研究冻结快照；没有擅自增加新股或改变选股口径。交易日历按[上交所2026公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)与深交所通知核验，覆盖至2026-12-31；未知下一交易日不生成新开仓指引，后续年度需维护。

股数测算沿原数量规则与参考费用、5bps滑点，实际费用以券商回报为准。平台提供交易辅助与本地记录，券商委托由用户执行，未接入自动下单。软件验收不改变已记录的策略历史开发边界或未来盈利的不确定性。
