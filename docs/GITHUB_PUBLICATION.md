## 更新方式

本目录是独立Git工作副本，`origin`为本次指定远端。后续源码/文档更新在该副本中审查、提交和推送。原本机私有工作区的main不应直接推送到GitHub。

来源工程先用 `scripts/prepare_github_export.py`生成脱敏候选，再用 `scripts/prepare_lean_github.py`筛选精简版本；两者都要求全新目标目录。它不会推送，不覆盖原资料；发布前仍须核查差异、凭据和大文件，不要用普通全目录复制覆盖当前发布副本。
