# 固定位置量价响应：观察结果与路线纠偏

**本轮保留“同一位置的有序响应”作为观察工具，否决把固定窗口外边界直接当作主导趋势。** OHLC确实补充了此前只看收盘遗漏的信息；成交量能约束解释，但尚未证明改善方向区分。下一步最需要解决的是参照位置为什么有效、何时失效与替换，不能直接再叠一个强度分数。账户回测继续暂停。

完整证据在[结果目录](../research_rounds/pv-boundary-response-20261020/README.md)，原研究结果没有覆盖。本轮实现的是观察器，没有发布新的趋势分类器或交易策略。

## 1 研究怎样限制事后解释

沿用15个固定案例的原观察日期，另设两个通信代理的2026-08-03及黄金ETF的2026-04-01窗口。这三个是针对已知反例的定向诊断，所有历史均为开发材料。

每个窗口开始前，以此前21个有效OHLC观察的最高、最低生成固定边界；事件扫描固定为随后21个有效日，不移动边界、不扩大扫描窗口。成交量以同一前置窗口的正量中位数为参照。18例全部可用，共378个扫描价格观察、756条双边界事实。13例发生接触，5例没有；另有4次符合事先定义的再次触及，共22个审阅时点和83张分层图。

预定的后续1、5观察响应允许超过扫描末日，但不能越过原案例结束日；不足则记截尾。S2、C1、W1第二次、W2第二次这4个时点的第五观察晚于扫描末日，符合冻结协议。378只计扫描观察，不含这些追加响应观察。

“接触”包括跳空至边界外侧，不表示确有交易在该价位成交。再次触及要求中间至少一个完整观察没有触及同侧，持续在外侧不重复计算；另一边界的每日事实全部保留，不因人工只选先触一侧而删除。

人工判断按收盘P、增加OHLC的H、增加量的V逐步锁定，首次接触完成后才看再次接触，最后揭示随后1、5个有效观察的响应。看图前修复了原计划中“晚事件P会泄露早事件H/V未来”的顺序问题，原协议和[修正记录](../research_rounds/pv-boundary-response-20261020/review-order-addendum.json)都保留。

P是**共同OHLC边界条件下的收盘响应视图**，事件日期本身也由OHLC决定，并非严格独立的纯收盘算法。分层审阅只能减少当前解释混用，不能抹去对历史的记忆，也不构成量能预测优势的统计检验。

## 2 数据与机械验证

重建14条与旧收盘/成交量逐日对齐的OHLCV。ETF及港股由已有原始四价和既定权益公式统一调整；A股使用已有同花顺信号四价和真实成交量；两条通信指数保留原始指数口径。没有拿语义未知的同花顺Q数据与旧总回报收盘拼接。四价调整属于信号研究口径，不是实盘报价或会计权益。

价格观察与量缺失独立；18条港股供应商前值占位行经交叉核对后排除，依据是零量、四价等于前收及另一来源缺该日，并非独立交易日历认证。零振幅真实bar保留但收盘位置未知。详见[数据说明](../research_rounds/pv-boundary-response-20261020/data-review.md)。

27次数据调整前缀检查通过。观察器另有9组独立验证，包括378次真实前缀比较、18次成交量重排，以及同样价量观测集合而顺序不同、同起点/极值/末值而事件不同、双边同时触及、零振幅、截尾和缺量测试。[验证报告](../research_rounds/pv-boundary-response-20261020/validation.json)只证明观测规则及因果实现成立，不证明趋势或交易有效。

## 3 主观图检与机制结论

本节在全部分层判断锁定后汇总。逐层原文保存在结果目录的`reviews/`，不以汇总重写早期判断。

| 例子 | 当时已经可见的证据 | 揭示后续后的评价 |
|---|---|---|
| 半导体ETF2024-09-30 | 整日位于旧上界上方，收盘在日内高处，量比约2.80 | 随后5观察均收在上界外。无需等完整回试才承认强推进；但快速响应主要已由价格识别，不能归功于成交量 |
| 黄金ETF2025-09-01 | 整根bar在上界外，量比约3.66 | 随后5观察均收在外侧。量揭示了参与规模变化，尚不是持久性或主趋势成立的充分条件 |
| 半导体ETF2026-07-01与07-10 | 两次上探均未保留外侧收盘；第二次量比由约1.23升至1.61，收盘位置由当日振幅的20.2%降至2.1% | 第二次之后继续下降。应记录“更多参与未换来更好结果”，但OHLC已给出受阻事实，不能称量独立识别了下跌 |
| 美团2022-07-12与07-29 | 修复后再次下探；第二次阴线更大、相对量约1.16，仍略收在下界内 | 两次之后5观察收盘均未留在下界外，均有反弹。否决“再次试探＋参与回升＝必然破位”；受损预警不等于持续下行确认 |
| 重庆燃气2024-07-09 | 下探收回，量比约1.66；审者在看未来前小幅提高局部恢复解释的信心 | 次日重新收在下界外，反证必须保留。07-16较低量、较浅再探后才逐步修复，也不能倒过来拟合“低量才好” |
| 恒生科技ETF2023两次上探 | 首次收回界内，再次收在界外；第二次量比约1.19，并非极端巨量 | 两次后续表现不同，关键可见区别主要来自价格是否保留在界外。要求每次量峰更高可能反而排除新推进 |

精确值来自[事件证据表](../research_rounds/pv-boundary-response-20261020/event-evidence-summary.csv)。其中收盘位置是`(C-L)/(H-L)`，量比使用各自冻结背景；都不是胜率、收益率或跨品种可直接比较的评分。后续5观察只用于核对当时解释，不能冒充对长趋势的验证。

**最重要的反例是无触及，而不只是失败突破。** 两个通信代理8月、黄金2026年4月、黄金2024年6月和恒生科技2022年4月，共5例没有触及固定外边界，内部却存在显著的推进、回落或修复。通信设备8月恢复较强；全指通信中旬推进再次丢失，后段较弱。二者都未触边，单靠边界事件会把不同状态压成同一个“未发生事件”。

这说明外边界可作为上下文，却不能单独决定主导趋势；不代表必须立即缩短窗口。通信本轮窗口截至8月底，**没有检验9月后续侵蚀**；黄金窗口也只覆盖4月。没有为了补齐结论而延长窗口。三例定向探针全部未触界，本轮对它们的“边界量价检验”覆盖失败，内部量价图只能给出另外的描述性观察。

分层判断给出的诚实结论是：**OHLC的信息增量比当前量表示更明确；量的有效作用仍待证明。** 相同放量可能伴随推进，也可能伴随推进被撤销；缩量可出现在修复、横摆和持续侵蚀中。这次人工审阅没有一例因为揭示量就形成有依据的主导方向翻转。C5的小幅信心提升随后还遭遇反例，不能把叙述更丰富当作算法已改善。

另一对重要反例是中电控股S2与半导体B1首触：两者都曾触上沿后收回界内、收在日内较低位置，之后一个立即越界保持，一个明显下移。单日OHLC受阻也不是终局标签；首触量没有给审者足够依据可靠区分，必须接受随后证据推翻当初倾向。

## 4 保留什么，停止什么

保留真实四价、因果事件账本、同一位置跨日响应，以及看未来前写下竞争解释和反证条件。合成路径证明相同观测集合、相同起终点或极值可以留下不同事件顺序，因而此账本并非净位移重新加权；这只是表示能力，不是有效性证明。

停止把固定21观察外边界作为唯一状态开关；停止把“再试一次”“放量”“缩量”直接映射成确认。没有另调窗口、量倍数或截图日期，也没有追加v1。对价格已经解释的差异，不把功劳记给量。

从交易判断角度，当前能更清楚地说“这一段推进已经受损”“这一轮修复又被取消”，但仍不能保证下一次接触后会反弹还是突破。方向不确定时应允许暂时撤销强势判断，同时不强行宣布相反的主导趋势。这一语义值得保留，尚未实现为通过验证的完整状态机。

## 5 下一轮 agent 的唯一优先任务

**先做参照位置机制的等价性审查，再决定是否实现。** 任务不是再换一组快慢阈值，而是回答：哪一次实际推进留下了需要维护的位置；它在从另一侧回访后是否仍有作用；旧位置何时失去解释资格，何时由新位置接替。

候选只允许一个：研究“同一位置由阻力转为承接、或由承接转为阻力”的有序过程。首次强推进可以立即输出正在推进，不强制等回试才承认启动；结构得到回访检验是另一项证据。穿回已知位置时可以先撤销旧强势解释，不能继续用更早的低点无限辩护，也不要求当日就确认相反趋势。该方向来自量价位置与后续响应的思想，是我们的设计推演，不是已验证的大师公式。

依次交付以下内容，尚未通过前不启动完整新模型：

1. **与旧机制逐项排重。** 对照已有确认高低点、保护点更新、两尺度迟滞和父包络，写出参照建立、被挑战、恢复、替换的转移依据。特别警惕“回访后再破高”只是旧HH/HL确认的改名。
2. **先给出可区分的合成对照。** 不能仅证明新字段不同：在旧模型状态相同的前缀中，说明新观察为什么允许不同解释；相同价格换量时，量改变哪项可检验的证据、何时应保持未知。若找不到实质差别，否决候选，不继续实现。
3. **通过后再冻结一个有限原型。** 复用全部18例完整既有案例区间，预先写清评价截至日期；重点同时面对通信内部修复、美团缓退、半导体快启动、黄金/银行整理，不能只补挑支持案例。此次新评估与当前21观察诊断分目录，不改本轮证据。
4. **验收重点是参照是否解释实际结构。** 新参照不能每个小摆动就替换，也不能陈旧到只能等很早的低点；无回访急涨保留快速推进资格。量若仍只改变措辞，不得称为完成量价趋势机制。没有跨案例共同改善则停在失败记录，不再自动接下一家族。

[独立设计审查](../research_rounds/pv-boundary-response-20261020/reviews/design-next-step.md)是候选构想，未获实证支持。账户、收益、选股排名和策略阈值优化均不在下一轮准入范围内。后续工作不需要重复数据准备或重跑旧账户。
