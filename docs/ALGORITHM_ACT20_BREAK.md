## 1. 两层职责与范围

个股与行业选择沿原I-NR1/S0；新增账户层只有ACTIVE（允许参与）与PAUSED（暂停）两种状态。ACT20_BREAK不是新的个股趋势公式，也不是视频均线策略/DAP量价新算法。个股E0-NR1原成交股数口径、G1强度与RS-H1不变；恢复市场广度使用真实成交金额。

已测407科技股、11行业，2024初—2026-10-26，初始100万元有限资金复利；当前存续、行业、市值快照的开发口径，非历史时点完整全池或样本外。各压力情景是独立替代账户。

## 2. ACTIVE时开仓

沿原I-NR1：影子E0-NR1结构有效，G1至少暖（内部等级>=2，对外50分），并有当日原I新入/新上行事实买入事件。仅仍暖/仍热不够。所属行业原E0趋势有效，数据/交易资格有效，并通过原RS-H1排名与资源约束。没有额外要求市场先突破63观察高点；该条件只管暂停后的恢复。

同日多股：行业按RS-H1降序，行业内股票按RS-H1降序，轮流每行业优先一个、再第二个；同分按原确定性顺序。已有持仓/待执行订单占用名额。最多6股票、3行业、每行业2股；有空位才接纳，不因排名改变主动换仓。

按实际账户当前NAV计算原首次预算：每股不超过15%NAV、原90%新增投入约束及真实现金/费用/整手限制。不是每股永久固定金额，不是每天等权再平衡；盈利后权重可以超过初仓15%，不自动加仓或减回目标权重。

收盘产生决策，下一可执行开盘尝试。原普通买单当日有效，未成交到期后重新参与原候选竞争；没有采用L2两日意图。原开盘已触及/低于保护位则拒绝买入。基础按实际执行日未复权开盘价±5bps滑点、费用另记，受T+1、涨跌停、停牌、数量/容量约束；日线代理不证明实盘成交。延迟压力额外跳过一次可执行事件，可改变到期与后续持仓。

## 3. 两种退出

个股正常退出：按E0-NR1结构支持维护，收盘触及或跌破支持等原结构失效条件时发出退出，下一可执行开盘卖出。G1由热转暖/冷本身不强制卖出。没有固定3R/5R止盈，没有上涨30%就卖；独立收复入场通道已关闭。

账户暂停退出：每收盘用实际NAV（现金、持仓及原账本权益/负债）计算：

    P_t = max(本次参与阶段之前的峰值, NAV_t)
    DD_t = 1 - NAV_t / P_t
    若 DD_t >= 0.20：进入PAUSED

初始P=100万元且ACTIVE。触发后取消/禁止新买，所有存量提出退出，按下一可执行开盘执行；原退出锁存，不因隔日反弹撤回。不是只卖亏损股票、不是一半减仓，也不是市场m21弱时改用10%（那属于B/C）。当天不能同时暂停又恢复。

## 4. PAUSED时恢复

必须已全部清仓，且无待买/待卖订单；当日同时满足：

1. 独立科技市场价格描述序列P_market(t)严格高于此前63个交易观察的最高值（窗口不含今日）。
2. 今日该序列收益严格为正，防止仅因旧高点滚出窗口就恢复。
3. 成交金额正方向广度严格大于60%，且满足每行业至少5只有效准备股票、至少8有效行业。

市场价格序列：各行业内当日有效股票log收益取均值，再行业等权取均值；累计exp收益形成价格描述序列。不是上证/创业板指数，也不是账户自身净值或可交易指数。价格本身使用冻结的描述序列；金额广度有效性在第3项约束。

金额广度逐股：r_t=ln(C_t/C_(t-1))；q_t=当日成交金额/此前21有效观察成交金额中位数；u_t=r_t*min(1,sqrt(q_t))；m_t=EMA21(u_t)。按来源段计算，前64观察不准备。每行业统计m_t>0股票比例，再对有效行业等权平均。并非“60%成交金额是买盘”，也不是净流入；成交金额只是有方向价格推进的权重。

恢复日收盘切回ACTIVE，并将本次阶段峰重置为当前实际NAV。随后仍须原I当日有效买点和原资源条件，才能安排次开盘买入。恢复不等于立即买满，也不自动买回曾持有的股票；恢复日可接纳当日有效买点。没有按空仓天数自动恢复。

## 5. 20%不是全历史回撤上限

例如阶段最高净值500万，收盘400万触发20%暂停，实际卖出仍在后续可成交时点；跳空可使亏损超过20%。如果最后清仓390万，后来恢复以390万作为新阶段起点，下一阶段再亏20%至312万，则相对旧500万已回撤37.6%。当前规则显式允许阶段峰重置，不能把“每阶段20%阈值”宣传成全程最多亏20%。
