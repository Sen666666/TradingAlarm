## 1. B4究竟输出什么

B4是一个不读取账户、持仓、入场价或盈亏的量价描述器。它提供三个并列分量，没有把它们压成一条 hot/cold 温度总分，也没有内置买卖规则。

| 分量 | 回答的问题 | 固定输出 | 不代表什么 |
|---|---|---|---|
| 平滑净推进 | 近期净向哪个方向推进、每观察推进多快 | μ5、μ21；各自符号与绝对值 | 不是上涨概率，也不是当前瞬时方向 |
| 事件结构 | 两种价格分辨率上，最近确认的方向是什么 | S21、S63；候选与确认收据 | 不是推进速度；旧上结构可以与负推进并存 |
| 当日冲击 | 今天是否出现相对典型日变动足够大的量价冲击 | acute_up、acute_down | 不是持续的 freeze 状态；标记消失不等于收复 |

交易策略另行决定：用哪些分量、何时入场、何时退出、是否重入、仓位多大。指标变化不自动等于订单。**本版不承诺仅以几个阈值就能复现 E0，也不是 E0 的严格增量超集。** 具体判断见[E0兼容核验](../research_rounds/b4-baseline-contract-20261025/E0_COMPATIBILITY.md)。

## 2. 输入、时钟与初始化

正式入口为 `strength_frame(f, joint=True) -> (frame, journal)`。`run_valid`仅是已验证单来源段的内部计算入口。

必需输入为 `close`、`volume`、`segment_id`、`valid_strength_observation`。核心不使用开盘、最高、最低；报告表附带OHLC或E0列不改变这一接口事实。

- 索引须为无时区、严格有序、唯一且无 NaT 的 DatetimeIndex。冻结核心检验的是完整时间戳唯一；日线适配层还须保证一天一行，不能把盘中多行当成多天，日志日期仅保存年月日。
- segment 必须明确、非缺失，字符串不得为空白；段编号不可离开后再次出现，如 A→B→A 会拒绝。
- valid 必须为无空值的布尔列。有效行的收盘与成交量必须正且有限；无效行可以保留原始缺口，但指标全部未知。
- 每个来源段只用有效行推进时钟；缺失日不补平价、不补零量。后一个有效收盘与前一个有效收盘直接形成收益，可能跨越多个日历日，因此单位严格为“每有效观察”。
- 新段重新预热、重建全部状态。存在已初始化旧终态时记录 `source_discontinuity`；不把旧结构跨段搬运。行情如何复权、主连如何拼接、量单位是否一致属于上游数据合同，B4不自动修复。
- 每段从零计数：第1个有效收盘为 t=0；第2个收盘产生 r1。t<64 的公开输出全部未知；第65个有效收盘 t=64 起公开。
- EW从 r1 开始递推。结构在 **t=64 才初始化**，初始锚点取 t=63；初始候选的 `anchor_observation=63`、`created_observation=64`。不是在 t=63 已经发出候选或信号。

## 3. 原单位净推进：方向与大小分开

每段令：

```text
p_t = log(C_t / C_0)
r_t = p_t − p_(t−1)
α_h = 2 / (h+1),                    h ∈ {5,21}
μ_h,1 = r_1
μ_h,t = α_h r_t + (1−α_h) μ_h,t−1
D_h,t = sign(μ_h,t)
M_h,t = 10000 × abs(μ_h,t)
```

计算 `C_t/C_0` 遇极端上溢/下溢时，仅对异常项用 `log(C_t)−log(C_0)`。μ与r原值为每有效观察的对数收益，`*_bp` 为10000倍，即对数基点；例如10 log bp是0.001对数收益，不是10%或10分。方向取原浮点符号，没有经济意义的“近零死区”。

5与21是指数平滑跨度，不是截断后的5/21个观察窗口。旧收益影响指数衰减，不会在某天整项离窗。这里不除以滚动波动率，所以不会仅因分母降低就把相同推进读成更高强度。

μ下降、μ由负接近零、μ由负转正是三个不同事实。负值变得没那么负只表示净下行减速，不能直接叫上行增强；连续平价时μ渐近于零，不保证有限天后恰好等于零。急跌后μ21仍可能为正，需同时读取当日收益、μ5与冲击，不能把慢分量当全部事实。

## 4. 滞后参考尺度

只用今天之前的有效观察：

```text
s_t = max(1.4826 × median(abs(r_(t−63)), …, abs(r_(t−1))), 1e−8)
v_t = median(V_(t−21), …, V_(t−1))
```

s是典型绝对单观察变动尺度，不是围绕均值的噪声标准差，也不是显著性检验；持续漂移也会改变s。1.4826是固定缩放常数，1e−8是数值下限，不是已验证的最小经济涨幅。v是滞后量基准。

结构分辨率 h∈{21,63}，新候选门槛为 `δ = sqrt(h) × s_create`。h用于位移分辨率，不是必须等待21/63天，不是未来预测期限。不同尺度重锚时点可能不同，实际门槛不保证实时嵌套。

## 5. 量价结构状态机

### 5.1 每个尺度的持久状态

每个h独立维护 `S_h ∈ {−1,0,+1}`，初始0，表示未确认。另维护当前结构方向的运行极值，以及一个或两个反向候选。

每个候选记录：方向d、锚点a与原始锚价、锚对数价p_a、创建日、冻结尺度s_create、冻结量基准v_create、冻结门槛δ、已接受的最大非负位移前沿F，以及累计新前沿证据Q。创建时 `F=Q=0`。本文“原价/原始锚价”均指输入收盘价格坐标中的非对数值，不保证是未复权的实际可成交价。

- S=0：保留从运行低点出发的向上候选与从运行高点出发的向下候选。
- S=+1：只保留向下候选；运行最高收盘是其锚。
- S=−1：只保留向上候选；运行最低收盘是其锚。

初始两候选锚定 t=63，门槛使用 t=64 可知的 s64/v64；此后重锚的锚日、创建日均为当前t，使用s_t/v_t。同一候选存续期间δ/v不更新。

### 5.2 当天先更新真实极值

已上行或未确认时，严格新高将向下候选重建在当日收盘；已下行或未确认时，严格新低将向上候选重建在当日收盘。重建时旧F/Q清零并保存旧候选快照。

并列价格不重置。没有新极值时，不因候选年龄、滚动尺度降低或旧冲击离窗而重置。此限制只针对候选；显示的μ、s和当日冲击仍按各自定义变化。

### 5.3 只为首次到达的新价格前沿累计量证据

对每个存续候选，计算：

```text
x_t = d × (p_t − p_a)
w_t = clip(sqrt(V_t / v_create), 0.5, 2)
eligible = (x_t 严格超过旧F) 且 (d × r_t > 0)

若 eligible:
    ΔF = x_t − F
    Q ← Q + w_t × ΔF
    F ← x_t
否则:
    F、Q不变
```

同一区间来回成交不重复记分，高量回到已经到过的价格也不补旧证据。证据只记录首次新价推进这一特定假说，不代表成交量的全部作用。

### 5.4 确认与反向候选重建

当天只有同时满足以下三项，才确认方向d：

```text
eligible 为真
x_t ≥ δ
Q ≥ δ
```

确认后 `S_h←d`；保存被消费候选的完整 `structure_confirmed` 收据；旧候选集丢弃，从当日收盘建立唯一的−d候选，用当天滞后s/v冻结新门槛；运行极值也从当天收盘重新开始。每个尺度、每观察最多一次确认。

高量不能豁免真实位移δ。普通量约δ可确认；持续最低权重0.5时约2δ可确认，且始终有 `0.5F ≤ Q ≤ 2F`。对相同锚点、门槛的候选比较，若新前沿每次权重都≥1，量版和去量版都会在真实价格达到δ时确认；完整历史中的两版可能已经在不同日重锚，不能忽略此差异。不能把本机制说成“放量普遍比纯价更早”。

确认没有到期失效规则。上结构可在横盘中一直保留，也可在已阴跌时暂未翻下；这正是必须把S与μ并列读取的原因。B4没有E0那条“已确认低点保护线只提高”的状态。

## 6. 当日急性量价事件与联合描述

```text
q_t = r_t / s_t
activity_t = V_t / v_t
qeff_t = q_t × sqrt(clip(activity_t, 1, 4))
acute_down = (qeff_t ≤ −2)
acute_up   = (qeff_t ≥ +2)
```

低量不折减真实冲击，高量最多把相对冲击放大2倍。这两个标记只有当日含义，独立于结构确认；不自动改变S，不建立跨日冷冻期，也不含“冲击已修复”的判定。次日不再acute_down，只能说次日没有再次达到该冲击阈值。

联合标签是以下固定映射：

| S21 | S63 | phase | 语义 |
|---:|---:|---|---|
| +1 | +1 | aligned_up | 两尺度最近均确认向上 |
| −1 | −1 | aligned_down | 两尺度最近均确认向下 |
| +1 | −1 | rebound | 较小尺度上、较大尺度下 |
| −1 | +1 | pullback | 较小尺度下、较大尺度上 |
| 一个0 | 一个非0 | building | 仅一个尺度已确认，building_direction取非0方向 |
| 0 | 0 | unconfirmed | 均未确认 |
| 未知 | 未知 | unknown | 无效行或预热不足 |

rebound不保证后来失败，pullback不保证只是健康整理，aligned_up不等于hot或适合买入。标签是结构组合的简称，不能替代原始数值。

## 7. 计算顺序、数值边界与输出合同

每个有效观察严格按下列顺序处理：

```text
1. 从第二个有效收盘起更新两条EW；不足65收盘则仅输出未知。
2. 计算滞后s/v、当日r/μ/冲击；如有冲击先写事件日志。
3. 对h=21，再h=63：
   a. 必要时初始化；
   b. 按旧结构方向检测新极值，重建相反候选；
   c. 更新存续候选的新前沿与量证据；
   d. 判定确认，保存原候选收据，并重建反向候选；
   e. 写入日末S、当前候选和运行极值。
4. 组合phase；保存该有效观察的日末行。
```

比较容差为 `τ(a,b)=32×eps64×max(1,abs(a),abs(b))`。`≥/≤`包含容差带；新高、新低、新前沿的严格比较须超过容差。`d*r_t>0`是原浮点严格正值；μ方向也没有套经济死区。不要混用E0的γ4原价容差。

核心frame按原索引返回下列字段族（完整列清单另存于本轮 `output-contract.json`）：

| 字段族 | 内容与读法 |
|---|---|
| r/r_bp、mu5/mu21及_bp/_direction/_magnitude_bp | 当日收益与平滑方向/大小 |
| s、volume_reference、activity、q、qeff、acute_up/down | 滞后尺度与今日冲击 |
| S21/S63、local/background、building_direction、phase | 结构方向及组合；local/background是S21/S63别名 |
| delta_h | **如果今天新建候选**的门槛；不是当前存续候选的冻结门槛 |
| confirmed_h、confirmed_direction_h | 今天是否确认、确认方向；它们不是买卖指令 |
| running_extreme_*_h | 日末当前方向极值、原价、有效观察序号和日期；未确认时不公开单一极值 |
| up/down_*_h | 日末候选active、anchor/price/date/observation、created_observation、threshold、scale_at_anchor、volume_reference、frontier、credit、x、new_frontier、frontier_increment、credit_increment、volume_weight |

未激活候选active=0，其余字段未知；候选创建瞬间F/Q为0，但初始t64候选随后可在当天推进甚至确认，日末不保证仍为0。`scale_at_anchor`字段名实际指创建时冻结的scale：初始锚是t63而scale是t64，其后重锚二者同日。**当日确认过的旧候选已经被消费，日末候选不是当时确认的收据。** 要审计确认条件，必须读取journal中的receipt。

journal事件种类为 `candidate_reset`、`frontier_extended`、`structure_confirmed`、`acute_up`、`acute_down`、`source_discontinuity`，含来源段、观察序号与日期及相关证据。frame attrs另有终态、模型名、单位提示；这不是另一个交易策略接口。`terminal`只保存结构状态，没有完整EW、滞后收益/量及价格原点，**不能当作增量续算checkpoint**；冻结入口按来源段完整历史重放，不能仅传一行和terminal假装等价续算。

`joint=False`为显式去量消融：新前沿权重固定1，冲击qeff=q；仍要求有效正成交量输入，不能把去量消融默认为正式B4。报告结果中 `e0_*`、`b1_strength`、`b3_grade` 是从旧结果导入的比较列；`price_*`是另跑消融附加列。它们均不属于B4核心输出，不可用e0_target“证明B4复现E0”。

## 8. 固定常数的理由与已知边界

| 常数/选择 | 本版用途 | 证据边界 |
|---|---|---|
| EW5/21 | 分别描述较快、较慢净推进 | 预设时间尺度，未证明最优 |
| 前63收益、前21量 | 典型变动与量基准 | 不含当天；主连换月、拆分等仍须上游审查 |
| 结构√21/√63 | 两种位移分辨率 | 不是统计置信度，非固定持有期限 |
| 1.4826、1e−8 | 尺度缩放、零变动数值下限 | 不等于行情真噪声或最小交易幅度 |
| 量权重0.5—2 | 限制单份新价证据受量的放大/缩小 | 参与假说，非知情资金证明 |
| 冲击量比截断1—4、阈值±2 | 低量不豁免、高量可强化当日冲击 | 非尾部概率保证 |
| 严格新前沿、固定候选门槛 | 防止旧坏数据离窗导致无新事实转上 | 不保证每次确认都是持久新趋势 |

既有研究中，阴跌负推进与部分急跌/快启动的描述改善，但仍有EW迟滞和过零、结构长期陈旧、快速V与失败反弹共有前缀不可区分的问题。黄金ETF曾连续21观察双结构向上而μ21为负；半导体急跌时结构确认仍可能很迟。量确实能改变部分结构路径，但没有证明量带来交易净收益。

原123技术检查、独立公式重算及物理前缀核验是技术证据，不是收益证据。冻结B4意味着以后比较同一个版本，不意味着已成为成熟温度、不意味着通过E0兼容、不意味着账户准入。原E0/R/R1、全部旧研究和失败证据保留。
